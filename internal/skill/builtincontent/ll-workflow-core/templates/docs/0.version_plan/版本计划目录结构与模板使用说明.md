# 0.version_plan 版本计划

> **版本规划与里程碑管理。**

## 目录结构

```text
0.version_plan/
├── plan/              # 版本计划详情（按版本号分子目录）
├── template/          # 模板目录
└── README.md          # 本文件
```

## 使用规范

### plan/ 目录

按版本号组织版本计划：
```text
plan/
├── 03/               # v03 版本计划
├── 04/               # v04 版本计划
├── 05/
├── 06/
├── 07/
├── 08/
├── 09/
├── 11/               # v11 版本计划
└── template/         # 版本计划模板
```

### 版本计划内容

每个版本计划应包含：
- 版本目标与范围
- 里程碑与时间节点
- 任务分解与分配
- 风险与依赖
- 验收标准

## 命名规范

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 版本目录 | `{版本号}/` | `11/` |
| 版本计划 | `v{版本号}-计划.md` | `v11-计划.md` |

## 模板列表

- `template/01-version-plan-template.md`：版本计划模板（含范围、里程碑、风险与验收）
- `template/02-milestone-checklist-template.md`：里程碑验收清单模板（含状态、证据与放行结论）
