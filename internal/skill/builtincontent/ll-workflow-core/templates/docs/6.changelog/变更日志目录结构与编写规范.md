# 6.changelog 变更日志

> **版本变更记录与发布说明。**

## 目录结构

```text
6.changelog/
├── template/          # 模板目录
└── README.md          # 本文件
```

## 使用规范

### 变更分类

| 类型 | 说明 | 图标 |
| --- | --- | --- |
| Added | 新功能 | ✨ |
| Changed | 功能变更 | 🔄 |
| Deprecated | 即将弃用 | ⚠️ |
| Removed | 已移除 | 🗑️ |
| Fixed | Bug 修复 | 🐛 |
| Security | 安全修复 | 🔒 |

### 命名规范

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 版本日志 | `v{版本号}-changelog.md` | `v11-changelog.md` |
| 阶段日志 | `{YYYY}-{MM}-changelog.md` | `2026-04-changelog.md` |

## 模板列表

- `template/01-whatsnew-template.md`：版本/阶段更新日志模板
- `template/02-change-entry-template.md`：单条变更记录模板（含影响、风险与验证信息）

## 维护规则

1. **每次发布必须更新**：新版本发布时同步更新 changelog
2. **关联需求编号**：每条变更关联 REQ-XXXX
3. **记录影响范围**：说明变更影响的模块和用户
4. **标注风险等级**：高风险变更需要特别标注
