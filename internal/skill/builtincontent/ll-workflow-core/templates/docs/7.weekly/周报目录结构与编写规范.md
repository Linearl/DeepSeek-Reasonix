# 7.weekly 周报

> **项目周报与经验回灌管理。**

## 目录结构

```text
7.weekly/
├── template/          # 模板目录
└── README.md          # 本文件
```

## 使用规范

### 周报内容

| 章节 | 说明 |
| --- | --- |
| 本周完成 | 已完成的任务和成果 |
| 进行中 | 正在进行的任务和进度 |
| 问题与风险 | 遇到的问题和风险 |
| 下周计划 | 下周的工作计划 |
| KPI 指标 | 关键绩效指标 |

### 经验回灌

高价值经验从任务执行回灌到周报：
- 重复修复模式
- 新的治理例外
- 高价值默认决策
- 审计规则缺口

### 命名规范

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 周报 | `{YYYY}-W{周数}-weekly.md` | `2026-W15-weekly.md` |
| KPI | `{YYYY}-W{周数}-kpi.md` | `2026-W15-kpi.md` |

## 模板列表

- `template/01-weekly-report-template.md`：项目周报模板
- `template/02-weekly-kpi-template.md`：周报 KPI 模板（含目标、实际、趋势与改进动作）
- `template/03-high-value-learning-backlog-template.md`：高价值经验回灌清单模板

## 维护规则

1. **每周必须更新**：周五下班前完成周报
2. **关联任务编号**：完成的任务关联 REQ-XXXX
3. **记录经验教训**：重要经验及时记录
4. **KPI 数据准确**：确保指标数据真实可靠
