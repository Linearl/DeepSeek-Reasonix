# 1.task 任务管理

> **新建或完成任何任务包之前，必须阅读本文档和"任务包六件套构成-编号分类规则-自动归档机制.md"。**

## 目录结构

```text
1.task/
├── A.inactive/{version}/ # 未激活需求（已定义但未进入执行池）
├── B.todo/{version}/     # 待执行任务（按版本分子目录）
├── B.1.paused/          # 暂停任务（临时中止，可恢复）
├── B.2.done/            # 已完成任务（自动归档目标）
├── B.3.cancelled/       # 已取消任务
├── template/            # 模板目录
│   ├── 六件套/          # 任务包六件套模板
│   └── audit-package/   # 审计任务包模板
├── requirements.md      # 需求任务总清单（SSOT，自动生成）
├── README.md            # 本文件
└── 任务包六件套构成-编号分类规则-自动归档机制.md  # 路牌文档
```

## 任务生命周期

```text
                    ┌─────────────┐
                    │  A.inactive │  需求已定义
                    └──────┬──────┘
                           │ 激活
                           ▼
                    ┌─────────────┐
              ┌────►│   B.todo    │◄────┐
              │     └──────┬──────┘     │
              │            │            │
              │     ┌──────▼──────┐     │
              │     │ B.1.paused  │     │ 恢复
              │     └─────────────┘     │
              │                         │
              │     ┌─────────────┐     │
              └─────┤ B.2.done    │─────┘
                    └─────────────┘  完成
                           │
                           ▼
                    ┌─────────────┐
                    │B.3.cancelled│  取消
                    └─────────────┘
```

## 状态枚举

| 状态 | 图标 | 目录 | 说明 |
| --- | --- | --- | --- |
| 待激活 | 🆕 | A.inactive/{version}/ | 需求已定义，尚未进入执行池 |
| 待办 | 📋 | B.todo/{version}/ | 已进入执行池，等待开工 |
| 进行中 | 🚧 | B.todo/{version}/ | 任务正在执行 |
| 暂停 | ⏸️ | B.1.paused/{version}/ | 任务临时中止，可恢复 |
| 已完成 | ✅ | B.2.done/{version}/ | 任务完成并验证通过 |
| 已终止 | 🛑 | B.3.cancelled/{version}/ | 任务取消/终止 |

## 任务包命名规范

```text
v{版本}-r{编号}-p{优先级}-{简称}
```

示例：
- `v11-r1001-p1-四件套治理`
- `v11-r2031-p1-上传自动用途识别`

## 六件套构成

每个任务包必须包含以下文件：

| 文件 | 必需 | 说明 |
| --- | --- | --- |
| `README.md` | 是 | 任务包概述 |
| `REQ-XXXX.md` | 是 | 需求说明（工作副本） |
| `REQ-XXXX-original.md` | 是 | 需求说明（冻结副本） |
| `tasks.md` | 是 | 开发任务清单 |
| `run_result.json` | 是 | 运行状态（控制自动归档） |
| `design.md` | 否 | 技术设计文档 |
| `decision_log.md` | 否 | 决策记录 |
