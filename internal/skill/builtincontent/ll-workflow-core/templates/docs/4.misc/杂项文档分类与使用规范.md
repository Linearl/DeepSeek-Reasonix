# 4.misc 杂项文档

> **临时文档、交接文档、学习记录等非正式文档。**

## 目录结构

```text
4.misc/
├── agents/            # Agent 相关文档
├── learnings/         # 学习记录与经验总结
├── project-approval/  # 项目审批文档
├── template/          # 模板目录
├── {主题}-{日期}/     # 专题文档（按主题+日期组织）
└── README.md          # 本文件
```

## 使用规范

### 文档分类

| 文档类型 | 落位目录 | 说明 |
| --- | --- | --- |
| 临时文档 | `{主题}-{日期}/` | 一次性或临时性文档 |
| 交接文档 | `{主题}-交接-{日期}/` | 跨人员/跨团队交接 |
| 学习记录 | `learnings/` | 技术调研、学习笔记 |
| Agent 文档 | `agents/` | AI Agent 相关配置与说明 |
| 审批文档 | `project-approval/` | 项目立项、审批记录 |

### 命名规范

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 专题文档 | `{主题}-{日期}/` | `{项目名}-恢复交接-{YYYY-MM-DD}/` |
| 学习记录 | `{日期}-{主题}.md` | `2026-04-01-MCP协议学习.md` |
| 交接文档 | `{主题}-交接-{日期}.md` | `前端开发-交接-2026-04-15.md` |

## 模板列表

- `template/01-reference-note-template.md`：参考资料/证据记录模板
- `template/02-reference-inventory-template.md`：参考资料清单模板（含来源、用途与可信度）

## 维护规则

1. **临时文档定期清理**：超过 3 个月的临时文档考虑归档或删除
2. **交接文档保持完整**：确保交接内容完整、可追溯
3. **学习记录持续更新**：重要学习成果及时记录
