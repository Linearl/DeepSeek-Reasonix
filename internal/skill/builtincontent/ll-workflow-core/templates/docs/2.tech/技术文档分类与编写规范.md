# 2.tech 技术文档

> **技术文档统一目录，覆盖 API、架构、开发规范、用户指南等。**

## 目录结构

```text
2.tech/
├── api/               # API 文档（接口定义、请求/响应格式）
├── architecture/      # 架构文档（系统设计、模块关系、技术选型）
├── database/          # 数据库文档（表结构、索引、迁移）
├── development/       # 开发文档
│   ├── standards/     # 编码规范
│   ├── templates/     # 代码模板
│   ├── tools/         # 工具使用说明
│   └── workflow/      # 开发流程规范
├── guide/             # 技术指南（入门、配置、常见问题）
├── specification/     # 技术规范（协议、格式、约束）
│   └── html/          # HTML 相关规范
├── user_guide/        # 用户指南（按功能模块组织）
│   ├── basic/         # 基础功能
│   ├── data/          # 数据管理
│   ├── deployment/    # 部署指南
│   ├── fiftyone/      # 数据可视化相关
│   ├── outbound/      # 出库功能
│   ├── testing/       # 测试指南
│   ├── upload/        # 上传功能
│   └── user/          # 用户管理
└── README.md          # 本文件
```

## 使用规范

### 文档分类

| 文档类型 | 落位目录 | 说明 |
| --- | --- | --- |
| API 接口文档 | `api/` | RESTful API 定义、请求/响应格式 |
| 系统架构设计 | `architecture/` | 模块关系、技术选型、设计决策 |
| 数据库设计 | `database/` | 表结构、索引、迁移脚本 |
| 开发规范 | `development/standards/` | 编码规范、命名约定 |
| 技术指南 | `guide/` | 入门教程、配置说明、FAQ |
| 用户手册 | `user_guide/` | 按功能模块组织的用户指南 |

### 命名规范

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| API 文档 | `{模块}-api.md` | `upload-api.md` |
| 架构文档 | `{主题}-architecture.md` | `system-architecture.md` |
| 指南文档 | `{序号}-{主题}-guide.md` | `01-getting-started-guide.md` |
| 规范文档 | `{序号}-{主题}-spec.md` | `01-api-spec.md` |

## 模板列表

- `01-doc-frontmatter-description-template.md`：文档 frontmatter 模板
- `02-analysis-report-template.md`：分析报告模板
- `03-guide-doc-template.md`：指南文档模板
- `04-api-doc-template.md`：API 文档模板

## 维护规则

1. **新增 API 必须同步文档**：接口变更时更新 `api/` 目录
2. **架构决策必须记录**：重要技术选型写入 `architecture/`
3. **用户指南保持更新**：功能变更时同步更新 `user_guide/`
4. **使用 frontmatter**：所有文档必须包含 `description` 字段
