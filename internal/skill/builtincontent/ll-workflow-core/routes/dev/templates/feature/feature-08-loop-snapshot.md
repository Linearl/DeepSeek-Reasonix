# 循环快照模板（feature-08）

## 用途说明

用于在每轮 B.1→B.2→B.3→B.4 后记录当前状态，便于循环推进与交接。

## 最小必填字段

- 轮次编号
- 当前处理专题
- B.1/B.2/B.3 结果摘要
- B.4 判定结果（未完成回 B.1 / 全部完成进 C.1）

## 可选字段

- 剩余任务燃尽信息
- 关键阻塞
- 优先级调整说明
- 状态一致性结果
- 交接工单完整性
- 质量门结果
- 双格式证据路径
