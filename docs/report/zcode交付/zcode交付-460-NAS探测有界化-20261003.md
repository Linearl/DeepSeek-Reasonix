## 二、修法（全部接入既有引擎或同模式加界）

1. **A workspacelease**：解析半边一行委托 `sandbox.ResolveAbsPath`（引擎）；`.git` 走查包 `boundedGitWorktreeRoot`（250ms 预算，goroutine+缓冲通道+timer，超时保留未折叠 root + `slog.Warn` 一条）。预算为包级 var `identityResolveBudget`（测试缝同置一处，生产不外露）。
   **语义申报**：修前 EvalSymlinks 的非 NotExist 错误会让身份解析失败→Build 报错；修后引擎超时/失败一律回退 cleaned abs（与 455fix「超时保留 cleaned abs」契约一致，可用性优先）。同输入键形不变（deepest-existing-ancestor+缺尾回拼，与原 walk 同构）。
2. **B pathidentity**：`Canonical` 委托 `sandbox.ResolveAbsPath`，删除本地重复 walk（455fix「消双实现」同款收敛）。键形逐点不变（有引擎一致性直测）；附带收益：保存路径键从每请求全 walk 变 TTL 缓存命中。
3. **C boot 三点**：
   - `normalizeAdditionalDirs`：解析走引擎；目录校验包 `boundedStat`（250ms）。**校验超时 → WARN + 跳过该目录**：授权面 fail closed（未验证的根不授予写权限），boot 可用性 fail open（原来挂 21s 后 Build 直接失败）。目录不存在/是文件仍照旧报错（拼写保护不放宽，预存 `TestNormalizeAdditionalDirsRejectsInvalidPaths` 回归绿）。
   - `pathComparisonKey`：走引擎；超时保留原路径——与原 EvalSymlinks 失败回退语义一致。
   - `nearestGitRoot`：包 `boundedNearestGitRoot`（250ms）；超时 = 无 git root → 用 cwd，与「找不到 .git」同回退。
4. **测试缝**：`gitWorktreeRootWalk`/`additionalDirStat`/`gitRootWalk` 包级 var，生产代码从不重赋值（与 `sandbox.canonicalEvalSymlinks` 同风格）；预算 wrapper 全部用缓冲通道，超时后晚归的 syscall 不阻塞、不泄漏。

## 五、遗留与边界

1. **语义变化两处（申报）**：① workspacelease 身份解析的文件系统错误不再失败 Build（回退 cleaned abs）；② 附加目录校验超时改为跳过授予（原来是 21s 后 Build 失败）。方向均为「授权面 fail closed、可用性 fail open」，与 455 原则一致。
2. **引擎 TTL 的既有权衡延伸到新调用点**：symlink/junction 身份翻转在 30s 窗口内对 workspacelease/pathidentity 不可见（lease 键/保存键短窗口稳定，出错方向为「沿用旧键」，非横向越权）。
3. boot 全包首跑 600s 命中 go test 默认超时（panic 段在 MCP go-sdk 连接栈，非断言失败）；加长超时（25m）重跑 892.9s 完整跑完，唯一 FAIL 为上述预存 bench 红。455fix 记录该包 447.6s——本机当前负载下同包更慢，属环境差异。
4. desktop 全包测试未跑（预存 watchdog 强杀，455fix 同）；tsc tip 预存错与本件无关。
5. 扫描清单 §三所列遗留点未修（均不阻塞会话打开主链）；后续若 NAS 再暴露新症状，优先复用本引擎扩点。
