## P2 重启自动轮：区分「更新触发的重启」与「正常重启」

### 位置与做法

| 内容 | 位置 |
|---|---|
| 标记文件本体（写入/消费/弃置名册） | `desktop/update_restart_marker.go`（新文件；`writeUpdateRestartMarker` :62，`updateRestartResumeAllowed` :97，`dropUnfiredAutonomousUpdateRoster` :131） |

| 恢复点门禁 | `desktop/tabs.go:4273`——auto-resume 家族（49-A2 goal 路径 + 254 roster 路径）仅当 `updateRestartResumeAllowed()` 放行才触发；标记按进程消费一次（sync.Once），拨杆 `off` 与标记门禁叠加生效 |
| 兜底②（中断工具不重放） | `desktop/autonomous_update_resume.go:317`（roster 路径）、`desktop/tabs.go:4307`（goal 路径）；判据 `tabHasInterruptedToolCall`（:53），底层 `internal/control/tool_recovery.go:58` `HasPendingToolRecovery` |
| 消费即删 + 非更新启动弃置名册 | `update_restart_marker.go`：标记读后即删（不跨两次启动）；无标记启动时把上次重启登记的未触发名册清空并逐条 Warn 点名（`非更新不续` 标记，遵守 1545 反静默丢失） |

语义变化（按用户裁决执行）：
1. 手动重启（RestartDesktop）、正常关闭/重开**不写标记** → 下次启动**不自动唤醒任何会话**（原 461 症状消除：卡在邮箱工具的会话不再被自动唤醒二次阻塞）。
2. 更新重启（发布 staging / 回退版本 / 官方更新通道）写标记 → 下次启动按 450/254 语义自动恢复。
3. 兜底②：恢复时若会话最后一步是未知结局的工具调用（未决 effect 记录），**不自动重放**「继续」提示——登记照常消费（不会在日后复活），fence 不结算（「中断的工具需要核实」面板留给人工）。干净会话（无未决工具）照常续跑，450 语义不回退。
4. 附带语义说明（裁决内含）：goal sidecar 路径（49-A2）同样受标记门禁——真崩溃（无标记）后 goal 会话也不再自动续跑，改为人工打开；如需崩溃恢复豁免需后续单独裁决。

- `go test . -run "Restart|Resume|Autonomous|VersionSwitch|Updater|UpdateRestart"` 全绿（ok 34s）。
- `go build ./...`（根模块）与 `go build ./...`（desktop 模块）通过；`go test ./internal/control/ ./internal/collabinbox/` 全绿（control 257s）。
- 状态判据（验收）：`update-restart-marker.json` 存在=上一次退出是更新重启；不存在=普通启动。
