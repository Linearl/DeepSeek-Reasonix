# Reasonix Fork 桌面版 v1.38.3-20261014-1900 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261014-0149** 以来的全部更新（批 25 八件）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。

## 概览

本版是 **会话可靠性与渲染修复批（八件）**：①渲染层瞬时丢失对话内容修复；②切 tab 就绪 16s 的 ancillary 腿治理（P0）；③恢复确认门不再卡住无人值守会话；④ask 工具在 autopilot/yolo 下的可达性收口；⑤崩溃回放 payload 伪造三层核实。

## 🖥️ 渲染与性能

- **渲染层瞬时丢失修复**（tl874）：未切 tab 时屏幕闪烁后 transcript 区域留白、需重开窗口恢复的问题修复。
- **切 tab 就绪治理**（tl882，P0）：`ContextUsageForTab` 加超时与缓存，解决切 tab 后 16 秒才就绪的 ancillary 腿问题。
- **canonical 探针**（tl883）：切 tab 路径零行为变更的前置打点，为后续根治件提供观测数据。

## 🤖 无人值守与决策链

- **恢复确认门不再阻塞自动化**（tl868）：守护/心跳类无人值守会话被恢复确认门卡住等人工=死锁。改为无人值守会话支持「自动继续」会话级策略，恢复时不弹门。
- **ask 工具可达性收口**（tl806）：修复 autopilot/yolo 下 ask 工具不可达用户（自动应答绕过），即使用户显式说「可以问我」。
- **附件双路发送**（tl870）：附件草稿在运行中不再被拦截；带附件消息按引导消息或新 turn 双路正确发送。

## 🛡️ 稳定性

- **崩溃回放 payload 伪造核实**（tl878）：上游 issue #45 复合处置，三层核实后按其自带 file:line 修复设计落地。
- **24 版合并后投影失效回归归因**（tl813）：调研会话触发「投影失效→全量重投影」导致 2.5M/1M 超窗的 P1 归因。
- **移植上游 #12526**（tl814）：Responses 流工具调用完整性校验补齐，修复「执行中异常自动中断」的机制缺口。
