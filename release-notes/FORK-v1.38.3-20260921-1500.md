# Reasonix Fork 桌面版 v1.38.3-20260921-1500 — Release Notes

> 本版本基于官方 `v1.38.3`，包含 `desktop-v1.38.3-20260916-1205` 以来的全部更新（约 190 个提交）。
> 数据 / 会话 / 记忆目录与官方版完全兼容，**覆盖安装即可，无需迁移**。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

这个版本集中解决两件事：**大会话不再卡**（打开、切换、保存从最长 1 分钟降到 1 秒上下），以及**多会话协作正式可用**（一套完整的跨会话沟通 + 并行开发工作流，含三个内置技能）。另外还有一批界面与体验改进。

---

## 🚄 大会话：打开、切换、保存不再卡

以前，几百 MB 的大对话打开要一分多钟、切换标签页卡 10 秒、每次自动保存都卡几十秒。现在：

- **打开 / 切换回到 1 秒上下**——只加载最近的消息，更早的历史翻上去再补，不会一次全读。
- **快速浏览不影响数据安全**——翻看历史不会改动会话内容，放心翻。
- **超长对话不会再「写不进也读不了」**——到达上限时自动整理，不需要手动处理。
- **卡了能查**——如果某次操作还是慢，日志会直接说明慢在哪个环节（排查命令见文末攻略）。
- **实验室新增「缓存大小调整」**——常驻的会话数量和缓存上限可以按机器配置调（默认关闭，行为不变）。

---

## 🤝 多会话协作：从实验特性到正式可用

**开启方式**：设置 → 实验室 → **跨会话通信** → 打开总开关 → 按提示重启。

开启后可以：

- **会话之间直接对话**：让 A 会话把活派给 B 会话、B 干完回信，全程在 Reasonix 里完成。
- **管理会话**：重命名、移动到分组、批量创建协作会话、创建时带上第一条指令、创建时指定用哪个模型。
- **跨会话消息轮次上限可调**：实验室里新增「协作链 hop 上限」（默认 5 次，可调 3~1000）——多轮来回的任务不再被迫中途换新对话。
- **发信更可靠**：发出去的消息有身份、有回执；接收方每封消息尾部都能看到「怎么回信」的指引。

## 🧩 内置技能：一条完整的「自主迭代」回路

以下技能随包内置，**对话里直接说就能触发**，无需安装：

| 技能 | 触发方式 | 能做什么 |
|---|---|---|
| `ll-iteration-intake` | 「跑一轮迭代巡检」「分析意见箱」 | 把意见箱反馈、崩溃记录、性能告警扫成「需求初稿」，支持痛点聚类分析 |
| `ll-iteration-plan` | 「排这轮开发」「哪些先做」 | 按固定判据排序，产出一轮开发计划（每项带可验证的验收标准） |
| `ll-iteration-parallel-dev` | 「用并行会话开发」「分工给几个会话做」 | 建多个 worktree 并行开发、收货合并、发版回写，一条龙。⚠️ 需要先开启跨会话协作 |
| `gh-issue-triage` | 「清理一下仓库 issue」 | 自己仓库的 issue 闭环：修复 → 验证 → 带证据关闭（原名 github-issue-triage，更顺手） |

> 原 `feedback_analysis` 技能的能力已并入 `ll-iteration-intake`，不再单独提供；`reasonix-fork-guide` 的实验特性说明已同步更新。

## 🔧 其他改进

- **模型名字看得懂了**：下拉里的供应商显示为 `DeepSeek Flash`、`MiMo Pro` 等可读名，不再混着内部代号。
- **重复的模型连接可以隐藏**：在 `config.toml` 对应连接段加一行 `hidden = true`，重启后所有界面都不再显示它，已有任务和会话不受影响。
- **自动化任务「立即执行」修复**：慢机器上不再静默失败，新建的会话会出现在左侧列表。
- **实验室改版**：实验特性按分组导航，更好找。
- **其他**：内置项目根可以移出侧栏、多条引导消息合并注入、上下文压缩保留思考片段、资源预算收拢等。

## ⚠️ 升级提醒

- **覆盖安装即可**；会话 / 记忆 / 配置目录与官方版完全兼容。
- ⚠️ **存储模式请停留在 v3**：实验里的「双写 / 仅 v4」档位尚未完成实测，已手动切换的用户请切回 v3。
- **不要回退到 1.34 / 1.38.1 以下**：会话日志已升级到 schema 2，旧版本会拒绝加载（文件不损坏）。
- 切出大会话时 1–3 秒的等待属已知现象，下一版修复。

## 安装

- GitHub Release 资产：`reasonix-desktop-amd64-installer.exe`，下载后直接安装，覆盖升级无需卸载。
- 已装用户：设置 → 实验室 → 开启 `restart-and-update` 后从 staging 发布。
