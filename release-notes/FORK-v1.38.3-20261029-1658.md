# Reasonix Fork 桌面版 v1.38.3-20261029-1658 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261029-1054** 以来的全部更新（9 项滚合+1 笔 CSS 修复：tl1240 双刀 + tl1222 + tl1246 + tl1248 + tl1193b + tl1242 + tl1244 + tl1102c）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。

## 概览

本版是 **批量操作与报障清障大批**：①侧栏批量会话操作（归档/移动一次一键）；②workbench 头部对齐 classic；③删除分组死按钮根治；④心跳任务行内暂停按钮；⑤E 开关迁实验室；⑥群聊邀请面板/搜索面板两处交互修复；⑦文档站内容补齐。

## 🗂️ 侧栏批量会话操作（tl1240，双刀）

- **批量归档/移动**：侧栏多选会话后一键批量归档或移动到分组（此前只能逐个操作）；后端批量端点 8 会话耗时 **1.18s→455ms**（38%）。
- **交互形态**：头部批量管理开关+checkbox 多选+行点击即切换+批量操作条（进度 N/M+失败列表+运行中跳过）；**默认视图零改动**（批量态才挂载）。

## 🧭 workbench 头部对齐（tl1222）

- workbench 布局左侧项目栏头部对齐 classic 三控件形态（合并筛选/折叠/新建下拉），双布局头部不再两套样子。

## 🗑️ 删除分组无效根治（tl1246）

- **Windows 原生确认弹窗死按钮根治**：此前「删除分组及其会话」点了没反应——确认弹窗在 Windows 上是永远答「否」的死按钮（Wails v2.16 忽略按钮数组）；改用应用内确认对话框后全链打通，删除失败也从静默改为可见报错。

## ⏯️ 心跳任务行内暂停（tl1248）

- 心跳任务列表行内新增暂停/恢复按钮（flat+grouped 双视图），暂停后行内即切恢复态，与「已暂停」筛选联动。

## 🧪 E 开关迁实验室（tl1193b）

- 实验开关迁移至设置-实验室「记忆与上下文」新分组（未稳定徽章、默认关）；配置实验段同步落地（重启生效）。

## 👥 群聊邀请面板关闭（tl1242）

- 邀请弹层点击面板外部即关闭（mousedown+click 双通道），不再必须找关闭按钮。

## 🔍 搜索面板高度溢出根治（tl1244）

- QuestionSearchPanel 高度溢出根治（max-height 包含块口径修正），不再顶出可视区。

## 📚 文档站内容补齐（tl1102c）

- 文档站 15 页真实内容+部署链就绪（结构/写作约定/发布核对步骤/基址对齐/共存约束）。
