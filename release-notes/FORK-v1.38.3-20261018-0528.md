# Reasonix Fork 桌面版 v1.38.3-20261018-0528 — Release Notes

> 基于官方 v1.38.3，包含上一个发布版本 **desktop-v1.38.3-20261017-0646** 以来的全部更新（约 22 项，批 38/39/40 三批收官）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本版是**能力架构渐进披露首发 + 对话内产物卡片 + 一批界面与稳定性收尾**：①AI 的工具目录全面改版——默认摘要档一次看全、53 个工具分成八组可查「组卡」、九个会话协作动作收拢为统一入口（后三项为实验特性，默认关闭，实验室开启）；②对话里可以直接渲染 Markdown/文本报告卡片并一键打开；③修复「发消息没反应」类无界等待、低分屏错排、todo 跨任务错乱等一批实际使用痛点；权限设置改下拉框、项目树不再有「加载更多」按钮。

## 🚄 主线一：AI 工具目录渐进披露（实验特性，实验室开启）

- **工具清单默认变摘要档**：AI 查询可用工具时默认一次返回 30 条精简摘要（每条一行），不再整屏刷 schema；要看细节再单独取。附两道安全闸：超大清单先预检、超限拒绝并给出分页示例（护栏而非故障）。
- **工具分八个组，可查「组卡」**：会话协作、消息收发、记忆、文件等 53 个工具按场景分组；AI 或用户可查某组的组卡（组内有什么、典型用法、入口示例），找工具不再靠猜。会话组还带常用动作映射（发消息/列会话/建会话等一屏可达）。
- **九个会话协作动作统一入口（session_hub）**：原本分散的九个协作工具收拢为一个聚合入口，AI 学习成本与上下文占用双降；关闭时九件原样可用，行为完全等价。
- **能力目录常驻精简版**：目录卡片以约 2 万字符的精简形态常驻 AI 上下文，使其始终"知道有什么能力"，又不过度消耗预算。
- ⚠️ 以上组/组卡/聚合入口/常驻目录挂实验开关，**默认关闭零变化**；开启：设置 → 实验室 → 对应开关，新会话生效。

## 🎴 主线二：对话内产物卡片与界面收尾

- **报告卡片直接在对话里渲染**：新增 render_artifact 能力——AI 把 Markdown/纯文本报告渲染成对话内卡片（首期 md/text），附「一键打开」按钮用系统默认应用查看原文件。
- **会话职责可见可编辑**：鼠标悬停会话即可看到职责说明（自动生成的名字背后到底干什么），右键可直接编辑弹窗修改。
- **对话权限设置改下拉框**：从平铺按钮组改为下拉二选一（对齐竞品样式，省空间）；弹窗尺寸加大、下拉展开对齐修复一并完成。
- **工具相关开关集中一页**：设置 → 实验室 →「工具优化」聚合页——工具表相关开关单页管理，常驻缓存体积给出可见警告，不再逐处翻。
- **项目树浏览不再有「加载更多」**：普通浏览改为自动续拉到底（搜索分页保留），翻历史不用反复点按钮。
- **快捷指令可用 AI 编辑**：agent 获得 set_quick_commands 工具，可用一句话增改快捷指令（复用与设置面板同一套校验）。
- 实验室条目收编：散落的自动化/效率条目并入对应卡片，「对话内产物卡片」入口归入视图布局卡（此前入口不可见与设置搜索遗漏一并修复）。
- 修复低分辨率屏幕展开侧边栏时输入框下方错排（拖动调整高度后恢复）。

## 🩹 稳定性与执行引擎

- **「发消息没反应」根治**：进程内保存等待曾可无限排队——现在有界超时并明确报错，不再无声卡死。
- **todo 跨任务不再错乱**：AI 在多个任务间切换时待办列表曾互相覆盖/判伪拒绝——引入计划标识语义修复三处，去重重发时明确提示「已去重，上次结果仍有效」并附上次结果摘要。
- **审批模式继承**：后台守护任务此前每次轮转都被打回逐条审批——现在继承你的全局审批模式设置，autopilot 下不再反复打断。
- **陈旧并发控制头退役**、冗余的重启更新工具入口移除（与设置面板功能重复）。
- **新增 rename_topic 工具**：按会话 ID 直接重命名会话（改名不换会话身份，跨端引用不断）。

## ⚠️ 升级提醒

1. **覆盖安装即可**，数据/会话/记忆目录与官方版兼容，无需迁移。
2. **存储模式建议维持 v3**：v4 可实验开启但 v3 记录会滞后；存储设置里的迁移可随时把会话迁回 v3（先自动备份）。
3. **不要回退到 1.34 / 1.38.1 以下**——事件日志 schema 单向升级，旧构建会拒绝加载（文件本身不损坏）。
4. **已知现象**：切换超大会话仍需 1~3 秒（专项排期中）；预存红基线两项（task704-switch 族 5 红 + task564 族 1 红）为纯测试面已知项，不影响使用，下一版清理。
5. 未验证项：部分包未跑 `-race` 全量（按既有口径）。

- 本地构建：`scripts/build-local-installer.sh`，staging 快速切换（Settings → Experimental → restart-and-update）。
