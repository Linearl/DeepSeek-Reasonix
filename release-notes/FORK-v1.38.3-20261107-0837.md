## 一、打回与缺陷根治（用户实测问题闭环）

- **版本面板全链收口**（tl1415c + tl1415d9，包 80 复测打回）：面板「主线」标记与切换判定读同一权威源（打开的 tab → 显式偏好），同 path 不再重复两行；降级行亮「降级副本」+文件名；拒绝文案三语人话（技术原文保留）；**顺修真 bug**：标签页停在副本上时「切回主文件」被静默带回副本。**点9 裁决落地**：展开的行在刷新/关开面板/采纳副本后保持展开（展开=用户状态），键用稳定标识不受主线切换影响；默认收起语义不变。
- **归档自撞根治**（tl1429c，包 80 复测仍失败）：真因=同一文件以两种大小写拼写进归档目标集，流程和自己刚拿的锁相撞。去重改 canonical 身份+批内幂等；持有者日志不再打误导性的 pid=0。
- **删除回弹+归档拒老会话**（tl1363b，11-05 反馈）：删掉的会话约 1 分钟弹回侧栏=心跳拿死 id 重开+界面重建清删除标记，已根治（绑定自动迁新会话，显式恢复语义不变）；空壳老会话归档一次成功，不再需要手改 json。
- **跨会话/群聊图片四缺口**（tl1465）：群聊图片恢复渲染（`@` 前缀未剥是根因，日志秒级刷屏同点断根）；跨会话消息图片内联显示；群聊粘图即时反馈且切标签页不丢；群聊不再渲染会话引导消息。
- **guardian 重启丢对话修复**（tl1424d，10-22 起的真回归）：分类闸门误拒 guardian 伴随转录，每次重启静默清空；修复后恢复跨重启对话与增量游标，审计侧车仍拒。
- **Goal 早停根治**（tl1459，用户三令+架构评审对齐）：根因定案=列表修复在保存空档改账本→检查点判冲突→回合被取消→goal 静默停（实际出口是第 5 个取消分支，非任务书所列 4 出口）。每轮退出打点+停止必带原因+6 类三语通知+界面同步熄灭；「promote 误改状态」怀疑实测证伪；自判死小修（有活租约时修复让路）。
- **性能诊断两缺口**（tl1417，issue #82）：max 长任务单独分桶+采样密度诚实标注；修掉「缓冲满轮换把长任务采样整段丢掉」的真机制；新增「长任务前最后活动」一行（开销 ≈ 一帧的 0.02%，双出口脱敏有钉）。
- **工作流重复条目**（tl1440）：对抗复核改写后不再重复入袋（真实 run 对账 10→7），退化可见+conclusion 口径注明。
- **「修复并瘦身」等版本面板误删防护**（tl1448，包 80 漏滚补合）：同 stem 双行区分+删除路径校验三层+主线文件绝不进清理集；移植适配中发现并修掉「清理入口可能误删主线文件」的真缺口。

## 二、新功能（用户立项/拍板）

- **资源管理器**（tl1456）：命令面板 → 工具与诊断 → 资源管理器；内存总览+进程表+子代理段；刷新节流，关面板即停；CPU/存储/网络 tab 后补。
- **协作中心『通知』栏**（tl1458）：历史通知留档（时间降序+200 条 FIFO+去重），四族接入「留档≠拦截」，级别筛选/懒加载/清空。
- **命令面板接入协作中心**（tl1462）：Ctrl+K 搜「协作中心/信件/聊天/群聊/通知」直达；受同一实验开关门控。
- **通知整合**（tl1464，用户批准方案+两点修正）：操作反馈（toast info 档+ask 后台）迁右下角统一堆叠，**错误/警告 toast 留顶部原样**；ask 展示≥10s；诊断 warn 30s 自动消失；三类开关默认全开，关展示≠关留档。
- **自定义工作流模板**（tl1454，宪法 Q2）：引擎五项补齐（节点契约/超时/取消/预算/可观测）+模板服务面+校验定位+版本化+模板视图（懒加载）+运行确认窗（deny 标红禁运行+「模板可能来自他人」提示）。**实验开关默认关**，关闭态与现状逐字节一致。
- **退役 creation 布局**（tl1450，宪法 N5）：三布局→两布局；旧配置值启动自动迁移 workbench（读兼容一版）；classic 4 兼容点入守护；bundle -3.8KiB。
- **删除 dream**（tl1453，宪法 Q1）：dream/distill 工具与实验开关移除，配置键 tombstone 兼容；决策模式保留。
- **记忆召回三小步**（tl1399）：bench 语料纳入项目库（33→780 条）+换词类目；keywords 缺失时保存回执提示补别名；存量覆盖率实测 6.2%（回填候裁决）。
- **Sentinel 通知去重**（tl1400）：同一禁用集合每进程只提醒一次，集合变化重发，清空提示「已恢复」。
- **参考页/产物交互补齐**（tl1445 参考页六项、tl1468 产物/参考相对路径+滚动条两修，覆盖 tl1428）。
- **待办封存态 UX**（tl1353）：封存后可只读展开上一回合列表，文案不再像丢数据。
