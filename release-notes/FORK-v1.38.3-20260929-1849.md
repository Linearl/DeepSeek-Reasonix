## 本包新增（批七点六 + CDP-B，13 分支 15 件）

### 体验修复

- **饼图与排序标签三层修复**：内存页堆内构成饼图溢出/重叠（数据归一 + 大弧阈值 + overflow hidden 三层根因）、环形图顺序标签显示——含像素级判据测试，图表不再超框。
- **会话菜单入口点亮修复**：设置项菜单在 manual/auto 状态下错误置灰——现按开关态正确点亮（仅 off 置灰）。
- **「合并下条」按钮可达性**：收件队列「全部合并」档下按钮改为可见禁用态 + 悬浮说明（原完全消失让用户困惑）；按钮隐藏时输出原因位日志，排查不再靠猜。

### 稳定性与恢复

- **provider 流错误重试可见性**：网络/流错误自动重试时错误条显示「已自动重试 N/M 次，恢复中」，重试期间「运行中」状态保持（不再误判为异常终止）；重试耗尽给出明确终态 + 「手动继续」按钮。
- **级联审批断链修复**：跨会话敏感操作审批的转交链两处断点修复（创建即建立转交授权 + 超时后二次转交尝试）——autopilot 父会话现在能收到子会话的敏感操作审批请求。
- **级联审批增强**：单跳（主↔子）审批恒转交不被拦截（防环逻辑保留给多级嵌套）；父会话的批准/拒绝决定落可检索日志（审计留痕）。
- **冷缓存压缩时机修复**：冷却会话真正被后台压缩（原来「该压没压」攒到唤醒后补压）；打开即豁免（不再在等待关键路径触发压缩）；只压非活跃 tab。

### 性能

- **runtime 复用/增量 boot**：同 root+model+effort 的新对话共享已建 runtime（prompt/skills/commands/hooks/registry 复用）——热路径新对话提速，开关默认关闭（实验室「runtime 复用」）。
- **MCP 阶段遥测**：boot 的 mcp 阶段逐 spec 输出耗时拆解 + 排队量化（`wait_ms`）——为后续优化提供归因数据，纯观测零行为变更。

### 新功能与配置

- **CDP 调试开关**（实验室）：开启后 WebView2 暴露 CDP 调试端点（随机端口，仅 127.0.0.1 回环）——供自动化测试/调试连接，默认关闭。
- **快速切换暂存目录可配置**：「重启并更新」的 staging 目录可在设置中自定义（不配置 = 默认 `%LOCALAPPDATA%\Programs\Reasonix\staging\`），提供复位按钮；错误提示携带生效路径。
- **「乐观并行」勾选修复**：勾选后不再「卡一会就弹回」（保存成功即 UI 成功；rebuild 失败降级为「重启生效」提示，不再回弹已保存的勾选）。
- **实验室分组调整**：「受管路径预授权」并入「自动驾驶」卡（它只影响 autopilot 行为）；「完全访问（YOLO）」移到「提效」组。
- **特性速览改大弹窗+图墙**：入口弹出大弹窗，卡片网格平铺全部特性（图标/标题/简介/怎么找）；文案从 `fork-features.yaml` 加载（改文案不改代码，缺文件/缺字段不白屏）；推荐徽章渲染位就位（默认无徽章）。
