# Reasonix Fork 桌面版 v1.38.3-20261016-2039 — Release Notes

> 基于官方 v1.38.3，包含上一个发布版本 **desktop-v1.38.3-20261012-0045** 以来的全部更新（约 80+ 项，跨批 24~35 与两次专项修复）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本版是一次**稳定性大修 + 两个新能力**：①修掉了两类"会话彻底卡死"——**转录门毒丸**（一条畸形工具参数让会话永久报错，本版装机后中毒会话自动恢复）和**保存锁互相等待**（跨会话保存互卡秒级→有界超时），另有"发消息没反应 / 设置页转圈 / CPU 飙高"的本地风暴源修复（关标签不再拖垮整个程序）；②**上下文压缩不再越压越大**，压缩失败从静默变成可见提示；③**项目分组支持任意层级嵌套**（最多 64 层），工作流编排引擎与可视化面板首次亮相（实验特性）。另含 ask 审批闭环、上百项修复与四个新技能。

## 🚀 新能力一：项目分组任意嵌套

- **分组可以放进分组**：支持多级嵌套（渲染深度 2 → 64），新建时可直接建子分组，拖拽可拖到分组三位置精确落位，删除分组时级联确认防误删。
- **右键菜单补齐**：分组右键重命名 / 解散分组、分组拖拽排序、文件夹图标兼做展开折叠。
- **误清空防护**：空项目列表不再静默清掉分组归属（数据丢失级防护）。
- 入口：左侧项目树右键 / 新建会话旁的分组按钮。

## 🚀 新能力二：工作流编排（实验特性，首发）

- **工作流可视化面板**：命令面板（搜索）→「工作流面板」——计划图预览（节点卡片、依赖连线、阶段分组）、运行中节点实时点亮（排队灰 / 运行中脉冲 / 完成绿 / 确认存疑黄 / 失败红），点节点下钻看指令全文与结果。
- **开启**：设置 → 实验室 → 未稳定档 →「工作流面板」，保存即生效。
- ⚠️ 当前为首发演示版：内置演示流程可播放，**编排引擎的端到端接线（对话中创建→面板运行）在下一版**；本版已具备完整执行引擎内核。

## 🩹 稳定性：卡死、丢话、静默失败专项

- **转录门毒丸自动解毒**：此前极少数会话会因一条空参数工具调用永久报「transcript gate」错误、再也无法继续——本版起装机后**自动放行并归一**，受影响会话（含诊断过的几个）开轮即恢复，无需手工修数据。
- **「发消息没反应 / 设置页一直转圈 / CPU 飙高」修复**：程序曾高频扫描全部历史会话文件拖垮主线程（实测设置页加载 23.9 秒、关标签超 20 秒触发整程序强杀）——扫描改缓存限容、关标签加单标签超时降级，不再殃及全程序。
- **压缩不再越压越大**：上下文压缩改单飞执行，准备期不再堆积新内容（此前"压前反升、越压越大"的根因断除）；压缩失败从静默改为**三态可见提示 + 失败卡**，可直接重试；压缩路径韧性加强，不再意外回退全量。
- **跨会话保存互卡修复**：两个会话同时保存时互相等待可长达十秒级——现在等待有界超时并明确报错，不再无限排队；保存热路径去掉慢操作（摘要计算提速约 12 倍，47.2ms → 0.6ms 量级）。
- **超大请求不再死等 18 分钟**：网关对超大 prompt 的确定性重置（RST）现在会被熔断识别——首字节前给出进度提示，不再无限重试循环。
- **「会话疑似卡死」弹窗误报修复**：等待工具（wait）执行期间不再被误判为卡死；转模型不再被已结束的后台任务拦截。
- **崩溃回放防伪造**：一键崩溃分析不再把旧报告"改头换面"成当前版本的新崩溃（版本戳与事件 ID 严格按原始记录回放）。
- 其他：新会话首次开轮失败自动重试；模型热切换后旧用量卡即时下线；启动后立即输入的草稿不再丢失。

## 📊 性能与观测

- **切标签治理四门**：打开会话 4.4s → **2.0s**、渲染长任务 174ms → **107ms**（均回门槛）；启动与首响读数持续观测中（周报自动复测）。
- **会话体积治理**：死会话事件文件超限自动轮转回落（实测 103.5MB → 45.6MB）；单会话 transcript/events 超阈值时**告警并给出转线建议**（不再无声膨胀）。
- **保存/加载提速**：会话文件读写去掉重复计算，路径大小写折叠+长效缓存（探针调用量从数万次降到近零）；几何快照加缓存（热点调用 26 次 → 0）。
- 新增右侧栏观测位与监测打点（effort 监测、委派度量、sentinel 状态展示）。

## 💬 ask 审批生命周期闭环

- **关标签再开会话，挂起的审批面板重新弹出**（超时态给出代答结果而非"结果未知"）。
- **自动代答有痕迹**：autopilot 代答时转录里明确显示「已代答 + 答案」，不再无痕通过。
- **同一问题可显式重发**：被去重拦住时用户可选择"重新提一次"，不再复用旧决定。
- 审批卡片醒目度提升。

## ⚠️ 升级提醒

1. **覆盖安装即可**，数据/会话/记忆目录与官方版兼容，无需迁移。
2. **存储模式建议**：推荐停留在 v3；v4 可实验开启（v3 记录会相对滞后），存储设置中的迁移可随时把会话迁回 v3（先自动备份）；v5 为上游自弃方向，有导入器可迁入。
3. **不要回退到 1.34 / 1.38.1 以下**——事件日志 schema 单向升级，旧构建会拒绝加载（文件本身不损坏）。
4. **已知现象**：切换超大会话仍需 1~3 秒；工作流面板当前为演示数据（引擎接线下一版）；启动/首响门读数待下期周报复测；事件文件总量治理另有专项在排期。
5. 未验证项：部分包未跑 `-race` 全量（按既有口径）。
