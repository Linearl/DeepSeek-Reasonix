## 概览

本版围绕三条主线：**稳定性根治**——「发消息后全局卡死」「循环打转停不下来」「装机后整窗挂死」「对话早停无响应」这批让会话直接不可用的问题逐一定位到根并修复，全部带自动化回归测试；**两项新能力**——工作流编排（定义管理面板 + `/workflow` 命令）与项目分组任意嵌套；**一个月的界面与体验打磨**——侧栏批量操作、滚动锚定不跳动、聊天贴底稳定、记忆召回提速、版本管理面板全链重做。此外实验室完成三档分级（推荐/可选/未稳定）共 86 项特性归档，产品文档站整体改版至 v2。

## 🚀 主线一：稳定性根治（会话不可用类问题清零）

**你能感受到的**：
- **发消息后全局卡死的风暴已终结**——此前一批老会话会每隔几秒拒绝写入、CPU 飙到 95%、消息只堆在内存里发不出去（单日数百次拒绝）；现在这类会话**打开即自动修复复活**，无需任何手动操作，警告风暴在测试中归零。
- **循环打转的会话点停止能停了**——模型陷入重复动作时，停止按钮 30 秒内自动升级为强制终止；若仍无响应，系统会**自动打断循环并明确告诉你原因**（连点几轮相同工具、没有任何新进展时触发）；停止后 5 秒内回到空闲态。
- **装机后整窗不再挂死**——此前保存任务卡住时，设置、切标签、用量面板会全部无响应且重启无效；现在读取路径与保存锁彻底解耦，即使保存被占，各面板也在 100 毫秒内正常响应。
- **对话不再「悄悄早停」**——分叉/恢复的会话此前可能盯着旧文件等消息、永远等不到而被误判卡死；现在窗口跟着搬家走，身份不再丢失，收发消息落回正确的信箱。
- **压缩失败不再把对话压死**——遇到限流自动等待续跑，遇到物理上限当场截断失败部分，对话保持可用。

**怎么用**：以上均为默认行为，无需配置；循环打断发生时会看到一条明确的中断提示。
**原理（1~2 句）**：写入防护从「无限拒绝」改为「补齐继续」，读路径从共享锁改为独立快照，停止链全入口武装自动升级，循环判定按「同签名+零新进展」计数。

## 🚀 主线二：工作流编排（新能力）

**你能感受到的**：可以把一段多步任务定义成可复用的工作流——在**工作流面板新增「定义」页签**查看、重命名、删除（二次确认）、直接运行；聊天框输入 **`/workflow`** 有参数补全直达；运行中可**暂停/恢复**（优雅挂起：跑完当前节点并落盘，随时续跑），面板可观测每个节点的执行状态。
**怎么用**：工作流面板 → 「定义」页签；或聊天框 `/workflow`。模板视图本身即完整编辑器。
**原理（1~2 句）**：面板、命令、模板、智能体工具共用同一份存储，改一处处处生效。

## 🌐 重点：跨会话协作与群聊（与 super agent 异曲同工）

**定位**：与 DeepSeek 主推的 super agent（多智能体协作）**异曲同工**——我们自 2026-09 起就以「多会话协作」原生形态落地：每个 AI 会话是独立个体，可互相发消息、查收件箱、组队干活，而不是所有任务都挤在一个对话里。

**你能感受到的**：
- **给另一个会话发消息**：像给同事发工作消息——通讯录寻址、跨会话投递、失败可重发，空闲会话约 30 秒内自动开工。
- **群聊 = AI 工作群**：把多个会话合流到一个消息流，谁说了什么、进展如何在一个窗口里看完。

**群聊用法（两个关键角色）**：
1. **@ = 定向派单**：输入 `@` 选择参与者（↑↓ 选人、Enter 确认）——消息**定向投递**给那个会话处理，适合「这件事谁擅长谁接」。
2. **副管理员 = 默认收件人 / 任务分配者**：你**没 @ 任何人**的发言，全部推送给副管理员去干（相当于群里默认 @ 负责人）；成员列表里可随时设为/撤销副管理员。
3. **保护提示**：群未设副管理员时，未 @ 的发言不会推送给任何会话（发送后如实提示，历史仍可查看）；投递有每小时上限与逐条状态（投递中/失败可重发）。

**原理（1~2 句）**：底层是带查重与排队的跨会话投递，群聊只是把多对多投递收进一个视图；副管理员本质是「未指定时的默认路由目标」。

## 🤝 主线三：分组、侧栏与消息可靠性

**你能感受到的**：
- **项目分组支持任意嵌套**——分组里可以再建分组，层级不限，侧栏树形展开。
- **侧栏批量操作**——多选会话后一键批量归档或移动到分组（此前只能逐个操作，批量接口提速 38%）；右键菜单按使用频率重排、低频项二级聚合。
- **聊天阅读不被打断**——侧栏展开/收起时聊天内容不再跳动（读到一半的文字按原位锚回）；贴底随机失效修复；左栏会话展开/收起保持滚动位置。
- **消息投递三形态丢失根治**——发给忙碌会话的消息不再丢、不再重复投递、空闲会话约 30 秒内自动开工；切换标签后新回复立即显示（此前要关开标签才恢复）；收件箱角标与懒加载修复。
- **「移出侧边栏」改红色危险确认**，空项目可正常移除；删除分组的死按钮修复。

**怎么用**：分组操作在侧栏右键与拖拽；批量操作点侧栏顶部列表开关多选。
**原理**：投递前查重+忙时排队+到达即广播；滚动锚定用结构性补偿跟随宽度变化。

## 🧠 主线四：记忆召回提速与长会话

- **重启后召回不再全量重建**——召回索引落盘为增量结构，重启首轮直接复用；配套「搜索走宽松档、自动召回走严格档」（搜索不漏、自动召回不吵），新增同义词触发通道（搜「改 bug」能召回写「修复缺陷」的记忆）。
- **压缩与长会话韧性**：压缩可见性提示、防早停审查层（只可把「停」改「续」、永不反向）、大会话冷启动解析提速约 4 倍（239ms→61ms）、内存占用从 148MB 降到 5MB 级。
- **记忆索引一次性迁移（DAG 退役）**：首次启动自动执行、有备份可回滚，296 个会话全量校验零失败——此后加载更快、占用更低。

## 🔧 我们修正的不合理机制（fork 独有）

上游能用，但以下机制在真实使用中不合理，本版起逐一修正：

| 不合理现状 | 我们的修正 |
|---|---|
| 循环打转的会话点停止停不下来，只能一级一级按 | **全入口 30 秒自动升级强制终止**，同形循环自动打断并可见原因 |
| 切模型/档位等 10 秒以上（整套运行时重建） | 同档跳过+按请求覆盖，降到 **3 秒级** |
| `!!` 开头的消息被后端误当终端命令执行 | 统一优先走快捷指令，未匹配则作普通消息 |
| 给会话发消息偶发静默丢失/重复投递 | 投递前查重+忙时排队+到达即广播，空闲自动开工 |
| 异常退出后会话卡「运行中」假象 | 残影根治，状态以实际事件为准 |
| 压缩失败把对话整个压死 | 失败部分当场截断+限流自动等待续跑，对话保持可用 |
| 老会话缺身份头每几秒拒绝写入、CPU 95% 烧机 | **打开即自动修复复活**，零手动操作 |
| 保存任务卡住时设置/切 tab 全局挂死 | 读路径与保存锁解耦，被占时各面板仍 100ms 内响应 |
| 用字节估算判上下文占用，含图片会话误触发瘦身 | 改实账判据（计价兜底），不再误伤 |
| 版本面板「查看版本」引导不可达 | 路径引导改为真实入口，按钮改名「管理会话副本」 |

**性能与观测**
- 轮询治理六项（失败有界 3 次即暂停、MCP 连接状态失败计数、共享时钟减少定时器）；用量面板（按来源/按类型看花费与缓存命中）；大会话状态解析有界化；任务列表刷新不再闪跳。

**群聊与协作**
- 群聊两大死路根治（邀请检索失效、群主退群死锁→「解散」可用）；群聊邀请面板关闭修复；跨会话信件族修复（角标、懒加载、重复投递）。

**文档与内容**

## ⚠️ 升级提醒

1. **覆盖安装**：从官方版或旧 fork 版本直接覆盖安装即可，会话与记忆数据正常读取，无需迁移。
2. **存储差异与回切承诺（重要）**：本版**移除了 DAG 事件索引**（长期拖慢加载的冗余结构），存储层面与官方版本**可能不兼容**——从本版切回官方版时，部分索引类数据需重建。**后续将立项提供迁移工具**，方便用户平滑回切官方；在此之前请勿频繁双向切换。
3. **禁回退**：请勿回退到 1.38.1 及以下版本（会话事件日志格式已单向升级，旧版本会拒绝加载——文件本身无损，切勿误删）。
4. **已知现象**（不致命、修复排期中）：①输入框状态行在空间足够时仍默认折叠且展开另起一行、窄态偶发文字溢出；②左栏部分会话时间显示「1个月」未自动翻正。另：工作流「定义」页签未做逐项人工验证（功能已入包，日常使用如遇异常请反馈）。
5. **未验证项**：本版由自动化门禁（构建/测试/完整性/预算）全量把关；主观体验类改动建议升级后按日常习惯使用一两天，异常随时反馈。
