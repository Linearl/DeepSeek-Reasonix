## 概览

本版围绕两条主线：**「卡死与卡顿」家族清零**——上一版定案的「目录扫描拖死主界面」从根修复（预算打满自动降级、解析超时不阻塞），连带治理转录区空白块、概览卡片恒显 '-'、退出误报双 crash 等一批偶发异常；**「子代理全程可看」**——运行中的子代理现在无需开任何实验开关即可在面板看到实时工具调用流（对齐 zcode 的透明标杆），落盘机制同步放开到全部派发方式。另有：effort 等级档位扩到 OpenAI/Anthropic 两家全集七档、远程设备（GC）扫码配对二维码与自拦截修复、一批界面细节打磨。全部改动带自动化回归测试。

## 🚀 主线一：卡死与卡顿家族清零

**你能感受到的**：
- **大会话库启动不再卡死**——此前会话库膨胀（事件总量上 GB）时，启动期的目录扫描会拖住整个主界面直至假死；现在扫描有 120 秒预算，到点未完成的部分自动转入后台队列继续，主界面立即可用；地址解析超时也不再逐个阻塞（每次最多 250ms，超时走快速通道+后台补解析）。
- **转录区不再偶发大片空白**——此前展开/收起右侧栏等宽度变化后，聊天区会顶出大片空白、要选中一段文字才能恢复；现在宽度变化时布局测量即时生效，空白与「选中才恢复」双双消失。
- **受控重启不再误报崩溃**——WebView2 计划内重启此前会被记成一次异常崩溃（一次故障出两条报表），已按「计划内证据」豁免；同时修正了一条重启报表的语义误导。
- **概览页 events 卡不再恒显 '-'**——取数失败现在会留日志、自动重试（3 次），持续失败会明确提示「取数失败」而非裸显示横杠。

**怎么用**：全部默认生效，无需配置。
**原理（1~2 句）**：扫描与解析链全部预算化+超限降级（后台队列续作）；布局测量层补上「宽度变化即发布」通道，缓存不再滞留旧坐标系。

## 🚀 主线二：子代理全程可看（透明标杆对齐）

**你能感受到的**：
- **运行中的子代理工作过程实时可见**——右侧「子」面板点开运行中的子代理，即可看到实时的工具调用流，**不需要再打开任何实验开关**（此前只有开了实验开关的详情视图才可见）。
- **普通派发的子代理过程也落盘**——此前只有工作流方式的子代理运行中会写盘，普通派发要等跑完才能看；现在全程 1.5 秒粒度快照落盘，前台/后台/批量派发一视同仁，重启也不丢。
- **两层保险**——内存实时投影（0 延迟）+落盘流（可靠）互为补充：落盘尚未生成时由内存投影顶上，落盘后自动让位给权威流。

**怎么用**：右侧「子」面板点开运行行即看；与 zcode 的子代理面板形态对齐。
**原理（1~2 句）**：写侧复用工作流已有的周期快照机制放开装载范围；读侧放宽只读通道的运行中限制，失败降级为「尚未落盘」提示不报错。

## 🌐 重点：远程设备（GC）连接两件

- **serve 守卫不再自拦**——此前设备自己的心跳会让自己的提交被 409 拒绝（自己拦自己），现提交携带设备身份、与活跃持有者匹配即放行；其他设备占用写权时的保护语义不变。
- **桌面版生成连接二维码**——设置 → 集成与连接 → 本地服务器服务，新增「扫码连接」区块：展示局域网/Tailscale 候选地址（可切换）+完整连接 URL+复制按钮，GC 端扫码即完成配对；token 认证参数已内置于 URL。

**怎么用**：桌面开本地服务器服务 → 打开扫码连接区块 → GC 相机扫码。
**原理（1~2 句）**：二维码值即网关地址+认证参数（与既有网关校验同源）；候选地址按私网优先排序自动发现。

## ✨ 其他改进（按主题）

**模型与档位**
- **effort 等级档位扩到七档全集**：none / minimal / low / medium / high / xhigh / max——对齐 OpenAI 与 Anthropic 官方档位（按模型代际自动收窄可用范围，不支持的档不会发出去防报错）；编辑模型对话框与快捷菜单预设段同步。

**界面细节**
- 输入框/状态行间距按 zcode 基准收紧（控件 32→28px、壳内边距取紧凑档），折叠/一行化行为零回退。
- 对话版本管理页四个数值列（大小/消息数/副本数等）表头与内容对齐修正。
- 信息栏新增「请求数」「运行时间」两个可开关显示项（设置 → 通用 → 信息栏显示项）；右侧栏「会话指标」卡支持折叠且记忆状态。
- 本地折叠通知（「已省略 N 条早期消息」）补充明确的恢复路径指引（设置 → 存储与路径 → 工作阶段版本与副本）。

**安全与正确性**
- 目标模式（Goal）早停根因链最后一环闭合：工具检查点遇到版本冲突时不再直接取消回合（此前这是早停的实际出口），改为与回合边界一致的受控接管；保存路径补一致性围栏钉族。
- refs 渲染引用值转义补齐（防含引号值破坏标记结构）。

**基础设施**
- fork 特性锚点清单（防合并丢块的自动化核对）完成全量甄别换代：57 处过期条目处置（17 条确认退役删除+40 条换代），恢复绿色可例行运行。

## ⚠️ 升级提醒

1. **覆盖安装**：从旧 fork 版本直接覆盖安装即可，会话与记忆数据正常读取。
2. **上一版（包 87）存储差异条款继续有效**：DAG 事件索引已移除、禁回退 1.38.1 及以下的条款不变。
3. **已知现象**（不致命）：①加载降级发生时后台日志有对应记录（正常行为）；②间距收敛幅度、版本页对齐效果建议升级后过目，观感不合适可反馈调整。
4. **远程联调说明**：GC 端扫码回填后，HttpClientFactory 的 token 注入需幂等（URL 已含 token 不重复注入）；若 Base URL 输入框不接受带参数的 URL，回填时请拆分为地址与 token 两字段。
5. **未验证项**：自动化门禁（构建/测试/完整性/预算）全量把关；主观体验类改动（间距/对齐）建议按日常习惯使用反馈。
