# Reasonix Fork 桌面版 v1.31.3 — Release Notes

> 本版本基于官方 `v1.31.3`，面向**长会话 + 多会话并行 + 成本控制**场景做了一系列 fork 增强：并行写更流畅、会话切换无感、归档更省心、长会话压缩阈值可降到 30% 且保留量随阈值联动、滚动更稳定。数据/会话/记忆目录与官方版完全兼容，**覆盖安装即可，无需迁移**。

## 使用攻略

- 所有 fork 功能均可在 **设置 → 权限 / 通用** 或**会话输入框右上角**找到入口；CLI/TUI 用斜杠命令。
- 安装**覆盖安装即可**，无需卸载、无需迁移数据；已关闭自动更新，未来可随时切回官方版。

## 概览

**Reasonix Fork v1.31.3 — 多会话并行 + 长会话成本与体验优化**

本版本聚焦三件事：**让多会话并行写不互相阻塞**、**让长会话（1M 上下文）压缩更早触发且保留量随阈值联动（降低 DeepSeek 缓存涨价后的输入成本）**、以及**一系列体验修复**（会话切换无感、归档不卡死、滚动稳定、提问定位条不密集）。所有 fork 魔改点均从用户视角描述，含具体用法。

发布日期：2026-08-25（fork 发布）

## ✨ 重点内容（新增）

### 子代理三档委派
运行子代理时可在「保守 / 均衡 / 激进」三档切换，按任务需要调整并行度与工具面，复杂任务更快推进。（#9004）

**用法（桌面版）**：输入框右上角、与「常规/目标/计划」同排，位于其**右侧**，点按「子代理委派」下拉即可切换：
```text
保守（light） · 均衡（balanced） · 激进（aggressive）
```
- 会话**执行中**控件**置灰不可选**（与「常规/目标/计划」一致）；
- 会话**空闲时**切换**即时生效**，并作为**会话级档位持久化**（写入该会话 BranchMeta，重启保留）；
- **新建会话继承全局默认档位**（此前会误回落到「保守」，已修复）。

**用法（CLI/TUI）**：`/subagent-policy light|balanced|aggressive`

**全局默认**：设置 → 通用 → 「新会话子代理档位」；也写入 `config.toml` 的 `[agent].subagent_policy`。

### 并行写入安全检查
同一项目多会话同时工作时，写不同文件不再互相等待。开启后路径明确的文件写入（写文件/改文件/多文件改）并行执行，靠「期望值校验」自动防冲突。（#9213 #9111）

**用法**：设置 → **权限** 页，紧挨「写操作模式」下拉，「**并行写入安全检查**」勾选项：
- 默认**勾选**（安全开启，同一工作区按写入锁串行）；
- **取消勾选**关闭检查，允许并行（同名文件防冲突由「期望值校验」兜底）。

### 长会话压缩阈值可降到 30%（DeepSeek 缓存涨价对策）
DeepSeek 输入缓存命中折扣从 `1/120` 涨到 `1/12`（10 倍），长上下文成本劣势明显。本 fork 允许把**自定义压缩阈值**降到 **30%**（原先最低 65%），让压缩**更早触发**、单次输入更短，从而降低输入成本。（#9158 / #9060）

**用法**：设置 → **Agent** → 「自定义压缩阈值」，输入 30%~85%（默认 80%）。注意：**阈值越低压缩越早**（上下文更小、单次更省，但摘要调用更频繁）；80% 更省缓存复用、但单次接近窗口上限。

**联动改进**：**最近原文保留量随阈值联动**（`窗口 × 阈值 × 20%`）——默认 80% 时保留窗口的 16%（与旧版一致），阈值降到 30% 时保留量相应缩小到 `窗口 × 6%`（1M 窗口约 60k，而非固定 160k），且**绝不会把最近几轮对话折叠掉**（有保底轮次保护）。此前 16% 是固定的窗口比例，降阈值不省保留量；现在真正联动。

## 🚀 改进

### 切换会话无感、秒开
内容已在本地内存的会话，切换**立即显示、无遮罩、无转圈**；缓存完整对话的会话数提升到 8 个，历史正文缓存上限 64 MiB。（秒切 PR 参考上游 #9385）

### 分组内可以归档单个会话
**右键分组内任意会话即可单独归档**，只影响那一个会话；整组归档失败时不再误把分组移除。

### 残留后台任务不再卡住归档
被打断的任务（如脚本关掉桌面版）会正确识别为已停止，不再阻塞关闭/归档。

### 恢复失败的会话不再自动复活 + 可强制归档
恢复失败的会话（超大/写权限 stale）此前每次重启被自动重新拉起、lease 不释放，导致**永远无法归档**（死循环）。现在：
- 恢复失败的会话**不再写入恢复列表**，重启不会自动拉起；
- 右键该话题 →「**强制归档**」（不可恢复），即使归档被活动任务拦截也能强制移入回收站。

### 会话滚动更稳定
长会话历史滚动不再错排/重叠；多行数学公式（`\substack`、`\underbrace`）行距不被挤压。（#9225）

### 右侧提问定位条不再密集
长会话右侧的提问定位横条（QuestionJumpBar）在提问多时挤成一团。现采样上限 120 → 60、`packed/compact` 密度阈值下调，横线间距更大更稀疏，拖动定位更准。（参考上游 #9218/#9219）

## 🔧 修复

- 会话 `meta` 文件损坏（如强制关机）时自动重建，不再卡住保存/关闭（#9155）
- `/compact` 压缩完成后不再一直显示「处理中」转圈（#9231）
- 会话改名/自动起标题后，历史面板立即刷新（#8597）
- 压缩提示文案更新，与实际数字卡片界面一致（#9157）
