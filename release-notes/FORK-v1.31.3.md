# Reasonix Fork 桌面版 v1.31.3 — Release Notes

> 本版本基于官方 `v1.31.3`，聚焦提升日常使用体验：多会话并行更流畅、切换会话无感、归档更省心、滚动更稳定。数据/会话/记忆目录与官方版完全兼容，无需迁移。

## ✨ 新增

### 多会话并行写不再互相阻塞
同一个项目里多个对话同时工作时，写不同文件不再互相等待。开启后路径明确的文件写入（写文件/改文件/多文件改）会并行执行，靠「期望值校验」自动防冲突；即使用户在某个会话里跑 `bash` 或长命令，也不会卡住其他会话的文件写入。（#9213 #9111）

**位置**：设置 → **权限** 页，紧挨「写操作模式」下拉框，找到「**并行写入安全检查**」勾选项：
- 默认是**勾选**（安全检查开启，多个会话写同一项目时按单一工作区写锁串行）；
- **取消勾选**即关闭该检查，允许并行写入（此时并发写同一文件的防冲突由「期望值校验」兜底）。

### 子代理三档委派
运行子代理时可在「保守 / 均衡 / 激进」三档间切换，按任务需要调整并行度与工具面，复杂任务能更快推进。（#9004）

**位置（桌面版）**：输入框右上角、与「常规/目标/计划」同排，位于「常规/目标/计划」的**右侧**；点按「子代理委派」下拉即可在 **保守 / 均衡 / 激进** 间切换：

```text
保守（light） · 均衡（balanced） · 激进（aggressive）
```

**交互细节**：
- 会话**执行中**档位控件**置灰不可选**（与「常规/目标/计划」一致，避免误以为变更会即时生效）；
- 会话**空闲时**切换**即时生效**，并作为会话级档位持久化。

**位置（CLI/TUI）**：在会话中输入斜杠命令：

```text
/subagent-policy light|balanced|aggressive
```

例如 `/subagent-policy aggressive`。

**全局默认**：桌面版在 **设置 → 通用** 的「新会话子代理档位」设置新建会话的初始档位；也写入 `config.toml` 的 `[agent].subagent_policy`。

注意：
- 桌面版的档位是**会话级持久化**的：切换到某档后重启会话仍保留（写入该会话的 BranchMeta），不再回到默认；
- 新建会话**正确继承全局默认档位**（此前会误回落到「保守」，已修复）；
- 旧版本忽略新配置项，向后兼容。

## 🚀 改进

### 切换会话无感、秒开
之前切换对话（尤其切回最近用过的）会先出现一段"加载中"遮罩。现在：
- 内容已在本地内存的会话，切换**立即显示、无遮罩、无转圈**
- 缓存完整对话内容的会话数提升到 8 个，历史正文缓存上限提升到 64 MiB
- 切回已打开过的会话基本无感，接近 Claude Desktop / Codex 的体验

### 分组内可以归档单个会话
之前归档分组内的对话只能整组归档，且会被同组其他正在工作的对话阻塞。现在**右键分组内任意会话即可单独归档**，只影响那一个会话；整组归档失败时也不再误把分组移除。

### 残留后台任务不再卡住归档
之前后台任务被打断（比如脚本关掉桌面版）后，会留下"卡住"的任务记录，导致该会话永远无法关闭或归档。现在已停止的任务会被正确识别，不再阻塞关闭/归档。

### 会话滚动更稳定
向上滑动长会话历史时，已渲染完成的内容不再出现错排/重叠；多行数学公式（如 `\substack`、`\underbrace`）行距也不会被挤压。（#9225）

### 右侧提问定位条不再密集
长会话右侧的提问定位横条（QuestionJumpBar）此前在提问多时挤成一团，难以上手 hover 定位。现在采样上限从 120 降到 60、`packed/compact` 密度阈值下调，横线间距更大、更稀疏，拖动定位更准确。（参考上游 #9218/#9219）

## 🔧 修复

- 会话 `meta` 文件损坏（如强制关机后）时自动重建，不再卡住保存/关闭（#9155）
- `/compact` 压缩完成后不再一直显示"处理中"转圈（#9231）
- 上下文压缩比例下限从 0.65 放宽到 0.30，长会话压缩更自由（#9158）
- 会话改名/自动起标题后，历史面板立即刷新（#8597）
- 压缩提示文案更新，与实际的数字卡片界面一致（#9157）

## 安装与更新提示

- **覆盖安装即可**：本 fork 数据目录与官方版完全兼容，直接运行安装包覆盖现有版本即可，**无需卸载、无需迁移数据**（会话、记忆、技能、配置均保留）。
- **如需回到官方版**：本 fork 已关闭自动更新；未来官方发布更新版本后，点击更新（或重启自动更新）即可回到官方版本，**数据无损**。
- 建议使用前备份：`config.toml`、`.env`（凭据）、`sessions/`、`memory/`、`skills/`、`desktop-projects.json`（每周一次）。
