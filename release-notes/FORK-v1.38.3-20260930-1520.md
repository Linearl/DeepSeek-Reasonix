# Fork v1.38.3-20260930-1520（四批：批八收官+批九首波+总线通道）

> 基线：上一个发布版本 v1.38.3-20260930-1151（增量对照基线）
> 本包焦点：**批八正式收官**（369 选区操作收官件）+ **379 图墙三列修复落地** + **405 冷启动提速** + **批九首波三件** + **总线通道两件**

## ✨ 新特性

- **选区快捷操作**（369）：划选对话文本后出现快捷菜单，支持翻译/解释（划词即用），结果卡可固定/关闭/Esc 退出；默认关闭——实验室开启「选区快捷操作」后生效，关闭时界面与旧版完全一致。
- **任务总线与外部智能体通道**（bus-mcp + bus-m3，默认关闭）：新增 `reasonix bus enroll` 一条命令把会话协作能力（收件箱/发消息/任务卡）开放给受信任的外部编码智能体；内置无头执行池可自动消化派来的任务并回执结果。三层安全门禁：白名单角色才可见、每角色每日配额、全程审计留痕——不配置即完全不存在，日常使用零影响。

## 🔧 改进

- **冷启动/开对话明显提速**（405）：多标签恢复时运行时构建复用（第一个 tab 之后免重复发现阶段）+ 构建错峰（同时最多 2 路并发，激活中的标签优先）——多标签冷启动和大会话打开的等待时间显著下降。
- **批九首波三件**：
  - **395 行内技能双缺陷修复（P1 正确性）**：字符串提交路径的行内技能渲染与 run_skill 产物字节级一致；输入框恢复显示用户键入原文而非拼接路径。
  - **168 MCP 搜索超时治理**：搜索/列表/检查冷启动零网络连接（回归测试钉死）；连接超时报错包含具体 server 名与调参指引；MCP http 传输接入 `[network]` 代理配置；本机回环地址强制直连（修复系统代理劫持本地 MCP 导致挂死的问题）。
  - **186 内置项目节点治理**：侧栏不再出现多余的内置根节点；项目域打开内置根路径自动归位全局域（6 处入口全接线+前端兜底过滤），会话经全局顶区正常可达。
