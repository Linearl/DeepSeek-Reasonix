# Reasonix Fork 桌面版 v1.38.3-20261031-0012 — Release Notes

> 基于 v1.38.3-20261030-1932（包56）以来：快捷指令语义修复+残影根治+builtin 安全收编+拖拽双标识，共 4 件 14 commits。覆盖安装即可。

## 本版内容

- **「!!」不再误触发终端**（1274）：此前输入「!!ls」这类以双感叹号开头的内容会被后端误当成 shell 命令执行（只剥了一个感叹号）——现已在后端四处入口统一拦截：「!!」开头优先走快捷指令分支，未匹配快捷指令时作为普通消息发送；桌面端与 TUI 的提示符显示同步修正，不再显示误导性的 shell 样式。serve 层补防线测试（HTTP 通道「!!ls」放行为逐字原文、单「!」仍 403）。
- **重启后假「运行中」残影根治**（1266b）：装包/重启后部分会话 tab 残留「绿点+已工作 N 分钟」的假运行状态——重启后查无执行体的 tab 自动改标「已断开」徽章；此时继续输入会明确提示「会话已断开，请重新打开」，不再静默把消息塞进死执行体。判定采用持久化锚+控制器活路径双边查，新会话首条消息、stale-binding 自愈窗口均不误伤（6/6 场景测试绿）。
- **21 个 builtin 工具安全收编**（1276）：内置工具里「自己拼路径/自己开 URL」的野路子全部迁到统一安全净化入口（sanitize，filepath.Clean 标准屏障），并落门禁测试——以后新增工具不走该入口直接红。CodeQL 安全扫描的批量告警从源头消除（降面实证随下次 push 的 Actions scan 自然产生）。
- **会话树拖拽双标识**（1267）：拖拽放置提示标准化为业界四分位模型——悬停条目间显示插入线（放到它前面/后面），悬停分组容器显示整体高亮（放进该分组），拖到哪放进哪一目了然。
