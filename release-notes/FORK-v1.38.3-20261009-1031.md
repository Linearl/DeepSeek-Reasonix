## 新功能

- **运行中子代理/命令实时面板**：输入框下新增小图标入口，展开可见当前会话运行中的子代理与后台命令（参考 zcode 同款面板）。
- **群聊式多 Agent 协作视图**：多 Agent 协作过程以群聊视图呈现，AI 团队分工一目了然。
- **子代理进胶囊计数**：前台同步子代理现已被运行胶囊正确计数，不再「跑了但看不见」。
- **MCP 连接状态可配置显示**：MCP 连接状态加入「信息栏显示项」管理，按需开关。
- **新实验特性：唤起新的子会话**：会话内可唤起新的子会话（此前仅 GC 支持主会话形态），默认关闭，实验室开启。
- **异步决策点回访**：后台长任务走到审批点时主动找人，不再原地等待。
- **安全/成本控制开关合并**：心跳空转自终止、循环中性继续注记、等待返回前复查三个开关合并为「安全 / 成本控制」两组，更易找到。

## 改进

- **压缩过程实时读数**：压缩期间显示实时 token 量与吞吐，对齐正常工作时的观感，缓解「压缩中不知道在干嘛」的焦虑。
- **收件箱改进包**：排序/视图控件上移 + 胶囊样式、收发双方文字说明、行 hover 修复。
- **选区快捷操作修复**：选中文本后快捷操作浮卡「开不了」的问题排查修复。
- **复制图标补全**：有引导消息的回合缺失复制图标的问题修复（630 场景补全）。
- **写读路径形态收口**：写读路径形态收口（J）+ 加载观测埋点（E），为后续性能分析铺数据。
- **可观测红线自查**：标识-路径对照自查并入评审惯例（zcode 借鉴 B⑥⑦）。

## 修复

- **锁内磁盘写隐患批处理**：50 处锁内磁盘写结构性归零（单 flusher 队列一次机制覆盖，调用点零改动）。
- **set_target 慢根因处置**：版本切换 set_target 慢的根因修复。
