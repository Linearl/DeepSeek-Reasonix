> 数据/会话/记忆目录与官方 v1.38.3 完全兼容（v3），覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本包以**体验还债**为主题：①**样式 token 化专项**——全局字号设置响应覆盖率从 18% 提到 60%+，圆角收敛 3 档，按钮体系归一（直接回应「设计语言混乱、字号随意」的社区反馈）；②**启动竞态修复**——启动后 tab 未就绪时打的字不再消失（composer 草稿 key 竞态）；③**heartbeat 配置健壮性**——新增 `reasonix heartbeat validate` 校验命令，配置损坏时不再静默清空任务列表（改沿用旧配置+UI 告警）；④**PR 门禁 CI 补厚**。另有上下文窗口核查与多项修复。

## 🎨 界面与样式

- **样式 token 化专项**（833）：高频字号（11/12/13px 三档）迁移到 `--text-*` token，**调全局字号设置的响应覆盖率 18% → 60%+**；圆角收敛为 3 档 token；按钮体系合并统一基类。纯样式归一，迁移前后视觉语义不变。
- **右键菜单补齐**（826 顺带）：项目分组支持右键重命名/解散分组、分组拖拽排序、分组字号加大、折叠标识对齐（方案 A：文件夹图标兼做展开折叠态）。

## 🩹 稳定性与修复

- **启动竞态：输入草稿不再丢失**（825）：启动后 tab 未就绪时在输入框打的字，全部标签加载完成后仍保留（草稿 key 随 hydrate 切换的竞态修复）。
- **agent 包 11 项存量测试失败清零**（822）：归因定案为 719 引入（判定读数钳制误伤），772 域「既有红」说法修正；修法=判定改读 canonical + 删误伤分支。
- **composer 族 2 项预存红排查修复**（828 同批核查）。
- **heartbeat 配置健壮性**（823）：新增 `reasonix heartbeat validate` 命令（配置文件逐字段校验，Human-readable 报错）；配置损坏时**不再静默清空任务列表**——沿用旧配置继续跑 + UI 告警条；保存路径原子写。

## ⚙️ 工程与基础设施

- **PR 门禁 CI 补厚**（829）：PR 面新增四项检查（前端构建/tsc/快面测试/go build+vet）——major 依赖升级破坏构建时 CI 自动拦截，不再依赖人肉本地验证。根因修正：dependabot PR 需 maintainer approve 才跑 CI 的平台机制，改用 pull_request_target + 三层安全收紧。
- **委派度量与文案**（820）：agent 委派行为回合级打点（档位/派发数/步数）；aggressive 档文案改协调者框定。
- **上下文窗口核查**（834）：右侧边栏上下文窗口显示三问核查，显示不全问题本轮修复。
