# Reasonix Fork 桌面版 v1.38.3-20261031-2357 — Release Notes

> 基于 v1.38.3-20261031-1812（包62）以来：**七件行为修复与增强全部滚合**（压缩触发真实用量、相对时间人性化、crash-recovery 仲裁、内容判定对齐、子智能体打开评估打点、心跳 yolo 审批迟到、effort 切换 UI 反馈），另附三份深查报告入库（纯文档）。覆盖安装即可。

## 本版内容

- **压缩触发改用真实用量**（1183）：压缩判断从本地字符估算改为 provider 真实 usage（prompt_tokens 含缓存命中/未命中 + completion），估算偏差不再导致提前或延迟压缩。
- **相对时间人性化**（1299）：界面全部裸秒展示点（最后事件心跳/运行时长/恢复等待/加载等待等）统一走格式化库，「7354 秒」变「2 小时 7 分 51 秒」；含 67 例边界单测。
- **crash-recovery 保存仲裁回归修复**（1294）：恢复路径的保存仲裁按 tl1177 tail-first preview 语义修正 characterization。
- **内容判定对齐**（1295）：sealed schema-2 残余 probe 与 LoadSession.HasContent 同源于 checkpoint 兜底，消除「两判据各答一个事实源」的分歧；顺带退役 ~265 行 DAG 轻扫描死代码（读路径自 tl1227 起无消费方）。
- **子智能体打开 3s 评估**（1293）：打开链路分段计时打点（prepare/rtt/first_out），fast-connect 竞态兜底保证 prepare+rtt 恒覆盖请求窗；打开慢从此可归因。
- **心跳 yolo 审批迟到修复**（1298）：新建会话即落 tool_approval_mode 进会话 meta——心跳任务的 yolo 不再首轮回落 ask 弹审批面板（无人值守死锁源之一）。
- **effort 切换 UI 即时反馈**（1301）：从支持 effort 的模型切到不支持时，力度控件旁即时显示「正在应用推理力度…」过渡态并锁定控件（此前 2.4s 无任何反馈，用户以为没生效）；三语文案齐备。
- **深查报告入库**（1083/1302/1303，纯文档）：投影回退全线深查、Global 泄露机制深查、引导消息拒收复发诊断——三份报告随主线入库，根治修复件已另立（tl1313 等）。
