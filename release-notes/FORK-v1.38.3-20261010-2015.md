# Reasonix Fork 桌面版 v1.38.3-20261010-2015 — Release Notes

> 基于官方 v1.38.3，包含 2026-10-10 20 版（1415）以来的全部更新（9 项功能更新）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本版是一轮**集中修复与体验打磨**：远端接管体验补齐六项细节（状态标记、进度轮询、倒计时双保险）；修掉三个偶发毛病（对话右键不能移动分组、协作标签页偶发空白、设置面板点击后偶发挂起）；提示音不再被浏览器策略拦截；实验室新增标签页管理能力、心跳任务转入后台化。同时仓库工程质量保障上线——每次推送自动跑门禁（类型检查/构建/安全扫描），问题在合入前暴露。

## 🤝 主线一：远端接管体验补齐（六项）

**你能感受到的**：远端接管会话时——等待确认的请求有明确状态标记（不再与运行中混淆）；接管进度有轮询反馈不再黑盒；「让出中」有独立状态不再误显示；路由分两阶段走不再一步到位卡住；倒计时带双重保险（到点与确认都校验）；同会话双开的边界有基准测试钉住。
**怎么用**：远端接管流程内自动生效，无需配置。
**原理**：接管状态机细化（Yielding 独立态）+ 轮询与事件双通道。

## 🔧 主线二：集中修复（三项偶发毛病）

- **对话右键「移动分组」**：会话右键菜单新增移动到分组的入口（此前只能拖拽）；
- **协作标签页偶发空白**：park 失败后标签页不再白屏（等待机制重构，构建完成自动激活）；
- **设置面板点击后偶发挂起**：「点击即发」预取加挂起看门狗，超时自动恢复不再卡死。

**原理**：预取链路加超时看门狗；标签页 park 等待器单一化（防重复堆叠）。

## 🧩 新功能（怎么用）

| 功能 | 怎么用 | 说明 |
|---|---|---|
| **实验室标签页管理** | 设置 → 实验室 | 实验特性支持标签页级管理（逐标签启停视角） |
| **心跳任务后台化** | 心跳运行时自动生效 | 心跳会话的任务执行转入后台，不占前台标签页 |
| **异常自动续轮** | 会话异常中断后自动生效 | 异常后自动恢复轮次继续（附 autopilot 文案修正） |
| **提示音修复** | 提示音场景自动生效 | AudioContext 单例化，修复提示音不响/重复初始化 |

## 🔧 其他改进

- **项目树双现与闪烁修复**：项目树节点不再偶现重复条目与闪烁
- **类型债清理 18 项**：一批历史遗留的类型缺失清零（工程质量项，无行为变化）
- **CI 门禁激活**：每次推送自动跑类型检查/双端构建/安全扫描，问题合入前暴露；代码全库规范化（gofmt 109 文件）；依赖安全升级（x.net HTTP/2 竞态修复）+ 工具链升级

## ⚠️ 升级提醒

1. 覆盖安装即可，数据/会话目录兼容，无需迁移；
2. 存储模式建议停留在 v3（双写/仅 v4 未实测）；
3. **不要回退到 1.34/1.38.1 以下**（schema 2 单向升级，旧构建拒绝加载，文件不损坏）；
4. 实验特性默认关闭，设置 → 实验室逐个开启（推荐配置见安装节）。
