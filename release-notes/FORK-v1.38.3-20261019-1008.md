# Reasonix Fork 桌面版 v1.38.3-20261019-1008 — Release Notes

> 基于官方 v1.38.3，包含上一个时间戳包 **desktop-v1.38.3-20261018-1137** 以来的全部更新（批 42，约 12 项）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本版是**项目栏与全局体验修复批**：①项目栏闪烁与 Global 会话冒泡两类「界面自己动」问题根治；②组内会话拖拽排序真正接线（此前拖了没反应）；③一批界面细节收尾——层级弹窗 z-index 修正、sha512 校验、三语言提示补全、详情弹窗全文查看、实验室条目重组；④按用户指令对历史遗留测试红做专项修复，8 项闭合（含 1 项真实产品缺陷）。全部修复面向日常可见的使用痛点，无数据迁移。

## 📌 主线一：项目栏稳定性

- **项目栏闪烁根治**：会话元数据在写入途中被反复回刷导致项目栏「自己动」——现在源头指纹一致时不重复发布，短窗口内的变更合并为一次刷新，运行中会话的活跃标记按 60 秒桶化更新，不再高频抖动。
- **Global 会话冒泡修复**：Global（全局）会话此前可能错误冒泡到项目列表——权威门控补上兜底校验，渲染前再做一次归档复核，双重防线杜绝错位显示。
- **组内会话拖拽排序接线**：同一分组内的会话此前拖动无效（落位识别缺失，表现为「拖了没反应」）——现在组内拖放直连排序写入并乐观更新位置，跨组与顶层拖排行为保持不变。

## 🔧 主线二：界面细节收尾

- **层级弹窗 z-index 修正**：多层弹窗叠加时的遮挡顺序修正，最上层弹窗不再被截断。
- **会话详情弹窗支持查看全文**：信件类内容此前只显示首行预览，现在详情弹窗可读全文。
- **三语言提示补全**：部分新功能的界面提示此前缺少简体中文/繁体中文/英文之一的翻译，已补齐。
- **实验室条目重组**：实验室开关按主题重新归组，相关条目收拢到对应卡片，查找不再靠翻。
- **文件校验加固**：涉及下载/更新的校验摘要升级至 sha512，抗碰撞性更强。

## 🛡️ 健壮性与测试面

- **capability id 输入加固**：对 AI 工具返回参数做字符级清洗与顺序锁定，恶意/损坏形态的参数不再可能污染会话历史（针对此前调研中发现的坏形态注入面）。
- **后台任务存活 A/B 测试件**：为「切模型后后台任务存活」场景补充了可复现的对照测试基建，后续回归可自动覆盖。
- **构建门禁锚点同步**：分叉完整性核对脚本的 4 处锚点随代码演进同步更新，核对恢复 843/843 全绿；两处历史测试文件补齐依赖绑定。

## 🔩 历史遗留失败专项修复（8 项闭合）

按「预存失败必须分析修复，不能看到也不处理」的要求，对全部历史遗留测试红逐项定性并修复：

- **检查点投影刷新补盘上对照（产品缺陷）**：工具执行检查点此前只按进程内状态刷新，跨进程延迟提交后重启会看到「过期投影不刷新」——现在补上盘上索引版本对照，重启即追平。
- **配置字段渲染补全**：`[serve]` 配置节的 `web_dist` 字段此前写入后会被渲染回写丢键，已补渲染行，配置往返不再丢失。
- **子进程统一安全管线**：删除解析等处的两处原始进程调用点全部迁移到统一管理入口，隐藏窗口、超时与取消行为一致，不再出现无边框闪窗与僵尸进程风险。
- **模型目录元数据补全**：kimi-k2.6 档模型补齐实现能力（并发上限/视觉），模型信息表不再出现零值。
- **测试随机制演进**（4 项）：截断流协议断言更新、中断恢复按当前 400 终态语义更新、模型清单漂移测试对齐、构建复用测试超时阈值放宽到本机真实构建耗时内。
- **1 项登记待修**：超大对话的摘要收缩链在阈值放宽后暴露一处真实断言（历史即存在，与本批改动无关），根因已定位到「摘要输入预折叠缺失」，归入压缩专项，清单见内建预存失败登记。

## ⚠️ 升级提醒

1. **覆盖安装即可**，数据/会话/记忆目录与官方版兼容，无需迁移。
2. **存储模式建议维持 v3**：v4 可实验开启但 v3 记录会滞后；存储设置里的迁移可随时把会话迁回 v3（先自动备份）。
3. **不要回退到 1.34 / 1.38.1 以下**——事件日志 schema 单向升级，旧构建会拒绝加载（文件本身不损坏）。
4. **已知现象**：切换超大会话仍需 1~3 秒（专项排期中）；`internal/boot` 等少数包的全量测试在本机超过 go test 默认 600 秒上限（历史既存，已确认与本批改动无关，测试面治理排期中，不影响使用）。
5. 未验证项：部分包未跑 `-race` 全量（按既有口径）。
