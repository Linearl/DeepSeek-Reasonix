# Reasonix Fork 桌面版 v1.38.3-20261015-0548 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261014-1958** 以来的全部更新（批 27+28 十七件，800s 夜战批）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。

## 概览

本版是 **夜战大批（十七件）**：①四类卡死/误判根治（events 折叠失效、save 锁互等、wait 工具误判卡死、切模型被后台任务拦）；②sentinel 穿透封堵（24 路径，实验开关默认开）；③新建会话自动开轮、跨会话折叠稳定性、capability 纠错等一批可用性修复。

## 🔒 稳定性根治（四件）

- **events 折叠失效根治**（tl884）：超大 transcript 下 events 折叠失效，改为空闲期自动升级 compact 兜底。
- **save 锁有界化**（tl885）：跨会话 save 锁互等（实测 791ms→11973ms 恶化）——确认锁粒度 + 缩短锁持有的机制级治理。
- **wait 工具误判修复**（tl879）：等长阻塞型 wait 工具此前被 doctor silent 判据误判为「会话疑似卡死」——判据补活性信号，不再只看 ledger 静默。
- **切模型不再被后台任务拦**（tl890）：turn 已结束时后台任务不应阻止切模型（此前 running=false 仍拦，用户被迫停掉 demo 服务器）。

## 🛡️ sentinel 穿透封堵

- **三面封堵**（tl895）：`bash -c` / `sh -c` / `eval` / `sudo` / `env` 内层命令逐段重查（shellparse AST 复用，深度封顶 4-8）、子 shell `(…)` 与 `{…}` 展平重查、git 判定跳过 `-C`/`-c`/`--git-dir` 全局选项。共 24 路径封堵；挂实验开关默认开，P50 开销 +2.4~10.5µs。
- **展示提醒件**（tl896）：禁用硬规则时打 slog WARN 并在会话内通知一条（消除「静默关底线」这一最危险配置态）；配置回写不再丢已禁规则。

## 🧩 可用性修复

- **新建会话自动开轮**（tl887）：无 runtime 的新会话此前无法自动开轮（空闲开轮桥 target 只含 tabs + detached runtimes），与「收信会话后台跑」口径不符。
- **跨会话消息折叠稳定**（tl811）：超高消息部分时候不折叠的问题逆向修补。
- **capability 纠错提醒**（tl877）：错误返回引导到正确用法（catalog 真名 / 单行 JSON / 参数封装约定）。
- **readBack 默认值放宽**（tl875）：`edit_file` 的 readBack 参数随日志教学态放宽（此前默认 false，模型不主动调用）。
- **longtask 稳态优化**（tl861）：围绕 React commit 链热点与几何读取缓存化削减稳态长任务。
- **ask 卡片醒目度**（tl860）：剩余秒数加大加色、接管按钮提为主按钮级视觉权重。
- **项目分组入口补全**（tl881）：树空白右键与工具栏补「新建分组」入口。
- **opencode go effort 三路由**（tl880）：preset 补 reasoning protocol 声明。
- **todo 三态文案**（tl893）：任务面板「当前会话暂无任务」区分空态与封存态。
- **分组嵌套后端片**（tl892A）：会话分组支持子分组的后端能力（B 片随后续版本）。
