# Reasonix Fork 桌面版 v1.38.3-20260920-1150 — Release Notes

> 本版本基于官方 `v1.38.3`，包含 `desktop-v1.38.3-20260916-1205` 以来的全部更新（约 187 个提交）。
> 数据 / 会话 / 记忆目录与官方版完全兼容，**覆盖安装即可，无需迁移**。
> 命名说明：本 fork 是官方 1.38.3 的增强版；上游后续版本（1.38.4+）处于桌面端大迁移阶段，稳定前**不追新基线**，修复与新特性以时间戳包 + 实验特性的方式持续提供。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本版本两条主线：

1. **大会话不再卡**：几百 MB 的大对话，打开从最长 71 秒降到 1 秒上下（**23 倍**），切换标签页的卡顿与「越用越慢」同步治理。
2. **多会话协作上线**：会话之间可以直接对话、互相派活；会话管理（重命名、移动分组）补全；发信可靠性整体加固。

另有：实验室改版、性能监控、上下文压缩质量、一批 agent 稳定性修复。

---

## 🚄 大会话：打开、切换不再卡

以前，几百 MB 的大对话打开要 **71 秒**、切换标签页卡 8–10 秒、同一个损坏日志还会反复阻塞其它操作。现在：

- **打开回到 1 秒上下**（实测 **23 倍**提速）——只加载最近的消息，更早的历史翻上去再补，不会一次全读；小对话行为完全不变。
- **读取更快**——修复了「每次打开都重建一遍索引」的浪费，大会话的重复读取不再成倍放大。
- **快速浏览不影响数据安全**——翻看历史不会改动会话内容；任何拿不准的情况都会自动回退到完整加载（宁慢不装假）。
- **坏日志不再反复卡住全局**——有问题的会话日志只处理一次并记住，不再每次访问都阻塞其它会话。
- **切换标签页更顺**——切换时的辅助数据并行获取；实验室新增「缓存大小调整」，常驻会话数量与缓存上限可按机器配置调。
- **超长对话不会再「写不进也读不了」**——到达上限时自动整理，不需要手动处理。
- **新增性能监控**——内存、磁盘写入、关键文件大小持续采样，慢了能从日志直接定位环节。

## 🤝 多会话协作

会话之间可以直接沟通协作，全程在 Reasonix 内完成：

- **会话互相派活与回信**：A 会话可以把任务交给 B 会话，B 完成后回信汇报；每个会话在通讯录中可寻址。
- **会话管理补全**：**重命名会话**、**移动会话到分组**、创建协作会话时**携带首条指令**、**指定模型**（避免同名模型跨端点歧义）。
- **发信可靠性四修**：发信方身份自动登记、幽灵项目重建死循环修复、新会话权限继承、回信引导（接收方每封消息尾部都能看到「怎么回信」）。

## 🔧 其他改进

- **实验室改版**：实验特性按分组导航，更好找。
- **内置项目根可移出侧栏**：global-workspace 内置项目节点不再「永久占据」。
- **待处理引导消息**：多条短引导合并注入，减少打断；复用输入框查看/编辑全文 + 草稿暂存。
- **上下文压缩质量**：Trace-as-State 改造，保留思考片段，压缩不再丢关键上下文。
- **资源治理**：预算收拢 + preview/DO 语义落地。
- **Agent 稳定性**：todo_write 串行校验死锁修复、中断收敛（ask 答复后自动续跑 / 空意图提醒 / 就绪度自动补证）等。
