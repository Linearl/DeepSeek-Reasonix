# Reasonix Fork 桌面版 v1.38.3-20261010-1415 — Release Notes

> 基于官方 v1.38.3，包含 2026-10-10 19 版（0045）以来的全部更新（25 项）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本版三件事：**打开会话与翻历史明显变快**（切到有驻留标签的会话首响从秒级冷读降到毫秒级读取，长会话翻更早消息按需补拉不再整页重载）；**一批偶发毛病集中修掉**（会话名偶现错乱、标签页打开空白一两分钟后才自愈、中断残留的工具调用面板不再长期挂着、保存风暴治理）；**实验室界面彻底重构**——全部实验特性改为数据驱动布局（首版分组定稿落地），并新增**轨迹视图**（时间线总览+记录检查器，实验特性）、**信件中心布局重排**、**快捷指令管理面板加大一倍以上**。

## 🚄 主线一：打开与浏览更快

**你能感受到的**：
- **切回刚看过的会话不再卡顿**：历史最新页有暖缓存，切 tab 首响从冷读降到毫秒级；空闲时自动预取其他标签的最新历史，轮到你点时已是热数据；
- **打开正在跑的会话立即看到新内容**：此前切到一个被后台唤醒的会话，看到的可能是一两分钟前的旧画面（要等后台自愈），现在打开时立即拉取最新历史并就地刷新——本版把这类「打开空白/旧画面」的变体全部钉住（五门测试矩阵）；
- **长会话翻更早消息更稳**：按页增量补拉，失败自动退避重试；
- **转录区渲染减负**：超长会话只对可见窗口做完整渲染，滚动不再越滚越卡（>500 轮场景实测不卡）。

**原理**：历史最新页加缓存与空闲预取；打开路径识别「轮次已生长」的旧快照并强制对齐最新。

## 🤝 主线二：可靠性集中修复

**你能感受到的**：
- **会话名不再偶现错乱**：自动标题不再覆盖你手动改过的名字；会话目录刷新时同步推送注册表信息；
- **中断残留自动清场**：上一轮被中断的工具调用记录，在你发出下一条消息时按「忽略它、继续走」自动结算收场，面板折叠条不再拖过一轮；（本体仍可在当轮内白名单/重试/手动处理）
- **保存风暴治理**：长时间高频保存的会话，重复快照自动合并、按实测保存耗时自适应退避——磁盘写压力显著下降（单次保存实测 0.7~1.3 秒的场景不再被固定节拍成倍放大）；
- **收件箱暂停状态可追溯**：手动暂停与系统自动暂停区分标记，自动暂停在条件满足时原子恢复、不误碰手动暂停；
- **等待确认不再显示为运行中**：标签页小圆点与项目栏活跃状态语义统一——转圈只在真的在跑，等待你确认时是另一种安静状态；
- **心跳任务轮换常态化**：长时间运行的心跳会话按资格矩阵自动轮换接力（复用会话、阈值判定、重试上限），不再长期占用同一会话。

**原理**：turn 结束时按开轮前快照结算遗留记录；保存链记录实测耗时驱动退避；标题以注册表为权威源。

## 🚀 主线三：新功能与界面

| 功能 | 怎么用 | 说明 |
|---|---|---|
| **轨迹视图**（实验） | 设置 → 实验室开启后，标题栏出现 转录｜轨迹 切换 | 时间线总览（耗时/分段/可拖选聚焦）+ 点行开记录检查器（实测时长、输入输出分节）；懒加载不拖慢启动 |
| **长历史窗口化** | 打开长会话自动定位到尾部 | 只渲染最近 12 轮窗口，向上翻按需扩展并保持阅读位置 |
| **信件中心布局重排** | 左下角收件箱 | 按你拖拽定稿的顺序：标题行 → 维护行（保留期/清理条件/立即清理）→ 视图工具条 → 分桶过滤 |
| **快捷指令管理面板加大** | 设置 → 快捷指令；或点 composer 菜单「添加快捷指令」 | 根治弹窗被压在 440px 的老毛病（此前宽度设置从未真正生效），现按 1100px 渲染；「添加」直接呼出完整管理面板（搜索/行内编辑/禁用/删除） |
| **压缩摘要经济模型**（实验） | 设置 → 实验室 → 上下文治理卡 | 压缩摘要可指定走更便宜的模型，产物跨模型有效——长会话压缩成本下降 |
| **心跳轮换开关**（实验） | 设置 → 实验室 | 与既有心跳配置同一张卡；默认开 |
| **steer 消息不再重复显示**（协作） | 跨会话消息 | 已发出待下一轮处理的引导消息折叠为状态占位，正文只在一处完整显示 |
| **实验室界面数据驱动** | 设置 → 实验室 | 全部分组/卡片/徽章布局改由配置文件驱动，后续调整不再动代码；首版分组按六点定稿落地 |

## 🔧 其他改进

- **流式卡顿有结论了**：经三分定论，卡顿主因是本机网络出口异常（非模型服务端）；超限与卡顿无因果关系——附带落地「有界尾部窗口」防线，压缩失败不再回退全量转录
- **中断记录治理**：长命令产物不再「先出现后消失」；实时压缩截断前先盖章主题行
- **静默降级全面可观测**：回滚失败、标题索引写失败、检查点恢复失败、主题/标签页配置损坏等此前只吞错误的路径，现在都有日志与告警（损坏文件先备份再处置）
- **存储面板行级处置信息**：每行显示可回收空间与「修复无效」标记，点击前即可判断值不值得清；事件日志增长速率预警（>20MB/小时提醒）；单日数百行的重复告警限频
- **标签页 autopilot 徽章修复**：autopilot 档不再错显示为红色 YOLO 徽章（橙色正确显示并优先级压过 YOLO）
- **servepool 项目名碰撞消歧**：同名项目自动加路径短哈希后缀，归属路由按根目录精确匹配
- **use_capability 参数错位自愈**：把 capability_id 误放进参数体内时自动提升到顶层（过校验才放行，静默自愈并计数），错误提示直接指认正确层级
- **安全巡检自动化**：仓库接入 gitleaks（密钥扫描，周度全量兜底+每次推送增量）与 AI 安全审查草案（标签触发）——随本版推送自动启用
- **一键分析补强**：折叠条 turn 结束即消失的生命周期契约测试钉住

## ⚠️ 升级提醒

1. 覆盖安装即可，数据/会话目录兼容，无需迁移；
2. 存储模式建议停留在 v3（双写/仅 v4 未实测）；
3. **不要回退到 1.34/1.38.1 以下**（schema 2 单向升级，旧构建拒绝加载，文件不损坏）；
4. **实验室界面布局已数据驱动化**：回退旧构建时，本版新增/重排的分组将回到旧布局（配置不识别则忽略），已开启的开关状态不受影响；
5. **本版新增两个 CI workflow 随推送启用**（gitleaks 每次推送扫描、AI 安审按标签触发），仅影响仓库，不影响本地使用；
6. 实验特性默认关闭，设置 → 实验室逐个开启（推荐配置见安装节）。
