# Reasonix Fork 桌面版 v1.38.3-20261010-1415 — Release Notes

> 基于官方 v1.38.3，包含 2026-09-27 版本以来的全部更新（约 365 项更新合并）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本版集中解决三层问题：**跨会话消息投递的一整类可靠性问题**（偶发丢失、重复投递、静默不唤醒、收件箱显示异常）——收件箱面板从此全面可用；**切换与打开的速度**（切模型/档位从 10 秒以上降到 3 秒级别；切回看过的会话首响从秒级冷读降到毫秒级）；**界面卡死误报治理与保存风暴治理**。新增会话图墙、收件箱面板、子代理详情面板、**轨迹视图**等一批功能；**一键分析全面升级**（卡顿可分析、进度可见、崩溃后一键恢复）；**安全告警清零**、仓库接入密钥扫描与 AI 安全审查；实验室界面完成数据驱动化重构。

## 🚄 主线一：消息投递可靠性大修

**你能感受到的**：给忙碌中的会话发消息不再丢失；重启后不会收到重复的引导消息；空闲的会话收到消息约 30 秒内自动开始处理（此前可能永远沉默）；收件箱面板不再「时好时坏」——读取失败会明确报错并给恢复按钮，而不是假装「暂无信件」。**收件箱读取速度从分钟级降到秒级**（长会话多项目场景此前一次面板读可能卡 18 分钟以上，根因已修）；给会话的消息有时收不到回应的断链问题已修。
**怎么用**：收件箱在左下角邮箱图标；失败提示旁一键恢复；空闲自动处理默认行为无需配置。
**原理（1~2 句）**：消息写入改为一次完成、忙时自动排队；投递前查重避免重复送；空闲会话收到消息自动开工，失败自动重试数次。
**⚠️ 行为提示**：短时间内**重新发送完全相同的内容**给同一会话，会被自动合并为一条（防重复投递的保护）——如需重发请稍作修改。
**本版新增（批 20-21）**：手动暂停与系统自动暂停在收件箱里**区分标记**，自动暂停在条件满足时自动恢复、绝不误碰你手动暂停的那条；跨会话的引导消息**不再重复显示**——已发出待下一轮处理的折叠为一行状态占位，正文只在一处完整展开。

## 🤝 主线二：协作与多会话体验

**你能感受到的**：后台任务完成会自动「叫醒」所在会话继续干活；停止按钮分三级（普通→升级→强制）覆盖全部场景；失败消息可一键重发；给谁的消息、谁发来的有下拉筛选；子代理完成后的确认提示不再卡住界面；**手动拖拽的会话顺序在刷新/新会话活动/重启后保持不变**；**左侧栏不再闪现「正在修复/稍后重试」等一闪而过的状态行**（持续 2 秒以上的真实修复仍正常显示）。
**怎么用**：停止按钮点击箭头展开三级；重发按钮出现在失败消息旁。
**原理**：后台任务完成后自动通知所属会话继续；排序持久化与显示层口径对齐；瞬态状态行去抖。
**本版新增（批 20-21）**：**等待确认不再显示为运行中**——标签页小圆点与项目栏活跃状态统一口径，转圈只在真的在跑，等你确认时是安静状态；心跳任务在长时间运行时按资格自动**轮换接力**（复用会话、阈值判定、重试上限），不再长期占用同一个会话。

## 🚀 主线三：一键分析全面升级

**你能感受到的**：
- **卡住也能分析**：会话卡顿检测弹窗直接给分析入口（不再只针对崩溃）；
- **进度实时可见**：分析会话有名字、有实时进度，不再是黑盒等待；
- **崩溃后一键恢复**：真实崩溃下次启动主动弹分析横幅，不再静默上报；
- **诊断会话统一归档**：一键分析创建的会话一律建在 Global 下，不再落进当前项目，也不再要求先展开某个项目；
- **弹窗观感统一**：分析/崩溃弹窗全中文化，与卡顿弹窗同一套观感；
- **分析不阻塞**：分析过程中可折叠弹窗继续其他操作。

**怎么用**：会话卡住或崩溃后，点弹窗「一键分析」；进度与结论在自动创建的分析会话中查看。
**原理**：分析管线共享同一条会话创建与进度事件链；诊断会话归档到全局作用域。

## ⚡ 主线四：速度与资源

**你能感受到的**：
- **切换模型 / reasoning 档位**：此前需要 **10 秒以上**，现在 **3 秒级别**（不再重建请求管线）；
- **切换会话/标签页**：此前 **20 秒以上**（长对话 + MCP 场景），现在 **3 秒级别**（跳过重复的全量加载）；磁盘繁忙时切 tab/模型不再出现全应用卡顿（锁内磁盘写结构化归零）；
- **启动**：文件系统探测限时 0.25 秒（此前网络路径异常可卡 21 秒）；
- **内存占用显著下降**：关闭会话立即释放其缓存，多开会话内存不再持续攀升；内存异常增长可一键抓取分析档案；
- **图片读取恢复稳定**：移除了图片引用化存储实验机制，各模型读图稳定；
- **压缩不再整单失败**：长会话压缩超限时保留部分进度继续；
- **上滑加载更早消息不再失败**：加载偶发失败自动退避重试，不再把「加载失败」横幅抛给用户；
- **Windows 不再弹黑色控制台窗口**（MCP 子进程启动根修）。

**原理**：请求管线按会话冻结+按请求覆盖；加载路径加缓存层；子进程启动隐藏控制台。

## 📈 主线五：打开与浏览更快（批 20-21）

**你能感受到的**：
- **切回刚看过的会话不再卡顿**：历史最新页有暖缓存，切 tab 首响从冷读降到毫秒级；空闲时自动预取其他标签的最新历史，轮到你点时已是热数据；
- **打开正在跑的会话立即看到新内容**：此前切到一个被后台唤醒的会话，看到的可能是一两分钟前的旧画面（要等后台自愈），现在打开时立即拉取最新历史并就地刷新——本版把这类「打开空白/旧画面」的变体全部钉住（五门测试矩阵）；
- **长会话翻更早消息更稳**：按页增量补拉，失败自动退避重试；
- **转录区渲染减负**：超长会话只对可见窗口做完整渲染，滚动不再越滚越卡（>500 轮场景实测不卡）；打开长会话自动定位到尾部，最近 12 轮窗口化渲染，向上翻按需扩展并保持阅读位置。

**原理**：历史最新页加缓存与空闲预取；打开路径识别「轮次已生长」的旧快照并强制对齐最新。

## 🔒 主线六：可靠性集中修复（批 20-21）

**你能感受到的**：
- **会话名不再偶现错乱**：自动标题不再覆盖你手动改过的名字；会话目录刷新时同步推送注册表信息；
- **中断残留自动清场**：上一轮被中断的工具调用记录，在你发出下一条消息时按「忽略它、继续走」自动结算收场，面板折叠条不再拖过一轮；
- **保存风暴治理**：长时间高频保存的会话，重复快照自动合并、按实测保存耗时自适应退避——磁盘写压力显著下降（单次保存实测 0.7~1.3 秒的场景不再被固定节拍成倍放大）；
- **流式卡顿有结论了**：经三分定论，卡顿主因是本机网络出口异常（非模型服务端）；超限与卡顿无因果关系——附带落地「有界尾部窗口」防线，压缩失败不再回退全量转录。

**原理**：turn 结束时按开轮前快照结算遗留记录；保存链记录实测耗时驱动退避；标题以注册表为权威源。

- **并发会话断链修复**：上滚加载更早历史不再因并发分支缺失而无法回溯
- 侧栏闪现假子项修复；崩溃观测增强（LocalDumps + 生命周期噪音门实验）

## ⚠️ 升级提醒

1. 覆盖安装即可，数据/会话目录兼容，无需迁移；
2. 存储模式建议停留在 v3（双写/仅 v4 未实测）；
3. **不要回退到 1.34/1.38.1 以下**（schema 2 单向升级，旧构建拒绝加载，文件不损坏）；
4. **本版含实验开关合并/旧键清理，也是单向的**——若回退旧构建，被合并的实验开关会回到默认态，需重新开启；
5. **实验室界面布局已数据驱动化**（批 20-21）：回退旧构建时，本版新增/重排的分组将回到旧布局（配置不识别则忽略），已开启的开关状态不受影响；
6. **本版新增两个 CI workflow 随推送启用**（gitleaks 每次推送扫描、AI 安审按标签触发），仅影响仓库，不影响本地使用；
7. GC 手机客户端相关功能（接管倒计时）为配合件，完整体验待 GC 版本发布；
8. 实验特性默认关闭，设置 → 实验室逐个开启（推荐配置见安装节）。

## 安装

- **推荐方式**：下载 Release 资产 `reasonix-desktop-amd64-installer.exe`（+便携版），**覆盖安装即可**——数据/会话目录兼容，无需迁移；
- 进阶：通过 **ll-update 技能**一键完成新版本下载与切换（**随包内置**，无需手动安装）；
- **实验特性推荐配置**：见 [FORK-实验特性推荐配置.md](./FORK-实验特性推荐配置.md)。
