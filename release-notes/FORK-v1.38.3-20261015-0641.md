# Reasonix Fork 桌面版 v1.38.3-20261015-0641 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261015-0548** 以来的全部更新（批 29 收尾两件）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。

## 概览

本版是 **批 29 收尾（两件）**：①710 类病灶体量哨兵——会话文件与 events 达阈值时主动告警并给出转线建议；②项目分组支持任意层级嵌套的 UI 片（递归渲染 2→64 层）。

## 🚨 体量哨兵

- **710 病灶体量哨兵**（tl886）：transcript 与 events 文件达阈值时打 WARN、给出转线建议并输出中断协议 handoff——把「会话大到不可用」从事后救火变成事前可见。

## 🗂️ 分组嵌套 UI

- **任意层级嵌套**（tl892B）：侧栏分组右键「新建子分组」，递归渲染从 2 层提到 64 层；拖拽支持三分位落点，删除分组带级联确认；264+ 断言覆盖。同时为 agent 提供会话整理能力（移动到分组/排序/重命名）。
- **合并后修正**：与 892A 绑定面 9 处类型收敛、两处 arity 按生成物修正（纯 TS 零运行时）；硬编码 rgba 换 theme token。

## 📥 获取

- 安装包：`desktop/build/bin/reasonix-desktop-amd64-installer.exe`（覆盖安装）
- 构成：886 + 892B 两支 + 合并后修正两笔，收口于 `f172a6e02`
