## 概览

本版两件事：**模型切换下拉的条目终于显示模型名而不是连接名**（此前自定义端点下每个模型都错显成端点名、同组还重复两条）；**一批依赖安全告警清零**（含 2 个 GitHub Actions 工作流与 2 组 Go 依赖升级）。

## 🐛 修复

**你能感受到的**：
- **模型切换下拉的条目名称修正**——你之前截图那种「MiMo TP / GLM CP1 / 中转1、中转2 每个条目都显示成端点名、同组重复两条」的情况，现在条目正确显示各模型自己的名称，连接名只出现在分组头；选择后生效的模型本来就是对的，现在**看到的和用到的一致**了。
- **目录扫描饱和告警的日志不再打印完整路径**（安全扫描残留的一处脱敏补漏）。

**原理一句话**：模型列表后端返回时把连接的显示名误盖进了每个模型条目，前端只是照实渲染——修在后端喂数据处，前端零改动。

## 🔒 安全

- **依赖升级把仓库安全面四个口径全部清零**（issue / PR / code-scanning / dependabot 告警均为 0）：hono 升 4.13.18（3 个在线服务，修复 CVE-2026-126355 等一组 CSRF/路径问题）、astro 升 7.4.12（文档站 XSS），加上 GitHub Actions 工作流与 Go 依赖组升级。
