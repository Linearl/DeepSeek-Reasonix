# Reasonix Fork 桌面版 v1.38.3-20261029-0133 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261029-0115** 以来的全部更新（2 项滚合：tl1227 + tl1220）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。⚠️ 本版含一次性数据迁移（DAG 索引退役），首次启动自动执行、有备份可回滚。

## 概览

本版是 **DAG 退役主线第二阶段批**：①存量 DAG 索引一次性无损迁移+读侧单路径化（296 个会话全量校验零失败）；②DAG 存量观测计数落地（普查 CLI+nil_cache 计数）。

## 🗄️ DAG 索引退役实施（tl1227，用户拍板不等退场条件）

- **存量一次性迁移**：全部旧会话的 DAG 索引（旧版会话事件图索引）一次性转换为扁平结构，全库 296 个 DAG 校验 0 失败（含 160MB 大件）；每个文件留 `.dagbak` 备份侧车，可单文件回滚。
- **读侧单路径化**：读会话不再判断「是否 DAG」，只走扁平路径——消除双路径维护成本与「同一语义两个真相源」隐患。

## 🔭 DAG 观测计数（tl1220）

- **普查 CLI**：`reasonix dag-sessions` 一条命令盘点存量 DAG 会话（实测存量 198 本）；归档分类器顺带修复 bufio 预读缺陷。
- **nil_cache+大文件组合计数**：V4 投影层 nil_cache 且 log_bytes>32MiB 的组合计数落地，为后续内存治理提供观测面。
