# Reasonix Fork 桌面版 v1.38.3-20261101-0936 — Release Notes

> 基于 v1.38.3-20261031-2357（包63）以来：**两批十四件修复全量滚合**——P0 深查组修复（引导消息拒收/终止失效/投影回退）+ 安全审计批次六单元（zstd 归档损坏/webfetch/审批旁路等）+ 会话管理批量面。覆盖安装即可。

## 本版内容

### 用户高频痛点修复

- **引导消息拒收修复**（1303）：跨会话引导消息不再被「非活跃 turn」静默吞掉——exact-turn 拒绝改走 queued_followup 排队并给「已排队」事实文案；未注入的引导消息补 Notice 可感知可重发；steer 受理后无注入加监督观测。
- **turn 无法终止修复**（1304）：停止按钮修复——取消请求不再把按钮锁死（可重入幂等已全码验证）；首按即武装 30 秒自动升级阶梯（L1→L2→L3 force）；后端 cancel==nil 四处静默 no-op 全部改可区分回执；796/1288 自愈守卫扩到前台普通会话（无人值守卡死可自愈）。
- **会话管理批量面**（1305）：delete_session 支持批量（targets 数组+分组/标题/不活跃天数谓词+保护阶梯+dry-run 影响报告）；manage_sessions 增 archive 动作；**trash 后补发 metadata 刷新**（侧栏僵尸条目根治）。

### P0 深查修复

- **超窗会话自救**（1083②③④）：压缩摘要输入解耦（pressure 下开分块道+摘要模型 401 自动换道）——「越大越压不动」恶性循环断根；Diet 通路前置改绑「可校验物化转录」——DAG 退役后对所有新会话结构性失效的救命通路重接（tl1173 以来新会话全受益）。
- **压缩状态**（1083②顺带）：snapToRuneBoundary 潜在 panic 修复。

### 安全审计批次（六单元，全部带复跑验收读数）

- **zstd 归档物化四连修**（1318，P0 数据完整性）：归档头/正文共用同一 bufio.Reader（防预读窗丢 64KiB——tl1220 实测丢 65,385B 的根因）；解码器池化改每流独占防并发互踩；临时文件随机名+有界重试防并发截断；**新增字节全等往返测试+8 并发验收**。
- **webfetch 两修**（1319）：Transport 按 proxyURL 缓存复用（修连接与 goroutine 泄漏）；proxied hostname 本地 SSRF 预检（尽力校验+失败可检索告警，保 GFW 场景代理解析不回归）。
- **审批旁路闭合**（1320）：shellsafe 输出重定向参数（uniq/less -o/diff --output 等）改判写操作；凭据读黑名单改模式匹配（.env 前缀族+常见凭据文件 11 族整族拦截）。
- **provider 三修**（1321）：确定性连接错误（证书/DNS/407）不再重试 10 次虚报计数；responses SSE 解码失败留痕（200 错误页不再吞真错）；anthropic 流终态 flush 未关闭 tool_use 块防整块丢失。
- **订阅短读+权限竞态**（1322）：增量读短读不再丢事件；「始终允许」策略写入加锁（修与并行判定读的竞态丢规则）。
- **low 五件**（1323）：doctor 报告错误留痕/collabchannel 取消守卫 fail-closed/webfetch 空 IP 守卫/新建会话 model 实参对齐/effortApplying 定序断言修正。
