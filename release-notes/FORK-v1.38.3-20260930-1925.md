## 本包新增（B3 内存战役 + 布局一致性）

### 内存战役（B3 链，根治长时运行内存膨胀）

- **detached runtime 闲置释放（O4）**：后台会话跑完且闲置 N 分钟后自动卸载 runtime（释放 DAG 状态/records 驻留，会话文件保留，重开即重载）——此前 detached 会话永久驻留到进程退出（实测 533MB/h 单调爬升），本修复后长时运行内存不再膨胀。设置项 `detached_idle_release_minutes`（默认 0=不释放，可配置闲置阈值）。
- **DAG 折叠检查点（O2）**：会话日志的压缩事件新增持久检查点（`<log>.dagckpt`），冷读只解码检查点+尾部增量，跳过被覆盖前缀的全量重放——预期 hydrate 提速 60-80%。默认关闭（实验室「DAG 折叠检查点」），开启后装机 grep `agent: dag checkpoint hit` 可确认生效。
- **runtime 复用（363A）**：同 root+model+effort 的新对话共享已建 runtime——热路径新对话提速，实验室「runtime 复用」开关。
- **MCP 阶段遥测（363B）**：boot 的 mcp 阶段逐 spec 输出耗时拆解+排队量化——为后续优化提供归因数据。
