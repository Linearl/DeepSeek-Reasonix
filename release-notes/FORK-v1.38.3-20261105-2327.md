## 缺陷修复

- **「切换到此版本」静默无效根治**（tl1430，用户实测面）：tl1280 下线 in-log head 慢车道后该按钮走死路（丢 id+假事件+return nil）。现副本行改传完整路径走**采纳语义**（ResumeSessionForTab 热切+落 preferred 重开持久）；工作中的 tab 明确拒切；新增 `head_switch` 事件落盘且**旧文件字节不动**（append-only）；回放兼容钉死。附带：events 处理三层语义落地。
- **归档自锁误判外部占用**（tl1429，17:55 装机现场续作）：新增锁登记面（kind/时刻）；终局判定改「OS 锁被拿 ∧ 登记表无条目」才算外部；本进程强放可撤登记在册句柄；`holder_class` 枚举化（pid=0 且登记命中=self_lock，不再恒 unknown）。**边界如实说明：17:55 现场是否确为自锁未证实，装包后复现看 holder_class 定案。**
- **删除确认后静默无反应**（tl1414，Windows 大小写折叠不一致）：扫描面真实拼写 vs 删除门折叠拼写，containment 字节级比较拒删静默；整对话删键错位假成功。三层修+全路径 slog 六处+删除三入口与版本删除 toast 可见化。
- **切 tab 16.6s 冻结**（tl1416）：读侧块坐标缓存按 key 分片失效（切 tab 风暴 fullScans 零增量断言）+写侧回写环防环闸（50 行风暴=2 增量 1 渲染）。
- **群聊未 @ 全员群发**（tl1406，用户四条裁决）：fanout 三分支（显式 @→仅被 @者/未 @→仅副管理员/无副管理员→零投递+提示）；@ 解析面补齐；channel_send 描述与 queuedFor 同步真实路由（有副管群报 1 不再报 3）；风暴回环钉死。
- **autopilot 高危接管必失败**（tl1408）：takeover 通道接入 high-risk；**接管=倒计时挂起无限等**（非单次延长）；不接管 15s 安全阀不变；前端按钮真生效（后端 false 回滚根因消除）。
- **50 处裸错误 toast 成片**等呈现面问题已全量盘点（tl1436 调研报告落盘，评级 A16/B6/C7/D2），改进件另行立项。

## 新特性

- **图片标注编辑器**（tl1412，对标 zcode）：画笔（三档粗细七色）/文字/形状（矩形箭头圆圈）+undo/redo/清空，导出合成 PNG 直接回填输入框；标注渲染与截图流共用一套语义（SSOT）。
- **外部 Agent 一键导入**（tl1422）：扫描 Claude Code/Codex/OpenCode 的 commands/skills/MCP（本机实测 304 项），逐项勾选+预览+冲突三策略+汇总回执；纯读外部文件。
- **压缩迭代三：模型驱动触发**（tl1419，实验开关默认关）：compress_ranges 工具+洪水闸（单次收益限+滑动窗口）+1396 红线触发确认；失败原因模型可读。
