# Reasonix Fork 桌面版 v1.38.3-20261031-1812 — Release Notes

> 基于 v1.38.3-20261031-1534（包61）以来：**白天积压的全量滚合**——十件已交付未合的活（工作流能力组、面板视角、残影前端断言、项目管理二级菜单、Ctrl+P 门控、压缩超时降噪、turn preflight、测量基建）全部并入，另含三处门禁清障。覆盖安装即可。

## 本版内容

- **工作流能力组**（934）：内置工作流五件套（定义/列表/读取/运行/状态）+ 工作流引擎与服务；工作流面板接真实运行数据（运行选择器、真运行 DAG 与快照渲染、运行中可中止、引擎诊断下钻），演示 fixture 降为「演示」按钮保留。
- **工作流面板视角**（933）：面板偏好与缩放跨会话持久化（画布缩放、拖拽、视口偏好记忆）。
- **残影前端接线断言套件**（1266）：已断开徽章四层钉死（徽章渲染、类型联合、三语文案、主题 token 复用）；本次补齐「断开优先于未加载」——同一槽位只渲染一个徽章，断开是更强的状态真相。
- **项目管理二级菜单**（1252）：项目右键的低频管理项（复制路径/重定位/版本/移除）收拢进「项目管理 ▸」二级面板（经典与工作台双布局一致），减少误触。
- **StatusBar 任务弹层**（1250）：悬停显示任务全文。
- **工具优化页文案对齐后端**（1251）：删除已失效的「压缩边界」承诺，明确「重启后生效」与工具表在启动时固定的真实行为。
- **Ctrl+P 门控补齐**（1275）：会话图墙实验开关关闭后，Ctrl+P 快捷键不再直接打开图墙——补上与面板入口不一致的门控（零痕迹契约在快捷键面此前失效）。
- **压缩状态误报降噪**（1021）：多轮压缩时上下文提示按标签页折叠去重，消除超时提示刷屏。
- **turn 卡死**（1213）：生成层重复 command 字段导致 preflight 拒绝后 turn 永久挂起的实证与修复。
- **测量基建**（1181）：REASONIX_HOME 沙箱下 WebView2 数据目录随 home 隔离（可并行测量，不再与运行中实例互斥）；启动分四段打点上报。
