# Reasonix Fork 桌面版 v1.38.3-20261012-1748 — Release Notes

> 基线：v1.38.3-20261012-0045（23.5）。本包为 batch24（wave3 七件 + 820 补充件）增量；含出包门禁三修（class-contract/theme-token/comment-leak）与预算棘轮四笔。
> 数据/会话/记忆目录与官方 v1.38.3 完全兼容（v3），覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本包修复 **tab 宽度档位锁死**（graphite 主题下拉宽/最大化/跨屏不再卡在收缩档位）与 **ask 审批面板不可达**（可逆操作也弹面板、面板内操作停止倒计时、无操作 15 秒自动代答）两个日常高频卡点；新增**群聊视图**（多会话合流消息流）；**超大长会话投影失效从「全量回退」改为有界处理**（自愈，不再整轮重投影）；压缩尾部预算形成完整包络；Responses 流工具调用完整性校验对齐上游 #12526；agent 委派行为开始落打点（可度量）。

## 🖥️ 界面与交互

- **tab 宽度档位不再锁死**（818）：graphite 主题下窗口拉宽/最大化/跨屏移动后，tab 即时恢复完整宽度，4 个 tab 不再提前收缩成窄条。根因是宽度观察目标选错（strip→bar）产生反馈环，本版解耦并补 window resize 兜底。
- **群聊视图**（802）：多会话消息合流为微信式消息流（窗口 60%×60%，最大化状态持久化），多线并行时一眼看清各会话动态。

## 🛡️ 审批与安全

- **ask 面板三要素**（806）：可逆操作也会弹审批面板（不再 0 秒静默自答）；你在面板内的任何操作立即停止倒计时；倒计时走完前 15 秒无操作才自动代答——审批不再「还没看清就过去了」。

## 🧠 压缩与长会话

- **超大长会话投影失效有界处理**（813）：极端规模会话（数 MB 级）触发投影失效时不再整轮全量重投影（此前会超窗转出、会话卡死），改有界路径自愈；已超限的旧会话修复后可自愈恢复。
- **压缩尾部预算完整包络**（812+819）：尾部预算 clamp 到 96K 上限防膨胀，≥256K 窗口另有 32K 下限保底——与 studio 同形的 `clamp(16%, 32K, 96K)` 两段式，小窗口行为不变。

## 🔌 协议与兼容

- **Responses 流工具调用完整性校验**（814，移植上游 #12526）：流式响应在工具调用未闭合时不再静默当作正常完成，转终止态校验+补完成，杜绝「半截工具调用」污染会话。

## 📊 agent 调度（内部可观测性）

- **委派行为打点**（820）：回合级记录调度档位/派发数/主链步数（DelegationMetricsAudit），子代理调度积极性从此可度量；
- **aggressive 档文案修正**（820）：删「小活留主会话」矛盾条款，改「Do NOT inline——派出去」单向倾斜，主会话角色框定为协调者。

## ⚠️ 升级提醒
