## 缺陷修复

- **归档死循环根治**（tl1390）：recovery 副本转正时侧车搬运在 Windows 上目标已存在即失败，导致转正永久卡死、同一会话双副本并存、侧栏状态与正文不一致（显示工作中但打开无运行态）——本包修复转正链（rename 覆盖+事务性+副本收敛），此前无法归档/状态错乱的会话恢复正常。
- **向运行中会话发消息不再裸报错**（tl1393）：回合中发送引导消息时若 turn 已换代（"is not the active turn"），此前报错弹脸且消息丢失；现降级进持久引导队列，回合结束自动派发，消息不丢。
- **子代理面板两层修复**（tl1387）：右侧「子」tab 此前不显示运行中子代理（与左侧任务弹窗数据源不同步）、子代理工作过程不可见——两层全修，运行中实时可见+工作过程可展开。

## 新特性/增强

- **CTXAgent 压缩三增量**（tl1378，实验特性默认关）：①curate_context 细粒度档（experimental_curate_context）②review hint 提示层（experimental_review_hint，每 25 工具批次/20k token 提示复查压缩）③compress 工具 hand-off 引导补「改动文件、未决问题」。
- **host 协议消息窄渲染**（tl1350）：session-context/压缩提醒/reasoning-language/nudge 四类系统消息从全宽改折叠紧凑条，不再占对话空间。
- **装机后 UI 验证自动化**（tl1382）：verify_pkg_ui.py 三态（run/plan/probe）——装机验证从人工逐项点检升级为脚本化，后续包装机自验提速。
- **todo_write 工具容错**（tl1354）：plan_id 破坏性语义进 schema 描述+in_progress 顺序规则自动容错，agent 误传不再封存失败。
- **准入矩阵代码化**（tl1340）：24 格策略表单一真相源+代码化，投递泵注入决策可审计。
