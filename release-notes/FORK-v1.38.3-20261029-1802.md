# Reasonix Fork 桌面版 v1.38.3-20261029-1802 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261029-1658** 以来的全部更新（4 项滚合+2 笔 TS 冲突修复：tl1243 + tl1170 + tl1144 + tl1212）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。

## 概览

本版是 **滚动锚定与清理根治批**：①侧栏展开/收起时聊天不再跳动；②筛选面板重构（改名+重排+记忆折叠）；③项目树空壳会话两阶段根治；④简洁模式思考行消失根治。

## 📜 侧栏展开/收起滚动位置保持（tl1243）

- **聊天不再跳动**：侧栏展开收起时聊天列宽逐帧变化导致内容重排、读到一半的字会跳（用户实锤）——现在贴底的继续贴底、读半截的按块重新锚回原位（宽度变化接 footer 同款结构性补偿，高度路径旧语义一字未动）。

## 🔽 项目树筛选面板重构（tl1170）

- **标题改「筛选与排序」**：hover 标题不再叫「筛选」（旧文案死键三语清除）。
- **顺序重排**：清除筛选 ▸ 排序条件 ▸ 按时间筛选 ▸ 按颜色筛选（按使用频率）。
- **时间/颜色两区默认折叠**：展开态 localStorage 记忆（projectTree:filterPanelExpanded），下次打开不用再点一遍。

## 🧹 项目树空壳会话清理根治（tl1144，两阶段）

- **删会话不再留空壳**：此前删除会话后项目树有时留「点开什么都没有」的空壳条目（删会话代码从不通知注册表下岗）——两阶段修复：①delete_session 空壳探针/清理终审挂统一判据（contact 查不到回落注册表判定，三处收敛+幂等）；②产生时刻补收敛（最后一个会话文件被删时即时走既有 deleteTopic 写路径=墓碑+分组剔除+树刷新），未造第二套清理机制。

## 💭 简洁模式思考行消失根治（tl1212）

- **「思考中」不再凭空消失**：断线恢复把思考缓冲清了、这段思考又还没存过底稿时，界面时长行在走、思考行凭空消失（用户现场形态）——修法=数据层给空窗留锚点+界面先亮「思考进行中暂无文本」标签，第一个字到达立刻切回实时文本。
