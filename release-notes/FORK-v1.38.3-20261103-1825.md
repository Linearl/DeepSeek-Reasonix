# Reasonix Fork 桌面版 v1.38.3-20261103-1825 — Release Notes

> 基于 v1.38.3-20261103-1605（包69）以来：**三件滚合**——候选链读数恢复 + 群聊浮层点外关闭收口 + 侧栏/历史标题去内部文件名泄漏。覆盖安装即可。

## 本版内容

### 缺陷修复（P1）

- **恢复候选链读数从全 0 恢复真实值**（1355）：恢复面板此前对每个候选项只显示「0 条消息·0 轮·无预览」——现改为对会话文件做内容扫描合成，条数/轮次/预览/最后活动全部读回真实值，并标注与主线的覆盖关系；扫描带 10 秒时间预算与进度条，超预算走纯计数降级行。「最长链合成」能力不因历史结构删除而丢失，反而获得真实读数支撑。
- **群聊浮层点外关闭收口**（1369）：四处浮层补齐「点击空白处关闭」——详情抽屉（此前唯一关闭钮被 300px 抽屉遮挡不可达，点击区域失灵）、新建群对话框、「@」选人浮层、「协作动态」浮层；详情抽屉与邀请框同时补显式关闭钮。点外关闭带边界保护：点浮层内部、触发按钮、右键菜单区域均不会误关。
- **侧栏与历史面板不再显示内部文件名**（1330）：侧栏会话子行、历史面板索引占位、新会话复用目录三处，此前会直接显示 `abc123.jsonl` 这类内部标识——现改为人话标签链（用户标题 > 主题 > 首条消息摘要 > 时间戳 > 默认「新的会话」），恢复的会话带「(已恢复)」后缀。

### 内部质量

- 1369 的两个点外关闭豁免锚点类补 CSS 定义（合并线门禁收尾代修，界面无可见变化）。

## 门禁与质量

- 三件全部经合并线滚合+门禁（两族浮层测试全绿 + ChainScan 定向钉 + desktop 恢复链两钉 + tsc=0 + vet=0 + check-all-parallel 10/10）。
- 预存红申报（基线对照）：internal/control 时间敏感族与 agent ChainScan 时间预算钉为负载时序抖动（复跑可绿），净新增红=0。

## 升级提醒

- 从包69（1605）覆盖安装即可；设置与数据全兼容。
- **已知现象**：若使用 mimo-api 直连通道的会话仍开轮即断，需续期 `.env` 中的 `MIMO_API_KEY`（凭据文件不随包更新，包69 已提示，仍未续期则现象不变）。
