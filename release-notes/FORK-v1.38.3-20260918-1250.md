## 本版新增：四线并行开发（会话管理工具 / 关 tab 不阻塞 / 测试防线恢复 / 启动首载与预取）

### 会话管理工具补全（任务 170）— agent 可改名、可移动分组

- `rename_session`：改会话标题，侧栏/搜索/通讯录三处同步
- `move_topic_to_group`：把已有会话移入指定分组（新增 MoveTopicToGroup 后端：
  先摘除旧组再加入——原 AddTopicToGroup 因单组归属校验无法单独完成移动）
- 移动/改名后侧栏分组行即时刷新；对运行中会话安全（只写元数据 sidecar，
  不碰 transcript writer lease）
- 完整性锚点已登记（check-fork-integrity 51/51）

### 关闭标签页不再被运行中任务阻塞（任务 162）

- 后端：stop_and_close 15s 超时后不再留下无法关闭的标签页——工作自动
  detach 到后台运行时继续跑（可从后台作业面板观察/收回）
- 前端：默认 keep_running 立即关闭（toast 提示任务已转后台）；「停止任务并
  关闭」移到右键菜单作为显式第二选项；文案不再出现「无法关闭」

### desktop 测试防线恢复（预存红清零：13 红 → 0 红）

七个独立 commit 逐条判定修复（测试过时 5 / 代码问题 3 / 夹具缺陷 2 / 打包
契约 1 / flaky 1，含两处真实代码修复：后台命令改走 internal/proc 隐藏窗口
构造器、restart-and-update 参数校验顺序提前）。`REASONIX.md` 的
Pre-existing failures 表恢复为空——下次追齐上游，测试防线不再有噪声掩蔽。

### 启动首载提速 + 标签预取（任务 123）

- 根因：startup 的 ~4.0s 花在为旧消息补时间戳而全量重放 146MB 事件日志
  （与文件大小线性）
- 修复：改为从事件日志**尾部有界读取**（8MiB，59ms）+ 进程内缓存，同一
  36.9MB 会话冷读 **4256ms → 1056ms**（-75%）
- 拿不到时间戳的旧消息显示为空（不再错误显示当前时间）
- **标签预取**：最近使用/悬停预取（带缓存预算守卫），第三/第二个标签首次
  切换显著改善（预取不解决首次启动，属固有冷读）
