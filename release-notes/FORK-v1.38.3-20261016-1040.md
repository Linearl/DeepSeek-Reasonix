# Reasonix Fork 桌面版 v1.38.3-20261016-1040 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261015-1528** 以来的全部更新（批 32+33 十九件）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。

## 概览

本版是 **压缩韧性 + 上游同款修复批（十九件）**：①超长会话压缩失败「永久放弃」根治（不再无重试无兜底）；②八件上游同款修复移植（含两件 data-loss 级）；③右下角弹窗统一、multi_edit 注入面、跨会话回执分级通道等一批工程与体验件。

## 🗜️ 压缩韧性

- **压缩不再永久放弃**（tl912）：超 1M + cache miss 暴涨的根因——压缩失败后无重试无兜底（实测 401/rate-limited/canceled 三连后常驻 1.82M）。修复后压缩失败会重试，永不全量。
- **压缩错误识别补齐**（tl897）：移植上游 #9696，`Input length` 超限报错此前不被识别为 context-limit，导致超窗。

## 🛡️ 上游同款修复（七件）

- **memory index 吞读错误丢数据**（tl898）：移植上游 #9487，`ReadFileUTF8` 的 err 被丢弃导致 MEMORY.md 静默丢失。
- **权限复位 data-loss**（tl902）：移植上游 #10335，关闭软件/切页后权限全变「工作区内修改」——验证先行，先复现再定修法。
- **递归删主目录护栏**（tl903）：移植上游 #11782，`$home` 赋值失败后继续执行会递归删主目录——core 层加执行护栏。
- **迁移不可回滚**（tl905）：移植上游 #11846，`MigrateV2` 就地重写 legacy memory 前补 `.bak` 快照。
- **effort 域合并件**（tl901）：移植上游 #8337+#10503，MAX 档重启被改回 Auto、升级遗留全局 subagent effort 拦模型切换。
- **verification ask 漏触发**（tl906）：移植上游 #12528，extension `tool.after` 覆写失败写入时补 ranClean 判定。
- **readiness 失败无提示**（tl907）：移植上游 #8859，final readiness 失败后侧栏永远 running——按 fork 通知机制重实施。
- **Windows shell 双子件**（tl904）：移植上游 #9597+#10446，非标准 Git Bash 发现面 + 前台 PTY 中文乱码/假超时。
- **compact 期间提交丢 turn**（tl900）：移植上游 #9806，`/compact` 期间提交不产生 durable turn id 导致 Send failed（579/580 族）。

## ✨ 体验与工程

- **右下角弹窗统一**（tl910）：`.rt-notice` 组件 + 四档严重度 token 化，废除硬编码色值。
- **multi_edit 注入面暴露**（tl915）：工具优化族键默认开启，执行面恒可用、关态与现状等价。
- **跨会话回执分级通道**（tl894）：无需行动的回执静默化进返回值 + UI 通知，需行动的保留注入——省回执轮次。
- **输入框失焦修复**（tl913）：偶发失焦问题排查近批 UI 改动面与焦点管理。
- **日期与周几注入**（tl914）：用户回合注入时间时同时注入中文日期与周几，防模型误读。
- **control 测试族治理**（tl748）：11 包 FAIL + DATA RACE 疑同源根因的 P0 治理。
- **GC 分组管理**（tl911）：GC 项目分组/会话分组补开发（此前只读展示无管理操作）。
