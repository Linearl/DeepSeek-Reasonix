## 概览

本版是包 88 后的快速跟进版，围绕**「看得见」与「用得起」**两条线：压缩进行中的实时读数（token/速度）补全到全部界面触点、多币种计费混显不再吞数字、会话费用支持右键清零；另有大返回结果自动落盘不再丢失、分组整体迁移到其他项目、编辑历史消息回溯重发（实验特性）、对话段间空白块根治、以及一批界面口径统一（字号随全局缩放/亮色对比度达无障碍标准/时间与标题口径合一）。

## 🚀 主线一：压缩过程「看得见」

**你能感受到的**：
- **压缩进行中，右上「上下文窗口」卡和底部进度条都会显示实时读数**（已压缩 token 数与速度）——此前只有折叠头和压缩卡有，右上卡整个空白；读取速度尚未产出时显示「估算中…」不再只剩孤零零的秒数。
- 压缩结束后这些临时读数整体消失，不留残迹。

**怎么用**：默认生效。长会话触发压缩（自动瘦身）时观察右上卡与底部条。
**原理（1~2 句）**：后端压缩进度事件本就在发，本次把漏接的界面触点全部接上；速度尚未产出时用「已用时+估算中」占位。

## 🚀 主线二：计费显示「用得起」

- **多币种不再吞数字**——曾用美元、后切人民币的会话，费用此前会因多币种混算直接不显示；现在逐币种分别上屏（如「多币种 $0.0123 + ¥0.85」），数字必出、币种如实标注，存量旧记录切换后正确显示。
- **会话费用一键清零**——右侧栏「会话指标」卡：悬停「会话费用」出明细卡（总额/计费口径/费率档/分来源），右键 →「重置会话费用」→确认后归 ¥0.00；重置前值自动写日志可追溯。恰为零的会话也如实显示 ¥0.00 而非横线。

**怎么用**：右栏指标卡悬停/右键即达；清零为会话级，其他会话不受影响。
**原理（1~2 句）**：多币种按原始币种分桶逐个格式化；清零复用既有重置链并补前值日志。

## 🌐 重点：大返回不再丢失 + 编辑重发（实验特性）

- **工具大返回自动落盘**——工具输出超大（如 78KB 任务清单）被截断时，此前提示的「恢复通道」实测已坏死（数据等于丢了）；现在截断内容**自动落盘为文件并提示路径**，用读取文件的既有方式即可看全原文，数据不再丢；过时提示语移除，超限阈值分层评估中。
- **编辑历史消息回溯重发（实验特性，默认关）**——运行中也可编辑历史消息：系统自动停止当前回合 → 从该点分叉截断 → 以编辑后内容重发，一次操作完成；实验室开启 `edit_resend` 后可用。

**怎么用**：大返回=自动生效；编辑重发=实验室开启后，运行中点历史消息的编辑入口。
**原理（1~2 句）**：截断落盘复用文件写入通道；回溯重发复用既有分叉截断语义，顺序修正为「先治理挂起项再截断」（分叉后旧清单不可达）。

## 🤝 远程协作（GC）三件

- **serve 提交不再被自己拦**——远程设备自己的心跳曾把自己的提交拒之门外（连续失败 8 次的元凶）；现在提交携带设备身份，与持有者匹配即放行，他人占用时的保护不变。
- **连接二维码+最近链接**——桌面端 serve 二维码（上一版已交付）配套：GC 连接表单新增「最近链接」历史（扫码/手输过的地址带时间展示、点击回填、可清空，token 加密存储）；连接后前台服务保活（常驻通知+双锁），长会话挂机不被系统掐断。
- **模拟器适配核查**：GC 端模拟器全失效问题另行跟进（真机不受影响）。

## ✨ 其他改进（按主题）

**界面与可读性**
- **字号接入全局缩放**——319 处写死字号全部改为随「全局字体缩放」设置联动（10px 以下小字保底上移；项目树保持独立密度不受影响）。
- **亮色主题对比度达标**——弱化文字与 yolo/danger 前景对比度提升到无障碍 AA 标准（4.5:1），暗色主题零变化。
- **对话段间空白块根治**——无时间戳的助手消息段之间不再出现 2 倍行高的空条带。
- **口径统一**——同一会话在侧栏/历史面板/命令面板显示同一标题（按后端权威链序）；侧栏行与工具卡相对时间同词表；绝对日期统一连字符格式；复用目录带「已恢复」标记；历史索引占位三语。
- **后台 Bash 输出**——右侧栏子代理面板新增「命令」区，后台 bash 任务点开即看实时输出（与子代理工具流两通道并行）。

**稳定性与正确性**
- **待确认徽章可手动消除**——侧栏「待确认」会话在对话内提供「知道了」按钮，点按即清徽章（侧栏+标签条同步），不必再发消息；等待的审批语义不变。
- **write authority 自愈**——崩溃恢复后引导消息不再要求手动重开：租约可重取时自动重授权+提示「应用崩溃后正在恢复」。
- **双 \r 污染防御**——工具调用 id 被污染（连续失败 8 次的元凶）四层防御：写入清洗/匹配投影/渲染可见化/错误回显清洗（切断「模型模仿自己坏形态」的自增强通道）。
- **分组整体迁移**——分组右键「迁移到其他项目」：组壳与全部成员对话一次事务迁入目标项目（失败自动回滚半迁移态；活跃会话拦截）。
- 界面加载期目录扫描超时不再冻结：降级态文案+重试按钮接入（配合上一版后台化）。

## ⚠️ 升级提醒

1. **覆盖安装**：从旧 fork 版本直接覆盖安装即可；编辑重发为实验特性默认关。
2. **上一版条款继续有效**：存储差异与禁回退条款（包 87 起）、多币种显示为展示层修复（存量数据不动）。
3. **已知边界**：①GC 前台保活的数小时级挂机验证需真机长测（机制已按该场景设计）②分组迁移的第二阶段（全局记忆迁移）由各对话后续自行完成 ③间距/对比度/行高等视觉项建议升级后过目反馈。
4. **未验证项**：自动化门禁（构建/测试/完整性/预算）全量把关；主观体验类建议按日常习惯使用反馈。
