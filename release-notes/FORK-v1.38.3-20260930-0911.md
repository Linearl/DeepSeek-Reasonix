## 本包新增（批八：内存/CPU 治理收口 + Output Style 新特性 + 跨会话协作增强）

### 资源治理（空闲不再烧、内存可管、日志瘦身）

- **空闲 CPU 大幅下降**：会话目录的 30 秒全量对账循环改为文件监听事件驱动——空闲时 CPU 趋近于零，仅文件变更才触发对账（单点移植上游 v1.38.12 修复，空闲烧 1.4-1.7 核问题根治）。
- **内存上限可配置（实验特性）**：新增「Go 内存上限」设置（`go_mem_limit_mb`，默认 0=不限制）——设置后运行时在堆接近限值时更积极回收并向操作系统归还内存；设置页修改即时生效，无需重启。
- **会话图片去重（实验特性，三档位）**：开启「图片去重」后，同一张图在会话日志中只存一份字节（其余为内容寻址引用）——重度图片会话的日志体积可降 16-18%；旧文件完全兼容照常读取。三档可选：关闭 / 首份内联 / 全部引用（all 档日志零图片字节，膨胀彻底断根；4KB 以下小图标仍内联防目录爆炸）；桌面/主进程双镜像取强合并。
- **静默错误可见化（第一批 11 处）**：审批桥、网关恢复、任务列表坏快照、分支侧车损坏等约 11 处「出错但无声」的路径补齐了日志——排查问题不再两眼一抹黑；4 处测试的静默跳过改为硬失败（零 SKIP 纪律）。

### Output Style 输出风格（实验室新特性）

- **5 种内置回答风格 + 自定义**：Explanatory（讲解式）/ Learning（协作留白）/ Concise（结论先行）/ Proactive（行动优先）/ Default，另支持在输出风格目录放 Markdown 文件自定义（兼容 `.claude/output-styles/`）。
- **实验室开关「输出风格」**：面板选择器切换 + 坏 frontmatter 可见报错（带文件路径与原因，不再静默）。
- **会话级即时生效**：切换风格当前会话立即重建运行时生效（流式输出中切换则本轮结束后自动应用并提示）；同时持久化写入配置，新会话沿用。

### 跨会话协作增强

- **跨会话改模型**：`session_control` 工具的 set_model 动作新增自拒绝保护（不能改自己）、未知模型名报错附带当前可用列表、执行后回执带旧模型与 effort 兼容性说明、审计日志记全调用方/目标/新旧模型。
- **unknown 状态自解释**：`get_session_status` 对看不到进程的会话新增 hint 字段（说明这不代表空闲/死亡，并给出两步核实方法）；跨会话发信回执在目标不可见时附「queued 是邮箱确认不是送达证明」提示。
- **代批审批上下文感知（实验特性）**：autopilot 代批时可配置范围（只批与当前任务相关 / 全部代批）+ 自然语言允许/禁止清单文件（不配置则模型自判）——代批 prompt 会携带清单内容与范围语义，超范围请求转人工。

### 会话切换与历史

- **打开历史对话到可发消息的端到端提速**：历史加载的快路径与碰撞守卫已验证在位并加防回归钉（此前分析确认等价实现已在，本包补齐测试护栏）。
- **运行中历史解锁**：turn 运行中上滚可正常加载更早历史（原 running 闸已移除，`historyHasOlder` 为唯一硬门）；15 秒自愈前置到所有闸之前（卡死 loading 任何条件下可复位），所有跳过路径补日志。

### 修复

- **设置保存不再假失败**：保存成功但后台重建失败时，不再回弹报错——忙碌时排队到本轮结束自动应用并提示，硬失败时明确提示「重启桌面后生效」，不再出现「写盘成功 UI 却报错」。
