## 本版新增

### 设置 → 实验特性

- **「会话存储」开关落地**：`session_storage` 现在可从设置页切换（`legacy` 默认 / `v4` 实验），并补齐了此前缺失的**渲染表**条目 —— 否则手改 `config.toml` 加的那行会被下一次设置保存**静默丢弃**，这个实验根本开不起来。文案写明 v4 是**双写**：`sessions/` 仍是 agent 持续写入的主转录，`sessions-v4/` 是每次落盘的全量替换镜像；两边都在写，所以**切回 legacy 不丢内容**。
- **需重启才生效的设置现在会主动提示**：保存后出现「已保存。该设置在启动时生效 —— 重启后才会应用。」+「立即重启」按钮，不必自己关掉再打开。后端新增 `App.RestartDesktop`，**刻意不挂在 `experimental_restart_update` 上** —— 那个实验守的是「发布并切换版本」（拷二进制、挪 `current.json`）的危险半边，而纯重启只重开磁盘上已有的二进制。
- **修复侧栏「实验特性」缺图标**：`settingsTabIcon` 的 switch 没有 `experimental` 分支，返回 `undefined`，导致该导航项与相邻项不对齐。返回类型是 `ReactNode`（容许 `undefined`），所以 TypeScript 从未报错。补该分支的同时**加了 `default` 兜底**，防止下一个新 tab 重演。

### 发布链

- **版本号带构建时间戳**：本分支长期停在 `1.38.3`，多个包共用同一版本号无法区分，因此包版本改为 `1.38.3-YYYYMMDD-HHMM`，安装目录 `versions/<name>/` 随之唯一，**可回退到指定的那一次构建**。（格式受 `installlayout.versionDirRE` 约束：只接受 `-` 后缀，不接受 `+`）
- **修掉 release notes 的静默降级**：workflow 原先在找不到对应 notes 时会**静默 fallback 到 `FORK-v1.31.3.md`**，等于把 1.31.3 的说明发到 1.38.3 的发布页。现在认识时间戳形式，再找不到就**报错退出**。
- **README 补充**：新增「本 fork 增加了什么」特性表，并说明构建时间戳的用途。

## 升级提醒

- 覆盖安装即可；会话 / 记忆 / 配置目录与官方版完全兼容。
- **不要回退到 1.34 / 1.38.1 以下的旧版本**：会话事件日志会**就地升级到 schema 2**（`upgraded_from_schema: 1`），而旧构建只支持到 1，加载时会以 `uses schema 2; this build supports up to 1` 拒绝打开（**文件不会被改动**，是保护性设计，不是损坏）。需要降级前请先在 1.38.3 里导出会话内容。
- **已知问题（本机环境）**：`go test ./internal/boot/` 整包在本机挂起（环境探测单飞机制 `beginProbe`，每个测试单跑均通过）。
