# Reasonix Fork 桌面版 v1.38.3-20261014-0149 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261013-1451** 以来的全部更新（低峰批六件）。

## 概览

本版是 **低峰批（六件）**：①表情包发送（8 分类 + 搜索）；②文件面板操作体验包（右键三项 + 回收站 + 多选批量删除）；③项目分组四件（重命名/解散/字号 token 化/图标列与拖拽换序）；④实验室 UI 完整性补全与证据门熔断改进。

## ✨ 界面与交互

- **表情包发送**（tl869）：8 分类 + 搜索，ZWJ 与肤色修饰直通；目录剔除 Emoji 14.0 字符（旧版 Win10 WebView2 无字形会显示方框）。
- **文件面板操作体验包**（tl855）：右键三项操作 + 回收站 + Ctrl/Shift 多选 + 批量删除前端。
- **项目分组四件**（tl827）：右键重命名、解散分组、字号 token 化、图标列统一网格、拖拽换序。

## 🧪 实验室与工具链

- **实验室 UI 完整性补全**（tl815）：28 键甄别、`bash_heavy_guard` 补卡与全链路接线、`editEvidenceRelaxed` 登记窗口落地、三键补灯；562 前端镜像 unstable 档 12→14，锚同步。
- **证据门熔断改进**（tl859）：阈值 2→3，回执附原因与合规路径。
- **launcher 计划性 handoff 识别**（tl876）：带新鲜 update-restart marker 的非 0 退出视为计划性 handoff，不再误报失败——847 家族终件。
