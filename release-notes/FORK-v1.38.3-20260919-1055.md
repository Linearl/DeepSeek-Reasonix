# Reasonix Fork 桌面版 v1.38.3-20260919-1055 — Release Notes（hotfix）

> **增量基线**：上一包 **`v1.38.3-20260919-0426`**。本包为专项修复包。

## 修复：切换标签页"时快时慢"——预取冗余重读清零

**症状**：切换标签页有时快有时慢，且与"开始工作"时段重合。

**根因（日志实测）**：上一包引入的标签预取存在自证缺陷——114 次预取中
**100 次（87.7%）的页面其实已经在缓存里**，却仍被强制整页重读（每次
85-675ms），且恰好发生在用户切换标签的同时。另有两处叠加：缓存键在
会话写入期间持续失效（每次切换都重扫整个尾部窗口，37 次记录）；预取的
预算守卫读错了上限（标签页上限 24 而非缓存自身驻留上限 3）。

**修复**：
1. 页面已驻留（缓存命中）→ 直接跳过预取（日志记 `reason=resident`）
2. 预算守卫改读缓存自身驻留上限
3. 缓存键改为 append-only 增量合并——会话写入期间只扫新增区间，不再全量重扫

**验证**：prefetch 测试 7/0（含"已驻留不再发后端调用"断言）+ 探针复测
同会话 cold 315ms / warm 215ms + tsc 干净。
