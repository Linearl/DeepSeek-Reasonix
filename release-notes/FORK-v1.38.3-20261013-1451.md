# Reasonix Fork 桌面版 v1.38.3-20261013-1451 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261013-0014** 以来的全部更新（批 24.4 七件）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。

## 概览

本版是 **批 24.4（七件）**：①sentinel 只读命令误拦修复（grep/cat 等不再被当写操作拦截）；②会话分组实施件落地——协作中心首版上线；③两件 data-loss/可用性类排查与根治（过程折叠回归、崩溃分析误改用户会话标题）；④`versions` 目录自动清理（更新后保留最近 4 版）。

## 🔒 安全与正确性（sentinel / 崩溃分析）

- **只读命令不再被误拦**（tl851）：`write_system_config` 此前按「路径出现」判写，`grep config.toml` 这类纯读命令也被拦（实测可被拼路径绕过）。改为按「写特征」判定——重定向与写命令才拦，`grep`/`cat`/`ls`/`head`/`tail`/`find`/`diff` 等已知只读命令放行；顺带自查 `exfil_credentials`、`delete_critical_path`、`force_push_protected` 三规则的同款问题，并补只读放行/写拦截矩阵测试。
- **崩溃分析不再误接管用户会话**（tl858）：更新重启后自动触发的崩溃遗留检测会命中用户既有会话并改写其标题（实锤：评测会话被改成「崩溃分析-…」）。修法限定自动链路只新建独立会话、不改写既有会话标题，并提供受害会话原名恢复路径。

## 🧩 分组与协作

- **协作中心首版上线**（tl856）：两图标合一入口、双视图容器与持久化、批量删除、对话链通道与右键跳转、副管理员与 @ 选人；schema v3→v4。
- **过程折叠回归排查**（tl857）：按「先复现定位类型 → 再二分归因到具体合并」推进，重点怀疑回合中途注入的 transient reminder 影响折叠判定。
- **冷历史切片读取独立排查**（tl836）：为 831 交付遗留的冷读路径单独立项，隔离归因。

## 🧹 存储与工程

- **`versions` 目录自动清理**（tl835）：更新后保留最近 3 个历史版本 + 当前版（共 4 个目录）+ staging，超额目录与 `*.replaced-*` 残壳自动清除。
- **desktop 包预存红排查**（tl854）：`Restart`/`Update`/`Lifecycle` 三词混跑触发 watchdog 强杀导致包级失败——主仓干净树同红、单跑全绿，按预存红登记并另立排查。
