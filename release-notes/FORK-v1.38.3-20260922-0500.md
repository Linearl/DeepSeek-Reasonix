# Reasonix Fork 桌面版 v1.38.3-20260922-0500 — Release Notes

> 本版本基于官方 `v1.38.3`，包含 `desktop-v1.38.3-20260921-1600`（上一个发布版本）以来的全部更新（23 个提交）。
> 数据 / 会话 / 记忆目录与官方版完全兼容，**覆盖安装即可，无需迁移**。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

这个版本的主题是**多会话协作从「能用」到「好用」**：跨会话通信一次性落地九项改进（防串线、可要求回信、工具精简、收件箱合并、状态查询），AI 调用工具的报错也从「猜谜」变成「给答案」。同时带来版本快速切换、心跳任务交给 AI 管理等日常改进。

---

## 🤝 跨会话通信：九项改进一次到位

- **发信可以要求对方回信**——开启后，对方完成工作若没有回信会收到提醒；另支持每日发送上限与逐项能力开关，防止失控。
- **防串线三层防护**——每次发信自动留底（发给谁、什么时候），回执里带收件方名字，过期 thread 一眼可辨；发错线在第一时间就能发现。
- **通信工具从 14 个精简到 10 个**——任务卡片四件套合并成一个、收发信查询合一，工具列表更清爽，模型调用更省。
- **收件箱合并注入**——实验室新增「收件箱合并」三档（关闭 / 同源合并 / 全部合并）：多条跨会话消息可以合成一条进入对话，不再刷屏；引导架也新增了手动「合并下一条」按钮。
- **派活前先看对方忙闲**——新增会话状态查询：一次拿到全部联系人的运行中 / 空闲 / 排队状态，对方离线时不会误报空闲。
- **对方的消息不再误伤你的会话**——跨会话消息正文不再参与本会话的只读/约束判定；带「只读」字样的审计报告不会再把你的会话锁成只读。
- **拒绝原因说真话**——跨会话消息被拒时明确说明是「达到链路上限」还是「串线」，不再统一报「无法核实来源」。
- **协作状态自动留痕**——引擎自动记录每条并行线的开工/交付/阻塞事件，管理者一次增量读取即可掌握全局，无需逐线追问。

## 🔧 AI 工具调用：报错从猜谜变给答案

- **参数写法自动纠正**——常见的双重包装写法会被自动解开并正常执行。
- **写错时给出对照示例**——校验失败的提示直接展示「实际收到的样子 vs 正确写法」，且重复犯错不会静默。
- **edit_file 支持行范围编辑**——新增按行号区间替换（带版本与锚点双重护栏），大文件改动不再需要贴整段文本。

## 🖥️ 桌面端日常改进

- **快速切换版本支持列表选择**——「快速切换版本」弹窗升级为版本列表（最新 + 当前 + 历史，动态列举），一键切换并自动重启，用户级技能与数据零触碰。
- **正在用的会话不再被踢出缓存**——大会话切走再切回不再触发全量重载（活跃会话豁免驱逐）。
- **心跳注入的上下文不再闪现在对话里**——系统注入的快照内容在聊天记录中隐藏。
- **heartbeat 定时任务可以交给 AI 管理**——新增查看 / 新建修改 / 启停三类工具：写错字段立即报错、并发写入有版本护栏。

## 🔍 全量审计加固（三路独立审计后修复）

本版在初版基础上经三路独立全量审计（工具引擎 / 跨会话协作 / 桌面渲染），修复全部发现的问题：

- **跨会话消息的「只读隔离」补全到最后一行**——审计发现此前只隔离了消息头部、正文仍参与判定；现按真实投递格式整块隔离，并以真实渲染输出作为永久测试防线。
- **「我发过哪些消息」可以查了**——此前发信留底只写不读；现通讯录查询工具新增发件箱视图（收件人、时间、摘要，最新在前）。
- **通信工具的教学文本全部更新**——系统提示与内置技能里残留的 6 个旧工具名清零，模型不再被指引调用已下线的工具。
- **并行批次的状态流汇聚**——多工作树并行开发时，状态事件统一写入共享目录，管理者一次读取即可掌握全部进展。
