# Reasonix Fork 桌面版 v1.38.3-20261020-0030 — Release Notes

> 基于官方 v1.38.3，包含上一个时间戳包 **desktop-v1.38.3-20261019-1008** 以来的全部更新（约 11 项）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

本版是**实验室档位改造 + 会话体验修复批**：①实验室新增「稳定」档与批量开关，核心能力默认锁定、进阶用户可解锁关闭（本次最大特性）；②write gate 门禁移除，AI 工具写操作不再被契约门禁拦截；③收件箱单条上限调档 16MiB，大文件传递不再被 4MiB 拦截；④项目栏闪烁二轮根治与 Global 冒泡守卫；⑤一批体验细节——后台 ask 提醒、压缩实时速率、工具名拼写容错。另修复两处合并后发现的真缺陷（压缩后通讯录提示丢失、协作工具诊断身份缺口）。无数据迁移。

## 📌 主线一：实验室「稳定」档（新特性）

- **新增第四档「稳定」**：位于推荐之上，收录经发布验证的默认能力（首批四项：会话协作 / 自动驾驶 / 完全访问 / 运行时复用）。稳定项在界面上**显示但默认锁定**，并注明原因。
- **开发者模式解锁**：实验室页新增「允许关闭稳定能力」总开关（默认关）——打开后稳定项可关，并给出兼容性提示；关闭状态下批量操作自动跳过稳定项。
- **批量开关弹窗**：实验室页新增快捷批量按钮——范围三档（稳定/推荐及以上/可选及以上）× 行为（开/关），确认后可选择立即重启或下次启动生效；含未稳定项不进批量、稳定项警示两道护栏。
- **手动关闭感知**：若你此前手动关闭过某个已转稳定的能力，条目会如实显示「你曾手动关闭」，不会被静默覆盖。

## 🔧 主线二：会话与收件箱

- **收件箱上限调档**：单条消息上限 4MiB→**16MiB**、总量 64MiB→**128MiB**；超过 4MiB 的大消息发送时给出软提醒（不阻断）。大请求仍受既定熔断保护，行为不变。
- **write gate 门禁移除**：AI 工具写操作前的 todo/criteria 契约门禁按用户拍板移除（开关化默认关）——此前「todo 写入被锁死需逃生」一类问题不再发生；外发命令门禁（push/deploy 识别）保持不变。
- **项目栏闪烁二轮根治**：在上一版合批基础上再进两步——事件驱动的目录刷新改为只取首页（展开目录不再整树重拉）、运行态通道前端合批（每 400ms 只保最新），高频事件下的抖动显著收敛。
- **Global 会话冒泡守卫保持**：上一版的冒泡修复继续有效，本版回归覆盖。

## 🛠️ 主线三：体验细节

- **后台会话 ask 提醒**：后台标签页收到 AI 提问时，右下角弹限时 toast，点击直达或自动打开标签页，不再错过后台提问。
- **压缩过程实时速率**：压缩对话期间状态栏实时显示 token 速率与进度，不再是静态「正在压缩对话…」。
- **工具名拼写容错**：AI 调用工具时的常见拼写变体（如 ability_id）现在被宽容接受并给出提示，减少调用失败。
- **批量开关需重启提示**：涉及进程级注册的开关在打开时会明确提示「重启后生效」。

## 🛡️ 健壮性与缺陷修复

- **压缩后「通讯录」提示丢失修复**：长会话压缩重建上下文时，AI 可用工具的教学段被遗漏，导致压缩后 AI 无法识别协作类工具（如实答「没有该工具」）——现已修复，压缩前后工具认知一致。
- **协作工具诊断身份缺口修复**：17 个 fork 协作类工具（跨会话信箱/任务卡等）补入诊断身份名单，工具诊断不再误报缺失。
- **两处测试不稳定根治**：mock 投递器在取消场景下的随机丢帧改为确定性投递（连续 20 次全绿）；另一处低频失败补齐失败现场捕获，留待根治。
- **完整性锚点同步**：分叉完整性核对脚本的档位锚点随稳定档演进同步（846/846 全绿）。
