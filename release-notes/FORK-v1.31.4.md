# Reasonix Fork 桌面版 v1.31.4 — Release Notes

> 本版本基于官方 `v1.31.4`，在 fork v1.31.3 全部增强之上，**吸纳了官方 v1.31.4 的 8 项稳定性/性能改进**：损坏会话元数据恢复、后台任务通知、降低数据库读取成本、稳定会话滚动、更好的数学渲染、保持侧栏活动顺序、停止目录反复重索引、恢复显式收尾恢复。数据/会话/记忆目录与官方版完全兼容，**覆盖安装即可，无需迁移**。

## 使用攻略

- 所有 fork 功能均可在 **设置 → 权限 / 通用** 或**会话输入框右上角**找到入口；CLI/TUI 用斜杠命令。
- 安装**覆盖安装即可**，无需卸载、无需迁移数据；已关闭自动更新，未来可随时切回官方版。
- 本次新增的上游改进大多**无需配置**，随版本自动生效。

## 概览

**Reasonix Fork v1.31.4 — 在 v1.31.3 增强上叠加官方稳定性/性能改进**

本版本在上一个 fork v1.31.3（多会话并行 + 长会话成本优化）的基础上，**同步吸纳了官方 v1.31.4 的 8 项桌面稳定性与性能改进**：损坏会话元数据不再卡死保存/关闭、安静后台任务不再误报"卡住"、重型的指标汇总读取退役（降 DB 成本）、长会话滚动更稳、桌面与 CLI 数学渲染更好、侧栏活动顺序不再错乱、空闲会话不再反复重索引、显式收尾恢复不再被隐藏轮询拖慢。

发布日期：2026-08-25（fork 发布）

## ✨ 重点内容（新增 · 官方 v1.31.4 功能同步）

### 1. 从损坏的会话元数据中恢复
会话元数据文件**全零或仅含空白**（如强制关机/非原子替换被截断，见 #6325）时，原来会卡住保存/关闭。现在**自动重建**该 meta，不再阻断保存与关闭标签页；真正的部分 JSON 仍保留为错误，绝不吞掉真实损坏。（#9155）

### 2. 更清晰的后台任务通知
安静运行的长时后台任务不再被报告为"可能卡住（may be stalled）"。通知现在明确说明**任务仍在运行**，并解释**如何用 `tools.background_jobs.stalled_warning_seconds` 调整或关闭警告阈值**（设 0 关闭）。避免把正常的长任务误判为故障。（#9115）

### 3. 降低数据库读取成本
退出了重型指标汇总（metric_users 30 天去重安装数轮询），其主键以 `date` 开头导致每次全表扫描。该面板按小时轮询、每个 signal 扫全表，日读取量达百亿行。现已移除该汇总表（回收约 5.6GB）与相关面板，改由去重安装数精简统计，显著降低数据库读取费用。（#9379）

**对用户影响**：崩溃报告 DashBoard 里不再展示那个会耗尽整个读取预算的 30 天去重安装数面板；其余面板不变。

### 4. 稳定的会话滚动
修复了长会话中**滚动跳动、闪烁、无法到达底部**的问题，尤其是在**流式输出**期间。会话内容变化时滚动锚点更稳定，不会在原生滚动条拖拽、滚轮、触摸读scroll时错位。（#9248 / #9341）

### 5. 桌面端和 CLI 中更好的数学渲染
- **桌面端**：修复 WKWebView / WebView2 中 `\boxed` 框线公式在部分浏览器被压扁的问题，框线公式宽度跨浏览器更稳健。
- **CLI 渲染器**：新增对更多 LaTeX 命令的支持（含 `\boxed`），不再把 `\boxed{x}` 渲染成字面量 "boxedx"。（#9141）

### 6. 保持侧栏活动顺序
切换会话时，通过精确保留已知的活动时间戳，**不再把用户的会话在侧栏按活动序错排**。精确索引刷新时，若某条源自导出的会话被观察到旧瞬时态，不会让已知会话在活动排序里"倒退"。（#9314）

### 7. 停止会话目录反复重新索引
修复了空闲会话**反复进入索引/修复状态**、导致侧栏删除看起来不可用的循环。索引不再重复发布未变快照，且未知计数不会把已知计数降级。（#9312）

### 8. 恢复显式收尾恢复
**标准回合和交付回合不再启动隐藏的收尾后续轮询**。此前每次标准回合后可能多跑一轮不必要的 thinking/请求；现在显式收尾恢复只用于 Goal / 批准后的 Plan 回合的续写路径，显著减少额外思考轮次与服务请求。（#9341）

## 🚀 改进（fork v1.31.3 保留）

- **子代理三档委派**：运行子代理时可在「保守 / 均衡 / 激进」三档切换，会话级持久化、新会话继承默认。用法：输入框右上角下拉；CLI/TUI `/subagent-policy light|balanced|aggressive`；全局默认在设置 → 通用。（#9004）
- **并行写入安全检查**：同一项目多会话写不同文件不互相等待，靠期望值校验防冲突。用法：设置 → 权限 → 「并行写入安全检查」。（#9213 #9111）
- **长会话压缩阈值可降到 30%**：DeepSeek 缓存涨价后允许自定义压缩阈值降到 30%（原最低 65%），压缩更早触发、输入成本更低；**最近原文保留量随阈值联动**（`窗口×阈值×20%`），且绝不会折叠掉最近几轮对话。（#9158）
- **会话切换无感、秒开**：内容已缓存会话立即显示、无遮罩无转圈；缓存会话提升到 8 个。（#9385）
- **分组内单会话归档**、**残留后台任务不再卡归档**、**恢复失败会话不自动复活 + 强制归档**。
- **右侧提问定位条去密集化**：采样上限 120→60、密度阈值下调，拖动定位更准。（#9218/#9219）

## 🔧 修复（fork v1.31.3 保留）

- 会话改名/自动起标题后历史面板立即刷新（#8597）
