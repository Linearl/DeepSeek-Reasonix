# Reasonix Fork 桌面版 v1.38.3-20261012-0045 — Release Notes

> 基于官方 v1.38.3，包含 2026-09-21 正式版（1600）以来的全部更新（约 400+ 项更新合并）。

## 概览

本版集中解决了**跨会话消息投递的一整类可靠性问题**（偶发丢失、重复投递、静默不唤醒、收件箱显示异常）与**会话「假运行」问题**（异常退出后卡在运行态、新消息被吞）——收件箱面板从此全面可用；**切换模型/档位从 10 秒以上降到 3 秒级别**；**大会话切换从 71.7 秒降到 3 秒上下（实测）**；**一键分析全面升级**（卡顿可分析、进度可见、崩溃后一键恢复）；**设置实验室全面重组**（单徽章、搜索直达、卡片合并、用量监测上侧栏）；**安全告警清零**。新增会话图墙、收件箱面板、v5 会话导入器、外部协作总线、ACP 双端接线等一批功能，agent 工具报错开始自带正确用法提示（自愈引导）。

## 🚄 主线一：消息投递可靠性大修

**你能感受到的**：给忙碌中的会话发消息不再丢失；重启后不会收到重复的引导消息；空闲的会话收到消息约 30 秒内自动开始处理（此前可能永远沉默）；收件箱面板不再「时好时坏」——读取失败会明确报错并给恢复按钮。**收件箱读取速度从分钟级降到秒级**（长会话多项目场景此前一次面板读可能卡 18 分钟以上，根因已修）；给会话的消息有时收不到回应的断链问题已修。
**怎么用**：收件箱在左下角邮箱图标；失败提示旁一键恢复；空闲自动处理默认行为无需配置。
**原理（1~2 句）**：消息写入改为一次完成、忙时自动排队；投递前查重避免重复送；空闲会话收到消息自动开工，失败自动重试数次。
**⚠️ 行为提示**：短时间内**重新发送完全相同的内容**给同一会话，会被自动合并为一条（防重复投递的保护）——如需重发请稍作修改。

## 🤝 主线二：协作与多会话体验

**你能感受到的**：后台任务完成会自动「叫醒」所在会话继续干活；停止按钮分三级（普通→升级→强制）覆盖全部场景；失败消息可一键重发；给谁的消息、谁发来的有下拉筛选；子代理完成后的确认提示不再卡住界面；**手动拖拽的会话顺序在刷新/新会话活动/重启后保持不变**；**左侧栏不再闪现「正在修复/稍后重试」等一闪而过的状态行**（持续 2 秒以上的真实修复仍正常显示）。
**怎么用**：停止按钮点击箭头展开三级；重发按钮出现在失败消息旁。
**原理**：后台任务完成后自动通知所属会话继续；排序持久化与显示层口径对齐；瞬态状态行去抖。

## 🚀 主线三：一键分析全面升级

**你能感受到的**：
- **卡住也能分析**：会话卡顿检测弹窗直接给分析入口（不再只针对崩溃）；
- **进度实时可见**：分析会话有名字、有实时进度，不再是黑盒等待；
- **崩溃后一键恢复**：真实崩溃下次启动主动弹分析横幅，不再静默上报；
- **诊断会话统一归档**：一键分析创建的会话一律建在 Global 下，不再落进当前项目；
- **弹窗观感统一**：分析/崩溃弹窗全中文化；
- **分析不阻塞**：分析过程中可折叠弹窗继续其他操作。

**怎么用**：会话卡住或崩溃后，点弹窗「一键分析」；进度与结论在自动创建的分析会话中查看。
**原理**：分析管线共享同一条会话创建与进度事件链；诊断会话归档到全局作用域。

## ⚡ 主线四：速度与资源

**你能感受到的**：
- **大会话切换从 71.7 秒到 3 秒上下（实测）**：会话快照稀疏索引+尾部窗口加载（更早内容翻上去再补）；
- **切换模型 / reasoning 档位**：此前需要 **10 秒以上**，现在 **3 秒级别**（不再重建请求管线）；
- **切换会话/标签页**：此前 **20 秒以上**（长对话 + MCP 场景），现在 **3 秒级别**；磁盘繁忙时切 tab/模型不再出现全应用卡顿；
- **启动**：文件系统探测限时 0.25 秒（此前网络路径异常可卡 21 秒）；
- **内存占用显著下降**：关闭会话立即释放其缓存，多开会话内存不再持续攀升；v4 快照物化设 96MiB 上限（曾致数 GB 级内存膨胀的根因已修）；内存异常增长可一键抓取分析档案；驻留会话按预算自动驱逐；
- **保存不再长时间等锁**：会话保存数十秒等锁已消除；
- **图片读取恢复稳定**：移除了图片引用化存储实验机制，各模型读图稳定；
- **压缩不再整单失败**：长会话压缩超限时保留部分进度继续；
- **上滑加载更早消息不再失败**：加载偶发失败自动退避重试；
- **Windows 不再弹黑色控制台窗口**（MCP 子进程启动根修）。

**原理**：请求管线按会话冻结+按请求覆盖；加载路径加缓存层+增量尾追替代全量重铸；锁内磁盘写结构化归零；子进程启动隐藏控制台。

## 🚄 主线五：设置实验室重组与用量监测

**你能感受到的**：
- **一个特性一枚徽章**：卡片头多枚徽章聚合为最高档（推荐>可选>未稳定），不再双标并排；
- **搜索直达**：设置搜索覆盖实验室条目——搜「心跳任务后台化」直达开关，不用逐组翻；

- **用量监测上侧栏**：GLM Plan 订阅用量按当前模型自动显示（五小时/周窗口余量+重置倒计时）；OpenCode Go 用量卡按当前地址条件出现——**用哪家显示哪家，不再无关占位**；设置页只留说明与开关，明细统一看侧栏；

- **新风格**：内置「专业+通俗」输出风格——技术解释自动附带通俗版；风格面板新增「打开目录」按钮直达自定义目录。

## 🚄 主线六：稳定性与正确性

**你能感受到的**：

## ⚠️ 升级提醒

1. 覆盖安装即可，数据/会话目录兼容，无需迁移；
2. **存储模式推荐停留在 v3**——fork 存储战略已定稿：v3 为长期推荐档；v4 可用但 v3 侧记录会滞后；v5 为上游 1.38.9+ 引入的新方向，其稳定性未经我们验证；**v4→v3 迁移器（备份提醒+进度可视化）下一版本提供**，届时可一键迁回；
3. **不要回退到 1.34/1.38.1 以下**（schema 2 单向升级，旧构建拒绝加载，文件不损坏）；
4. **本版含实验开关合并/旧键清理，也是单向的**——若回退旧构建，被合并的实验开关会回到默认态，需重新开启；
5. GC 手机客户端相关功能（接管倒计时）为配合件，完整体验待 GC 版本发布；
6. 实验特性默认关闭，设置 → 实验室逐个开启（推荐配置见安装节）。
