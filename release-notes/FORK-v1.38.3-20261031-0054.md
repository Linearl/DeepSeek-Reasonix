# Reasonix Fork 桌面版 v1.38.3-20261031-0054 — Release Notes

> 基于 v1.38.3-20261031-0012（包57）以来：实验室新增「DAG 迁移」卡（检查+迁移两按钮）。覆盖安装即可。

## 本版内容

- **实验室新增「DAG 迁移」卡**：两按钮——「扫描」清点当前还有多少旧格式会话、「开始迁移」把它们转到新格式（两步确认+实时进度）。正在使用的会话自动跳过（关掉它的 tab 再点即可），系统进程运行时迁移会自动拒绝以防冲突，历史修复快照不碰。迁移完成后：老会话保存不再触发全量重放（此前最大单个会话每次保存卡 4~6 秒），老日志也不再被旧格式绑定。
- **迁移工具增强**（同一入口）：扫描/迁移全程条数+进度+剩余时间反馈，逐条结果可读；异常中断不再丢报告。

## 使用提示

- 装完本包后：实验室 → 存储组 →「DAG 迁移」→ 先扫描、再迁移；提示有会话被跳过时，关掉对应 tab 后再点一次即可。
- 迁移**不会减小日志体积**（格式转换，内容不变）；要给旧会话日志瘦身，用实验室同组的「折叠/压缩」能力（后续包会修好它的判断逻辑）。
- **不要手动删除会话的 events 文件**：它是会话加载的首选数据源，删了会退回只保留最近 100 轮的检查点，更早的聊天历史会真丢。
