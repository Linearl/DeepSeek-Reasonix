# Fork 魔改特性介绍（用户向）

> 面向用户的 fork 差异说明：挑日常能直接感知、有明确入口的 13 条。
> 完整差异台账见 [`FORK-vs-upstream.md`](./FORK-vs-upstream.md)；结构与开关见仓库根 [`FORK.md`](../FORK.md)。
> 基线：官方 v1.38.3。
> 更新：2026-09-15。

---

## 1. 项目分组

项目树支持「新建分组」，项目可右键「移动到分组」。分组可折叠，**折叠状态跨重启保持**。

- **入口**：项目树头部「新建分组」；项目右键 →「移动到分组」
- **上游**：无（fork 独有，#9222）

## 2. 项目颜色筛选与排序（多选）

项目可设颜色标记，并按颜色**多选筛选**与排序。

- **入口**：项目树头部调色板按钮
- **与上游差异**：上游有颜色标记的数据层，**筛选 UI 是 fork 独有**；且 fork 的筛选支持**多选**（v1.38.3 起，此前点击是替换语义）

## 3. 本地服务器 / 远程网关

把桌面端已连接的项目通过局域网 / Tailscale 暴露给远程客户端（GrandCouncil 手机 App）。开关、监听地址、一键复制 gateway token。

- **入口**：设置 → 集成与连接 → 本地服务
- **上游**：无（fork 独有）

## 4. 工作阶段版本与副本

管理会话的恢复副本：查看**版本链**，**由用户选定**设为默认版本后合并（**不是自动挑最全的** —— 系统只在主线明显偏短时提示「主要内容可能在分支里」），被完全覆盖的副本归档进可恢复的回收区；若副本未覆盖当前记录则拒绝合并。

- **入口**：设置 → 存储与路径 → **工作阶段版本与副本**
- **上游**：无合并恢复副本能力（fork 独有）

## 5. 搜索历史提问

长会话内搜索历史提问并跳转；滚到顶部可加载更早历史。

- **入口**：会话内搜索
- **上游**：无（fork 独有）

## 6. 输入框草稿持久化

草稿 / 粘贴块 / 附件路径跨重启不丢（localStorage + `pagehide` 落盘，256KiB 上限）。

- **入口**：自动生效，无需设置
- **上游**：**fork 侧完整持久化层仍独有**。上游有草稿 key 推导（`composerDraftKey.ts`），但**无** `composerDraftPersistence.ts` 的 localStorage + pagehide 落盘路径；跨重启恢复是 fork 能力（台账 `#9580`，v1.33.0 交付）

## 7. 计划任务 / 心跳自动化（provider / 模型可选）

侧边栏「自动化」管理心跳任务；**每条任务可单独指定 provider / 模型**（模型覆盖支持 `provider/model`、纯 provider 或纯模型名，留空沿用话题当前模型）。

- **入口**：侧边栏 →「自动化」；任务编辑中的「模型覆盖」
- **上游**：心跳任务本身上游有；**上游 `HeartbeatTask` 类型无 provider/model 字段**，任务级模型覆盖是 fork 改进（台账 `#9070`，v1.33.0 交付）

## 8. 只读研究预算加倍

只读调研/分析任务触发软预算收敛后，可用 `extend_research_budget` 把轮次预算 **10→20→40→80**（每 turn 最多 3 次，时间闸门同步加倍）。

- **入口**：agent 自动出现该工具时使用
- **上游**：无（fork 独有）

## 9. 每轮上下文预算行

每轮注入上下文占用（如 `41k/128k (32%)`）；临近自动压缩阈值时提示把关键决策写进项目文档，降低长任务中途「被压缩焦虑」。

- **入口**：自动生效（Debug 级日志可查 `feature=context-budget`）
- **上游**：无（fork 独有，#9520）

## 10. 快捷指令

自定义常用文本片段，在输入框「+」菜单一键插入到光标处；仍由你确认后发送。支持搜索、启用/停用，上限 50 条（标题 60 字 / 正文 8KB）。设置与「+」菜单读同一份配置。

- **入口**：输入框「+」→ 快捷指令；管理在 设置 → 通用 → 快捷指令
- **上游**：无（fork 独有，v1.38.3）

## 11. 重启并更新（实验特性）

把本地构建从 `InstallRoot/staging` 发布为新版本并自动重启桌面端，零人工「关闭→更新→重启」。

- **入口**：设置 → 实验特性 → 打开后状态栏出现按钮（默认关闭）
- **上游**：无（fork 独有；上游走 Electron 自更新路径，见 #10222）

## 12. 乐观并发写入（并行写入安全检查可关）

上游多个会话写同一项目时，**整工作区一把写锁串行**——多会话并行开发时互相卡住。fork 提供 write-if-unchanged（`expected` 基线）陈旧内容检测：内容对不上就拒绝该次写，而不是把所有人堵在锁外。默认仍开串行锁（安全）；可在设置中关闭，改为并行 + 逐写校验。

- **入口**：设置 → 沙箱/权限 →「并行写入安全检查」
- **上游**：**未解决**。上游 `main-v2` 仅有 `WorkspaceLease` 整工作区串行，**无** `optimisticWrite` / `expected` 参数（台账 `#9213`）

## 13. 已授权写目录面板 + 全局公共写目录

可视化管理「这个会话/全局允许写哪些目录」：本会话已授权写目录可查看/添加/删除；**全局公共写目录**（`[sandbox] allow_global`）跨项目永久生效，子目录自动覆盖。解决「深层级写入反复弹审批、乱写随机子目录」的上游痛点。面板支持切换窗口内任意会话查看其授权（v1.33.0）。

- **入口**：设置 → 权限 → 已授权写目录
- **上游**：**未解决**。上游无写目录管理面板、无 `allow_global`（台账 `#9167` → `#9174/#9175`，v1.31.4 起）
