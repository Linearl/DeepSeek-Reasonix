# Reasonix Fork 桌面版 v1.38.3-20261029-0414 — Release Notes

> 基于官方 v1.38.3，包含上一个包 **desktop-v1.38.3-20261029-0133** 以来的全部更新（6 项滚合：tl1228 + tl1221hot + tl1233 + tl1235 + tl1226b + tl1230）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。

## 概览

本版是 **性能双达标 + UI 细节修批**：①大会话冷启动性能 P0 达标（resolve 239.5ms→61.1ms、内存 147.8→5.1MB）；②纯 CSS 双件修模式下拉跳变与换行图标；③信件族双件修角标与懒加载。

## ⚡ 大会话冷启动性能（tl1228，双 P0 达标）

- **resolve 有界探测**：大会话状态解析从常态 239.5ms 降到 **61.1ms**（有界探测替代无界全量扫描）。
- **内存治理**：图缓存两层同降 64MiB，applyMessage 峰值内存 **147.8MB→5.1MB**（≤150MB 目标超额达成）；巨会话最后一公里接 tl1173 checkpoint（接缝已留）。

## 🎨 模式切换 UI 修复（tl1233 + tl1235，纯 CSS）

- **模式下拉固定宽**：composer 模式下拉展开态宽度 116→168px 固定，切换模式不再跳变。
- **↪ 图标换行修复**：flex-wrap 根因修复，图标不再被挤到第二行。

## ✉️ 信件族修复（tl1226b + tl1230）

- **新信角标即涨**：收到新信件时左下角未读角标立即+1（此前需刷新才涨）。
- **信件懒加载**：信件列表 20 条上滑分页加载，大会话信件不再一次性全量拉取。

## 🧪 测试面实证钉（tl1221hot）

- session_heads_scan 测试补 2 行实证双钉；其余 19 件改判退役处置归 tl1236（任务书前提已被 1227 读侧退役冲掉）。
