## 概览

本版主线是**昨日验收打回的两件返修 + 过程透明性与体验打磨**：引导消息有了 ↪ 标识与真实时间戳、输入框历史提示词能翻到 steer、pre-repair 备份清理从「弹系统窗+按钮卡死」修到顺手（孤儿标注+按大小排序）、bash 等工具调用前有了人话描述；另有一批底层稳态——Shell 声明不再随重启漂移、进程存活判定对齐防误清、重启更新装错目标当场报错不再静默失败。

## 🚀 主线一：消息显示与历史补齐

**你能感受到的**：
- **中途插入的引导消息有了 ↪ 标识和真实时间戳**——与普通消息一眼可分，被切开的回合不再显得「输出断了半截」；
- **输入框的历史提示词能翻到引导消息了**——按 ↑ 或点时钟图标翻历史时，之前中途补充的话（steer）不再缺席；
- **更新提示会告诉你是哪个版本**——装机重启后的提示带上新版本号，不用再自己去查。

**原理一句话**：引导消息此前被「不算独立用户回合」的分类判据误用于显示与历史入口，现在各处用对了判据。

## 🚀 主线二：备份清理顺手了（验收返修）

**你能感受到的**：
- **删除备份不再弹 Windows 系统弹窗**——走应用内确认与回收站语义；
- **删完一条其他按钮不再卡死**——状态刷新正常；
- **原对话已不存在的备份会标注出来**（孤儿），**列表按占用从大到小排**——最占空间的排最前，清理收益一目了然。

## 🌐 主线三：过程透明与体验

**你能感受到的**：
- **工具调用前有人话说明了**——bash/读写/检索等 7 个高频工具的调用卡显示一句「这一步在干什么」（模型按指引填写），命令原文收在下方可展开；
- **远端连接向导等处的容量数字统一为 KB 口径**，不再一处 KiB 一处 KB；500 B 不再显示成「500.0 B」；
- **等待提示不再误报**（昨日包已修，本版含其返修链）。

## 🛡️ 主线四：底层稳态

- **Shell 声明不再随重启漂移**——环境 shell 探测纳入持久防抖（跨重启字节稳定），探测瞬时失败不再让环境声明来回翻；
- **进程存活判定对齐**——修掉「EPERM（进程存在但无权限）被判成死进程」导致的锁误清风险；
- **重启更新不再静默失败**——没设置更新目标就执行会当场报错并告诉你先 set_target（此前会静默排队到边界失败）；
- **测试与出包防线补强**——预存红登记制、出包祖先性自动校验、预算棘轮台账入库三件套随包。

## ⚠️ 升级提醒

- 覆盖安装即可，数据（会话/配置/项目）无迁移；
- 工具调用卡的「人话描述」由模型按指引生成，个别调用可能仍只有命令原文（属正常）。
