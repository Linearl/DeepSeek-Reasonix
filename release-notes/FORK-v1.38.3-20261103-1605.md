# Reasonix Fork 桌面版 v1.38.3-20261103-1605 — Release Notes

> 基于 v1.38.3-20261103-1152（包68）以来：**六件滚合**——P0 会话开轮即断根治 + 终端命令交互改版 + 渲染丢信息三修 + 项目树整理失败三修 + workflow 两处契约修复。覆盖安装即可。

## 本版内容

### 缺陷修复（P0/P1）

- **多会话开轮即断根治**（1364）：双层修复——环境层定位为 mimo-api 通道凭据失效导致开轮即断（走该通道的会话全部受影响，其他模型通道会话不受影响；**已知现象：该通道凭据需在 .env 续期后方恢复**）；代码层修复合并时丢失终态诊断证据的问题（中断态信息以 newest-wins 方式携带，转录不再只剩裸 interrupted 标记）。六轮复现回归 2/2 通过。
- **终端命令交互改版**（1365）：点开命令工具卡先看结果——命令区默认最多三行截断、下方「展开命令」入口点开才显示完整命令；结果区「显示全部」独立工作，互不干扰。
- **渲染丢信息最小档三修**（1347-fix）：XML 剥离双层防护 + 加载失败时透传原文 + 前端兜底，三处堵住内容在渲染链路中静默丢失的口子。
- **项目树「正在整理历史」失败三修**（1315）：失败判定按文件版本记忆（不再每轮重解析注定失败的大转录）+ 目录扫描失败留痕（不再无迹可查）+ 失败记忆从「全禁到下次重建成功」演进为「落定态接管」。

### 缺陷修复（P3）

- **workflow 状态空态契约修平**（1334）：一次运行都没发生过时，状态查询统一返回空列表而非空值——调用方不再需要区分两种空。
- **workflow 恢复快照时间回填**（1336）：存档时记录每个节点的完成时刻，重启读档原样填回——不再出现「公元元年」零值时间（-62135596800000）；老存档没有的时间留空不瞎填。

## 门禁与质量

- 六件全部经合并线滚合+门禁（合后 23/0 全绿 + 双钉 + tsc + vet）。
- 预存红申报（基线对照）：internal/control 11 项 / agent 2 项 / sessioncatalog 3 项与基线同红，净新增红=0。

## 升级提醒

- 从包68（1152）覆盖安装即可；设置与数据全兼容。
- **已知现象**：若使用 mimo-api 直连通道的会话仍开轮即断，需续期 `.env` 中的 `MIMO_API_KEY`（凭据文件不随包更新）。
