# Reasonix Fork 桌面版 v1.38.3-20261031-0810 — Release Notes

> 基于 v1.38.3-20261031-0054（包58）以来：**夜间七件大批**——内存按需解码（P1 主力）+ events 瘦身根治 + GC 策略旋钮 + 存储面板重构 + 残影根因修复 + 全角！！任意行 + 设置页提速。覆盖安装即可。

## 本版内容

- **内存按需解码/驱逐三层落地**（1281，P1 主力）：大会话的消息数据不再全量驻留内存——实测大头 `literalStore` 从 **277.6MB 降到 53.2MB**。打开大会话后的内存占用显著下降，这是「内存基线」战役的主力件。
- **events 瘦身根治**（1285）：折叠判据反向缺陷修复——预估「折不动」不再永久豁免，改放行一次真实折叠并按实测收益判定；确认无收益的大日志自动走**无损 zstd 压缩兜底**；清扫的活跃判定修复（tab 开着但不在工作持续一段时间即纳入处理），配额改为按可释放字节排序——**最大的日志优先被处理**，不再「越活跃越被跳过」。
- **实验室键替换：Go 软内存上限 → GC 策略旋钮**（1286）：原「Go 软内存上限」实测设低会触发 GC 风暴卡死，已退役（旧配置值安全忽略）；替换为 GC 策略旋钮（热改、可随时回退）。
- **会话存储面板重构**（1287）：v4 档位选项退役（保留 v4→v3 迁移器）；**DAG 迁移卡从实验室转正**进会话存储面板（复用统一进度/报告 UI）；新增「清理迁移备份」按钮（显示占用+一键清理，保留最近一份）；新增 v5 会话导入入口。
- **残影根因修复**（1288）：tab「运行中」残影的 wedged-running 根因定位并修复（不再叠防线，直接治本）。
- **全角！！+ 任意行激活**（1273）：快捷指令支持全角 `！！`（免切输入法），且**任意行行首**都能触发（此前仅首行）。
- **设置页打开提速**（1284）：实验室页数据就绪 17.5s→秒级（boot 排队异步化，骨架先行）。

## 升级提醒

- 覆盖安装兼容，会话/配置/记忆目录不变；**不要回退到 1.38.1 以下版本**（会话格式不兼容）。
- Go 软内存上限设置已退役：若旧配置留有该值会被安全忽略，无需手动清理。
- 已知预存红：internal/control 全包 11 失败（schema-2 持久化类环境红，与本次改动无关）。
