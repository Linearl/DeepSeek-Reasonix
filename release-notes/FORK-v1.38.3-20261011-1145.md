# Reasonix Fork 桌面版 v1.38.3-20261011-1145 — Release Notes

> 基于官方 v1.38.3，包含 2026-09-21 正式版（1600）以来的全部更新（三周，约 400+ 提交；细节见各时间戳 notes，本篇列发版级主线）。
> 数据/会话/记忆目录与官方版完全兼容，覆盖安装即可，无需迁移。
> **Fork 与上游差异全览**：见 [FORK-vs-upstream.md](./FORK-vs-upstream.md)。

## 概览

自首发以来四批连发：**界面体验**（设置实验室全面重组——单徽章、搜索直达、卡片合并）、**稳定性**（切模型参数钳制、简洁模式双根因、竞态与预存红清零、hang 误报族收口）、**远端协作**（接管补锁、消息卡片化、复制键补齐）、**新能力**（v5 会话导入器、存储四档稳定化、专业+通俗内置风格）。工程质量侧：CodeQL 门禁激活且告警清零、race 检测清零、15 条历史预存红清零、integrity 锚点 872/872。

## 🚄 主线一：多会话协作与信件中心（9-21→10-10 批次）

**你能感受到的**：
- **信件中心**：跨会话消息的人类可读面板——五桶聚合（审批/提及/自动化/系统）、保留期与清理规则、发信方过滤、对话链视图（此前只有 agent 能读信件）；
- **协作群聊视图**：只读观察窗——AI 团队分工、会话运行状态、消息数一目了然；
- **跨会话消息卡片化**：引导消息统一卡片展示（来源标签+悬停完整 ID），不再裸露原始文本；
- **远端接管**：移动端/远程客户端接管桌面会话的完整链路（超时语义、标记栏、后台不动运行中会话）。

## 🚄 主线二：性能与资源（9-21→10-10 批次）

**你能感受到的**：
- **大会话切换从 71.7 秒到 1 秒上下**：会话快照稀疏索引+尾部窗口加载（更早内容翻上去再补）；
- **内存治理**：v4 快照全量物化修复（上限 96MiB）、heap 高水位自动抓取（7 天保留+越档即抓）、驻留会话预算驱逐；
- **保存锁等待消除**：会话保存不再出现数十秒等锁。

## 🚄 主线三：设置实验室重组（10-06 起批次）

**你能感受到的**：
- **一个特性一枚徽章**：卡片头的徽章聚合为最高档（推荐>可选>未稳定），不再双标并排；
- **搜索直达**：设置搜索覆盖实验室条目——搜「心跳任务后台化」直达开关，不用逐组翻；
- **界面组瘦身**：14 项合并为 9 项（检索与历史/输入与选区/视图布局三张合并卡），一屏可见；
- **参数卡规范**：新参数卡不带任务编号后缀，各配徽章（闲置释放=推荐、Go 软内存上限=可选）；
- **新风格**：内置「专业+通俗」输出风格——技术解释自动附带通俗版；风格面板新增「打开目录」按钮直达自定义目录。

## 🚄 主线四：稳定性与正确性

**你能感受到的**：
- **切换模型不再报参数错误**：max_tokens 按目标模型自动钳制；
- **简洁模式双根因修复**：思考展开内容错乱与滚动跳走均已修（测试钉住）；
- **hang 误报族收口**：正常等待不再被误报为卡死；弹窗分析失败后提供「复制」按钮手动反馈；
- **长任务不再卡界面**：958ms 级长任务两大源头消除，通知音效不再卡顿；
- **项目树稳定**：双现条目与闪烁已修；右键「移动到分组」即时生效。

## 🤝 主线五：远端与协作

**你能感受到的**：
- **跨会话消息统一卡片化**：带来源会话标签，不再裸露原始文本与联系人 ID；
- **远端接管更稳**：并发代理锁与接管会话补锁，多端操作不再抢占错乱；
- **协作标签页不再空白**；心跳会话归属正确（不再错进 Global）；
- **崩溃误报消除**：更新重启不再重复弹崩溃分析提示（历史积压一次性排水）。

## 🧩 新能力

- **v5 会话导入器（CLI）**：`sessions import-v5`——上游 1.38.9+ 桌面版的 v5 会话可导入 fork（默认 dry-run 预览+全量备份+完整性校验）；
- **存储四档稳定化**：会话存储四种模式全部通过八阶段验证矩阵（历史版本的双写写放大缺陷已修——增量尾追替代全量重铸）；
- **外部协作总线（实验）**：本进程内托管协作总线 MCP 端点，外部 agent 可接入 Reasonix 信件与任务卡（替代外部 serve 常驻）；
- **路径规则接线（实验）**：`.reasonix/rules/` 规则文件注入运行时（Claude Code rules 语义）。

## 🔧 其他改进

- **CodeQL 门禁激活**：安全扫描进 CI 且 6 条告警全部分诊闭环（0 open）；
- **race 检测清零**：5 处跨测试数据竞争修复，-race 全绿；
- **15 条历史预存红清零**：断言与锚点全面对齐现行机制；
- **vet 全仓清零**：unsafe 使用唯一一处真修（出参语义化）；
- **app.go 拆分**：7846 行巨石文件按域拆为 15 个文件（纯移动，行为零变化）；
- **依赖安全升级**：HTTP/2 竞态依赖与工具链升级；
- **integrity 锚点体系**：872/872 全绿（拆分重构后逐锚实点迁移）。

## ⚠️ 升级提醒

1. 覆盖安装即可，数据/会话目录兼容，无需迁移；
2. 存储模式建议停留在 v3（四档已稳定化，但日常推荐 v3）；
3. **不要回退到 1.34/1.38.1 以下**（schema 2 单向升级，旧构建拒绝加载，文件不损坏）；
4. 实验特性默认关闭，设置 → 实验室逐个开启；
5. **本版未含**：协作群聊增强、GC 移动端配合件（下一版本内容）。
