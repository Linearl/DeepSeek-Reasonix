## 配置文件位置

- 全局：用户级配置目录下的 `reasonix.toml`
- 工作区：项目根目录下的 `reasonix.toml`

## 常用分区

| 分区 | 作用 |
| --- | --- |
| `[desktop]` | 桌面端偏好（语言、外观） |
| `[experimental]` | 实验特性开关（默认关闭） |
| `[permissions]` | 工具审批与沙箱策略 |
