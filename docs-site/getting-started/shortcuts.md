# 快捷键

按使用端划分。桌面端快捷键在 **设置 → 快捷键** 中管理，按 `?` 可随时打开快捷键帮助表（显示当前实际生效的绑定）。

## 桌面端：全局

| 按键 | 作用 | 说明 |
| --- | --- | --- |
| Windows/Linux `Ctrl+K`，macOS `Cmd+K` | 打开或关闭命令面板 | 打开时聚焦搜索框；`Esc` 关闭 |
| `F1` | 打开产品文档 | 本站；命令面板中也有「产品文档」项（fork 新增） |
| Windows/Linux `Ctrl+,`，macOS `Cmd+,` | 打开设置 | 设置里的「快捷键」页可自定义绑定 |
| Windows/Linux `Ctrl+W`，macOS `Cmd+W` | 关闭当前顶部标签页 | 最后一个标签页有关闭保护 |
| `Ctrl+B` / `Cmd+B` | 显示或隐藏左侧边栏 | |
| `Ctrl+Shift+B` / `Cmd+Shift+B` | 展开或收起最近的 shell 输出 | |
| `Ctrl+1`-`9` / `Cmd+1`-`9` | 跳转到侧边栏对应编号的可见对话 | 短暂按住 `Ctrl`/`Cmd` 会显示编号标记 |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | 放大、缩小或重置文字大小 | macOS 为 `Cmd` 系 |
| `?` | 打开键盘快捷键帮助表 | |

## 桌面端：输入框

| 按键 | 作用 | 说明 |
| --- | --- | --- |
| `Enter` | 发送当前消息 | IME 组合输入确认不会被截获 |
| `Shift+Enter` | 插入换行 | |
| `Shift+Tab` | 切换 Plan 开/关 | Plan 只改变「先规划」的工作流 |
| `Ctrl+Y` / `Cmd+Y` | 切换 YOLO 开/关 | 关闭时尽量恢复之前的 Ask/Auto 基底 |
| `Ctrl+V` / `Cmd+V` | 粘贴剪贴板内容 | 剪贴板图片会作为附件加入；图片也可拖进输入框 |
| 输入边界处 `Up` / `Down` | 回放更旧或更新的已提交提示词 | |
| 运行中 `Esc` | 取消当前回合 | 后端尚未开始回复时会恢复草稿 |

## 桌面端：审批卡片

| 按键 | 作用 |
| --- | --- |
| `Left` / `Right` | 移动高亮动作 |
| `Enter` | 确认当前高亮 |
| `1`-`4` | 直接选择编号动作（工具审批默认高亮「允许一次」） |
| `Esc` | 拒绝或关闭 |

## CLI / TUI：常用

| 按键或命令 | 作用 | 说明 |
| --- | --- | --- |
| `Shift+Tab` | 按 Ask → Auto → Plan 循环 | 底部状态栏显示当前模式 |
| `Ctrl+Y` | 切换 YOLO 开/关 | |
| `Ctrl+L` 或 `/cls` | 只清空可见 transcript | 丢弃对话上下文用 `/clear` |
| 空闲且输入为空时双击 `Esc` | 打开 rewind 选择器 | 同 `/rewind` |
| `Ctrl+O` | 切换详细 reasoning 显示 | 同 `/verbose` |
| `Ctrl+B` | 展开或收起较长 shell 输出 | |
| macOS/Linux `Ctrl+V`；Windows `Alt+V` | 粘贴剪贴板图片 | 图片粘贴是独立的应用动作 |
| 以 `!` 开头的一行 | 直接运行 shell 命令 | 不经过模型 |
| `Ctrl+C` | 复制、取消、清空或退出 | 有选区时优先复制 |
| `Ctrl+D` | 退出 TUI | |

## 自定义

桌面端：**设置 → 快捷键**，选择可配置行后按下新组合键即可保存。撤销、重做等标准编辑快捷键为锁定项；与已有动作冲突的组合键会拒绝保存。
