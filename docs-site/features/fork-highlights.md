# 本 fork 特性

本仓库是 [esengine/DeepSeek-Reasonix](https://github.com/esengine/DeepSeek-Reasonix) 的长期维护 fork：在追齐上游的同时保留确实需要的改动。数据与上游兼容（随时可用官方安装包切回）。这里挑日常能直接感知、有明确入口的能力；完整差异台账见仓库 [`release-notes/FORK-vs-upstream.md`](https://github.com/Linearl/DeepSeek-Reasonix/blob/main-v2-stable/release-notes/FORK-vs-upstream.md)。

## 桌面 UI

| 能力 | 入口 |
| --- | --- |
| 项目分组（折叠状态跨重启保持） | 项目树头部「新建分组」；项目右键「移动到分组」 |
| 项目颜色筛选与排序（多选） | 项目树头部调色板按钮 |
| 搜索历史提问并跳转 | 会话内搜索 |
| 输入框草稿持久化（草稿/粘贴块/附件路径跨重启不丢） | 自动生效 |
| 快捷指令（常用文本片段一键插入，上限 50 条） | 输入框「+」→ 快捷指令；管理在设置 → 通用 |

## 服务端与远程

| 能力 | 入口 |
| --- | --- |
| 本地服务器 / 远程网关：把桌面端项目暴露给局域网 / Tailscale 客户端 | 设置 → 集成与连接 → 本地服务 |
| 独立 CLI 网关（NAS / systemd 部署） | 见仓库 `docs/` |

## 存储与恢复

| 能力 | 入口 |
| --- | --- |
| 合并恢复副本：列出带 recovery 副本的工作阶段（主线/总计/共有/独有/孤立计数），可预览分支、查看尾部消息、勾选合并；被完全覆盖的副本进可恢复回收区 | 设置 → 存储与路径 → 工作阶段版本与副本 |
| 重启并更新（实验特性）：本地构建一键发布并自动重启 | 设置 → 实验特性打开后状态栏出现按钮 |

## Agent 与上下文

| 能力 | 说明 |
| --- | --- |
| 只读研究预算加倍 | 只读调研触发软预算收敛后，`extend_research_budget` 把轮次预算 10→20→40→80 |
| 每轮上下文预算行 | 每轮注入占用（如 `41k/128k (32%)`），临近压缩阈值时提示写关键决策进项目文档 |
| 计划任务模型覆盖 | 侧边栏「自动化」中每条心跳任务可单独指定 provider / 模型 |
| 乐观并发写入 | 多会话写同一项目不再整工作区一把锁串行；write-if-unchanged 检测陈旧内容并拒绝错误写入。默认仍串行（安全），可在设置 → 沙箱/权限关闭串行锁 |
| 子代理委派档位 | 按任务选择子代理规格 |

## 权限

| 能力 | 入口 |
| --- | --- |
| 已授权写目录面板：会话级授权可视化管理 + 全局公共写目录（跨项目永久生效，子目录自动覆盖） | 设置 → 权限 → 已授权写目录 |

## 稳定性约定

- 只测 Windows 桌面版（`win-amd64-desktop` + 经典布局），其他目标未经验证。
- 稳定版本：`1.31.4` – `1.34` 与 `1.38.3`；`1.38.1` 已知不稳定。
- 上游处于大重构或发版混乱期时不追更新，停留当前基线。
